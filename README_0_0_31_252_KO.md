# JCS 0.0.31.252 — 프로필·정보 배치 편집 (1차)

31.251이 적용된 기존 정참시 저장소에 올리는 **변경 파일 전용 패치**입니다. 전체 사이트 소스가 아닙니다.

## 설치
1. ZIP을 풉니다. `index.html`, `src`, `css`, `api`, `lib`, `assets`를 **기존 저장소 루트의 같은 경로**에 올립니다.
2. 기존 파일 삭제는 없습니다. 폴더를 통째로 삭제하거나 이 ZIP으로 저장소 전체를 교체하지 마세요.
3. `api/polimable-hud-layout.js`와 새 `lib/polimable-hud-layout-http.js`도 반드시 함께 올리고 Vercel 배포를 완료합니다.
4. 관리자 계정으로 로그인하고 `/polimable`에 접속합니다. 우측 상단 **배치 편집**을 누릅니다.

기존 인증/Redis 모듈(`lib/session.js`, `lib/rebuild-store.js`, `lib/redis-rest.js`)과 기존 `JCS_REBUILD_SESSION_SECRET` 및 Redis 연결 설정을 재사용합니다. 이 패치는 해당 기존 파일을 덮어쓰지 않습니다. 별도 패키지 설치나 환경변수 추가는 없습니다.

## 이번에 편집할 수 있는 것
1P/2P 각각 프로필 사진, 플레이어 이름, 민심 글자, 민심 점수, 바퀴 수, 자산 글자, 자산 점수 — 총 14개 요소.

- 화면에서 누른 뒤 끌어 옮기기; 선택 테두리 오른쪽 아래 손잡이로 크기 변경
- 작은 요소는 오른쪽의 **수정할 부분** 목록에서 선택
- 화살표 버튼 또는 키보드 방향키: 보드 원본 기준 1px 이동; Shift+방향키: 10px 이동
- 프로필: 원형에 맞춤 / 얼굴 크기 / 사진 안쪽 이동. 사진 안쪽 이동은 원형 프레임은 두고 얼굴 위치만 조절합니다.
- 글자: 크기와 색 변경. 게임의 실제 이름·민심·바퀴·자산을 표시합니다.
- 되돌리기/다시, 전체 보기/선택 확대, 가로폰·폴드 화면 비율 미리보기
- **미리보기**: 편집선 없이 실제 배치를 확인. 게임은 여전히 일시정지됩니다.
- **닫기**: 게임으로 돌아갑니다. 아직 전체 반영하지 않은 배치는 게임 화면에 적용하지 않으며, 관리자 기기에 임시저장해 다음 편집 때 이어갈 수 있습니다.

모바일에서는 도구를 화면 아래에 배치합니다. 도구 모음을 옆으로 넘기면 나머지 조절 기능이 나타납니다. 편집 도구는 게임과 함께 축소되지 않습니다.

## 안전한 편집 진입
이동·주사위·AI 턴·거래 선택이 진행 중이면 **턴 종료 후 편집 · 취소**로 대기합니다. 안전한 1P 대기 시점에만 현재 테스트 게임을 일시정지합니다. 다른 이용자의 게임을 멈추지 않습니다. 편집 중 주사위/전략카드 입력을 차단하고, 닫으면 기존 게임을 재개합니다. 진행 중인 거래는 먼저 마무리해야 합니다.

## 임시저장과 전체 반영은 다릅니다
- 임시저장: 현재 관리자/현재 브라우저의 localStorage. 다른 사람에게 적용되지 않습니다.
- **전체 반영**: 확인창 후 관리자 인증을 서버에서 검증하고 기존 Redis에 배치를 저장합니다. 다음에 새로 여는 게임은 서버 배치를 불러옵니다. 진행 중인 다른 이용자의 게임 화면을 강제로 이동시키지 않습니다.
- 저장 실패/권한 오류/동시 수정 충돌이면 완료라고 표시하지 않습니다. 내 임시저장은 유지됩니다.
- 다른 관리자가 먼저 반영한 버전 위로 덮지 않도록 버전 비교 및 Redis 원자적 비교 저장을 사용합니다.
- **백업·복구 → 이전 전체 배치 복구**: 직전 게시 배치를 서버에서 복구합니다.
- 설정 JSON 내려받기/불러오기는 보조 백업 기능이며, 사용자가 숫자를 직접 편집할 필요는 없습니다.

API를 함께 배포하지 않았거나 서버 연결에 실패한 경우 관리자는 `배치 편집 연결 재시도`를 보게 됩니다. 서버 저장에 성공하지 않은 상태를 전체 반영 완료라고 표시하지 않습니다.

## 이번 범위에서 바꾸지 않은 것
기존 31.249 배경 이미지, 게임판, 32칸 이동 좌표, 기업별 깃발/건물 좌표, 주사위 결과/확률, 가격·강화·특수칸 경제 규칙, AI 판단, BGM·효과음, 카드 UI를 변경하지 않습니다.

**칸별 캐릭터/깃발/건물 배치 편집은 이 패치에 포함되지 않습니다.** 승인한 단계 구분에 따라 먼저 프로필·정보 편집기를 확인합니다. 따라서 기존 깃발 위치 문제가 이 파일로 해결되었다는 의미는 아닙니다.

기존 배경은 재생성하지 않았습니다. 기존 프로필 스프라이트의 원형 부분만 실제 PNG로 잘라 별도 파일 2개로 만들었습니다. 프로필·HUD 동적 요소의 구식 표시를 숨기고 새 편집 가능한 요소를 같은 논리 캔버스에 표시합니다.
