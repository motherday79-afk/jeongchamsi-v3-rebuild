# 0.0.31.337 — 오래된 폐허

- 월드맵에 1인 추리 미니게임과 전용 폐허 배경·제목을 추가했습니다. 예상 난이도 3.8~4.0/5이며 실제 플레이 후 조정합니다.
- 여섯 석관의 문양·보석·무기를 비교합니다. 네 조사 지점에서 ‘두 기록 중 정확히 하나만 참’인 단서를 모으고 수호자에게 두 번 질문할 수 있습니다.
- 시간 제한 없이 후보를 표시하고 한 석관을 최종 개봉합니다. 성공/실패 후 단서별 가능 후보와 정답 해설을 확인하고 새 문제에 재도전할 수 있습니다.
- 정답은 서버에만 저장되며 300개 배치에서 네 단서의 유일한 정답과 각 단서의 필요성을 검사했습니다. 진행 중 재입장하면 같은 탐험을 이어갑니다(30분 이내).
- 왕묘 발견 1회를 일일퀘스트에 연결해 총 8개로 확장했습니다. 별도 골드·다이아 보상은 지급하지 않습니다.
- 기존 뒤로가기, 공통 제목, 음향 켜기/끄기 규칙을 사용합니다. 배경음은 기존 추리/약탈 계열 BGM을 공유합니다.
