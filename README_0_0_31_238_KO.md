# JCS 0.0.31.238 · POLIMARBLE Logical Canvas + 1P HUD Patch

## 목적
31.237에서 HUD 요소가 서로 다른 좌표계와 반응형 규칙에 의해 흔들리던 문제를 먼저 정리합니다.
이번 단계는 전체 HUD를 한 번에 고치는 것이 아니라, 1672×941 고정 논리 캔버스를 도입하고 1P 정보만 픽셀 좌표로 정확히 검수하는 1단계입니다.

## 이번 패치에서 변경
- 1672×941 고정 논리 캔버스 추가
- 브라우저 표시 크기에 맞춰 논리 캔버스 전체를 통째로 scale
- 1P 이름 / 민심 / 바퀴·자산을 각각 독립 픽셀 좌표로 배치
- 2P 정보, 전략카드, TODAY RANKING, 소유 마커는 다음 단계 좌표 검수를 위해 임시 숨김
- 기존 주사위 / 캐릭터 이동 / AI 턴 / 게임룰은 유지
- 기존 백그라운드 이미지 변경 없음

## 검수 포인트
1. 1P 이름이 첫 번째 정보 라인 중앙에 들어가는지
2. 1P 민심이 첫 번째 정보 라인의 큰 숫자 위치에 맞는지
3. `N바퀴 · 자산 N`이 두 번째 정보 라인 중앙에 맞는지
4. 브라우저 크기를 바꿔도 1P 텍스트가 패널에서 따로 밀리지 않는지
5. 주사위 / AI / 캐릭터 이동은 31.237과 동일하게 작동하는지
