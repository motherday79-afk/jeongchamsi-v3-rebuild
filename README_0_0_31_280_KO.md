# 정참시 280 — 광산 표시·광고 이미지·채굴 리듬

- 공동 잭팟은 금고 느낌의 금속 테두리와 큰 금액으로 표시합니다. 기존 공동 실패 횟수에 1회=1G 기준을 적용한 누적 표시입니다. 현재 지급·차감은 없으며 추첨도 비활성입니다. 브론즈 100G·실버 300G·골드 1,000G 설명은 도움말로 이동했습니다.
- 관리자 광고 설정에 이미지 첨부, 미리보기, 이미지 지우기를 추가했습니다. JPG·PNG·WebP 최대 1MB, 권장 800×450px입니다. 이미지 선택 후 업로드 완료를 기다리고 **광고 설정 저장**을 누르면 반영됩니다. 잘리지 않게 전체 이미지를 표시합니다.
- 광고 이미지는 기존 공개 Vercel Blob에 저장하며 Redis에는 URL만 저장합니다. 저장소 설정이 없는 경우 업로드 실패를 표시합니다. 광고판 클릭과 회수 후 광고주 이동은 유지합니다.
- 채굴 모션의 들어 올리기·내려치기·충돌·회복 시간을 다르게 조정했습니다. 기존 8프레임 이미지를 유지한 타이밍 수정이며 1.5초 채굴 주기는 그대로입니다.
- 정기 heartbeat 통신 때 채굴 버튼을 반복 비활성화하거나 저장 중 문구를 표시하지 않습니다. 같은 버튼·상태 문구와 정지 프레임의 반복 덮어쓰기도 줄였습니다.
- 화면을 켜둔 채 채굴을 멈추고 1분이 지나면 화면 안에 안내가 표시됩니다. 채굴 시작·화면 이탈·저장고 가득 참 때 안내와 대기 시간을 초기화합니다. 반복 팝업은 없습니다.
- 관리자 전용 입장 제한을 유지합니다. 기존 골드·강화·당첨 기록은 초기화하지 않습니다.

관련 테스트 21개 통과. 운영 이미지 업로드와 실제 화면·모션 검수는 사용자에게 맡깁니다. 279 FULL에 280 PATCH를 적용합니다.
