# 정참시 0.0.31.257 — 폴리마블 플레이 효과

## 사용 방법
폴리마블을 새로고침하고 주사위를 굴리면 새 효과가 자동 적용됩니다. 별도의 배치 재설정은 필요하지 않습니다.
- 주사위: 입체 회전 → 착지 → 확정된 눈 표시 → 해당 숫자만큼 이동.
- 캐릭터: 잘린 두 말 이미지를 온전한 투명 이미지로 교체. 이동 시 가벼운 점프, 그림자와 현재 차례 표시.
- 칸: 밟은 칸 표면·지명·소유 오브젝트가 함께 눌렸다 복귀하며 도착 테두리가 빛납니다.
- 깃발·건물: 획득·강화 시 등장 효과. 소유자별 테두리와 최종 강화의 굵은 테두리.
- 전략카드: 퍼플·골드 뒷면에서 앞면으로 뒤집혀 공개. 보유 카드는 왼쪽 프로필 아래에서 선택하고 사용하기를 누릅니다.

기존 가격·강화·주사위 확률·추가 턴 규칙과 서버에 저장된 배치 편집값은 유지합니다. 배치 편집 시 효과를 정지합니다. 기기의 동작 줄이기 설정에서는 회전·점프를 줄입니다.

## 확인 범위
게임·배치·카드·오디오 관련 자동 검사 32개 통과. 로컬 브라우저에서 굴림→이동→구매→AI 차례, 더블 2+2→4번 카드 칸→카드 사용을 확인했습니다. PC와 모바일 크기 화면을 확인했으나 실제 휴대전화의 성능·전체화면 동작까지 확인한 것은 아닙니다.

## 파일
PATCH는 256 전체에 덮어쓰는 변경 파일입니다. FULL은 257 전체 소스입니다. 테스트용 고정 주사위와 로컬 미리보기 서버는 포함되지 않습니다. 운영 배포 상태는 별도 배포 기록을 참고하세요.
