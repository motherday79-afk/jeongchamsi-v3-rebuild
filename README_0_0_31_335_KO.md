# 0.0.31.335

- 노래하는 숲·깨어있는 눈·망자의 계곡·후회없는 약탈·오만의 탑 입장 화면에 승인된 세계관 이야기와 짧은 규칙을 추가했습니다.
- 시작 후 이야기는 숨겨지며 기존 게임 규칙·보상은 유지합니다. 입장 문구는 작은 화면에서 스크롤할 수 있습니다.
- 망자의 계곡: 손이 나타난 후 충돌까지 0.35초 → 0.45초로 조정했습니다. 첫 20초의 사전 예고 0.1초를 포함하면 0.55초입니다. 전체 60초, 내구도 3칸, 금화 빈도와 공격 간격은 유지합니다.
- 클라이언트와 서버가 같은 회피 시간을 사용하며, 이전 버전의 진행 중 도전은 다시 시작해야 합니다.
