# 262 — 폴리마블 화면 확대
게임 전용 화면에서 정참시 공통 검색·글자크기·푸터를 제외하고 화면 안에 보드 전체가 들어가는 최대 크기를 사용합니다. PC의 1200px 바깥 제한 및 1672px 배율 상한을 제거했습니다. 모바일 주소창 높이 변화·회전에 맞춰 비율을 유지하며, 노치 안전영역을 반영합니다. 상단 중앙에 정참시 홈 및 지원 브라우저의 전체화면 버튼을 제공합니다. 홈 이동 시 일반 사이트 화면으로 돌아갑니다.
기존 칸 눌림·이펙트·게임 규칙·저장 배치는 변경하지 않았습니다. 사용자의 요청에 따라 반복 시각 검증은 생략하고 크기 계산 검사 및 JS 구문 검사를 수행했습니다. 새로고침하여 확인하세요.
