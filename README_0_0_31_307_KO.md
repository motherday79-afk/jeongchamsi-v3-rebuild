# 307 — 일일퀘스트 월드맵 · 광산 뒤로가기

## 사용 방법
- 광산 메뉴의 일일퀘스트를 누르면 화면 전체에 월드맵이 열립니다.
- 나의 광산: 채굴 화면으로 복귀합니다.
- 후회없는 약탈: 기존 약탈 게임에 입장합니다. 오늘의 도전 횟수와 퀘스트 완료 여부가 지도에 표시됩니다.
- PC·가로 화면용 지도와 모바일·세로 화면용 지도를 별도로 사용합니다.

## 뒤로가기 기준
- 광산 → 일일퀘스트 → 약탈: 뒤로가면 월드맵, 다시 누르면 광산입니다.
- 채굴·인부·저장고·상점·캐릭터·복권·도움말·관리 창에서도 열기 전 화면으로 돌아갑니다.
- 창의 닫기 버튼과 Esc도 한 단계 돌아갑니다.
- 월드맵의 광산으로/닫기/나의 광산은 광산 화면으로 돌아갑니다.
- 강화·구매 후 화면 갱신은 이동 기록을 추가하지 않습니다.
- 새로고침과 브라우저 앞으로가기도 저장된 광산 내부 화면을 복원합니다.
- 광산 기본 화면에서 뒤로가면 원래 방문했던 사이트 페이지로 돌아갑니다.
- 결과 저장 중 창을 닫아도 골드 정산은 취소되지 않으며 결과는 약탈 기록에 남습니다.

골드·도전 횟수·채굴 규칙과 관리자 전용 입장은 변경하지 않았습니다.
검사: 이동 기록 전용 테스트 3개 및 수정 JavaScript 문법 검사. 화면·플레이 검수는 사용자 진행.
