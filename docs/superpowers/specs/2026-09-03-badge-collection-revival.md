# JCS_0_0_26 배지 컬렉션 부활 설계

## 목표

구버전의 56종 배지 컬렉션(기본 13종, 확장 40종, BLACK 3종)을 복원한다. 브론즈부터 BLACK까지 등급이 즉시 구분되는 시그니처 크레스트 디자인으로 전면 개편하고, 실제 획득 판정·마이페이지 컬렉션·관리자 회원별 해금/회수·대표/전시 설정을 하나의 데이터 흐름으로 연결한다.

## 확정 정책

- 기존 배지 이름과 획득 취지를 보존한다.
- 브론즈·실버는 측정 가능한 조건을 달성하면 자동 획득한다.
- 골드·플래티넘은 조건 진행도를 보여주되 관리자 승인 후 획득한다.
- BLACK 3종(`운영자`, `정참시장`, `미카엘`)은 관리자만 회원별로 해금·회수한다.
- 관리자 계정은 56종 전체를 조건 없이 대표/전시 배지로 사용할 수 있다.
- 관리자는 일반회원에게 조건 미달 배지도 직접 해금할 수 있다.
- 저장된 글·댓글·좋아요·투표 등 과거 기록은 최초 조회 시 소급 평가한다. 과거 출석 자료가 없으면 출석/시간 배지는 배포 이후 기록부터 평가한다.
- 대표 배지는 1개, 전시 배지는 최대 3개이며 같은 배지를 두 영역에 중복 배치하지 않는다.

## 데이터와 판정

회원 활동 레코드에 `grantedBadges`, `representativeBadge`, `showcaseBadges`, `badgeSignals`, `badgeEvents`를 호환 방식으로 유지한다. 배지 엔진은 게시물·댓글·받은 좋아요·조회·투표·활동일·연속 활동일을 계산한다.

`earnedBadges`는 자동 획득 브론즈/실버, 관리자 직접 해금, 관리자 계정 전체 사용 권한을 합친 결과다. 골드/플래티넘 조건 충족은 `eligible` 상태로 노출하며 자동 지급하지 않는다. BLACK은 진행도와 무관하게 관리자 해금만 실제 소유로 인정한다.

## 화면

### 마이페이지

- `/mypage`에서 보유 수와 등급별 요약을 노출한다.
- `/mypage/activity?tab=badges`에서 56종 전체를 브론즈·실버·골드·플래티넘·BLACK 순으로 보여준다.
- 획득, 승인 대기, 미획득 상태와 조건 진행도를 구분한다.
- 획득한 배지만 대표 1개 및 전시 3개로 선택할 수 있다.

### 오른쪽 사이드바

- 로그인 회원의 대표 배지 1개와 전시 배지 3개를 정확히 네 칸에 노출한다.
- 비어 있는 칸은 빈 슬롯으로 유지한다.
- 대표 배지를 전시 목록에 중복 노출하지 않는다.
- 데스크톱 사이드바와 모바일 참여 카드가 같은 데이터를 사용한다.

### 관리자

- 회원 목록에서 회원별 현재 보유 배지와 대표 배지를 확인한다.
- 56종 전체를 등급별로 펼쳐 직접 해금/회수하고 저장한다.
- 골드·플래티넘 조건 충족 회원은 승인 후보로 표시한다.
- 관리자 본인에게는 모든 배지를 사용 가능 상태로 보여준다.

## 디자인

선택된 `B · 시그니처 크레스트`를 적용한다. 공통 다면체 크레스트 형태를 쓰되 등급별 재질, 테두리, 깊이와 광택을 강화한다.

- BRONZE: 묵직한 동합금
- SILVER: 밝고 차가운 은금속
- GOLD: 깊은 황금과 따뜻한 하이라이트
- PLATINUM: 정참시 청록 보석과 희소 광휘
- BLACK: 흑요석 표면, 금빛 각인과 제한적인 광륜

애니메이션은 반복하지 않으며 호버/선택 순간에만 미세하게 반응하고 `prefers-reduced-motion`을 존중한다.

## API와 보안

- `GET user/badges`: 로그인 사용자의 판정 결과, 진행도, 보유·대표·전시 상태 반환
- `POST action`의 배지 대표/전시 액션: 서버에서 보유 여부와 1+3 제한 검증
- `GET admin/badges`: 전체 현황 및 승인 후보 반환
- `PATCH admin/users`: 관리자 인증 후 회원별 직접 해금/회수 저장
- 일반 사용자는 다른 회원의 배지 상태를 수정할 수 없다.
