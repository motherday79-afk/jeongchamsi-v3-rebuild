# 정치인별 24시간 심층 분석 — 승인 명세

사용자가 승인한 범위: 상세 상단 목록으로·즐겨찾기·비교하기 옆 갱신하기 추가. 기존 하단 갱신 유지. 포인트 갱신 성공과 동시에 구매 회원에게 대상 정치인의 관리자 수준 진단 01~10 및 전략 처방을 24시간 개방한다. 해당 기간 관리자 재게시 후 최신 자료도 열람할 수 있으며 종료 시각은 바뀌지 않는다. 열람권이 유효한 2~4명은 관리자 수준으로 비교하며, 미개방/만료 인물이 섞이면 개방 안내를 표시한다. 재열람과 비교는 추가 차감하지 않는다. 자료 수정·게시·사진 편집 등 관리자 작업은 관리자에게만 허용한다.

권한은 회원 ID와 정치인 ID를 함께 기준으로 저장하며 공개 스냅샷과 분리한다. 결제 차감·게시·열람권 부여는 동일한 저장 트랜잭션에서 성공하거나 실패한다. 서버가 현재 시간으로 모든 상세/비교 요청의 권한을 검증한다. 만료 직전 응답과 화면 복귀/뒤로가기를 포함해 오래된 화면으로 권한이 연장되지 않도록 한다.

구현 결정: 기존 175/176 갱신 거래는 소급 개방하지 않는다. 177부터 성공하는 갱신에 적용한다. 유효기간 중 단순 열람/비교는 무료이며, 사용자가 다시 명시적으로 유료 수집을 확인한 경우에만 새로 차감하고 성공 시점부터 24시간을 다시 부여한다. 실패한 재갱신은 기존 열람권에 영향을 주지 않는다. 갱신 기능을 관리자가 꺼도 이미 구매한 열람권은 만료까지 유지한다. 쿨다운은 기존 수집 정책을 유지한다.
