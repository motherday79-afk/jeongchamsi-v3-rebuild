# Poll automation and Android completion push implementation plan

**Goal:** Publish newly verified presidential approval surveys on Monday/Thursday/Friday 17:00 KST and notify the opted-in administrator after poll or NOW Rank publication.
**Architecture:** Keep current Redis and authenticated gateway. Add original-document extraction to the poll collector, semantic change detection and a durable notification outbox. Reuse Firebase project jeongchamsi-v3 and existing Android package. Preserve the existing native intro/back navigation and GitHub signing secrets.
**Spec:** User approvals in this conversation: implement/deploy both automation and Android push, deliver APK; user handles visual acceptance.

## Constraints
- Do not invent unavailable survey values or replace complete data with incomplete revisions.
- Preserve historic AI/HUMAN comparisons; current human survey display must reflect the collector.
- Push only to opted-in active administrators; authenticate registration; no public topic subscription.
- No completed notification on collection failure or unchanged content. Retry transport failure without duplicate visible notification.
- Preserve Android package/signature when secrets exist; do not put server credentials in APK/source/logs.

## Tasks
- [ ] Original report PDF/ZIP extraction with bounded fetches and provider-specific, fixture-tested validation; update schedule.
- [ ] Poll semantic change tests, same-period merge, public latest display, atomic completion event.
- [ ] Firebase sender, admin device registration and notification outbox; tests for unauthorized access, opt-out, duplicate and failed delivery.
- [ ] Hook NOW Rank final publication; poll completion hook; retain failed notifications for retry.
- [ ] Android FCM receiver, notification permission/toggle, trusted navigation and deep links. Build through existing GitHub Actions.
- [ ] Essential regression tests, production deploy, initial collection, APK artifact delivery. User performs visual/phone acceptance.

## Review focus
Incomplete or incompatible survey tables; transient FCM failure after data commit; logout/admin role removal; token refresh; duplicate cron/queue deliveries.

## Execution ledger
- Existing Android source is on android-minimal-webview, no FCM SDK currently. Firebase project already contains matching com.jeongchamsi.preview app; FCM HTTP v1 enabled.
- Existing source collector only reads HTML/news summaries. Existing published comparison uses stored polls; current collection must be shown independently so historic comparison is not silently rewritten.
