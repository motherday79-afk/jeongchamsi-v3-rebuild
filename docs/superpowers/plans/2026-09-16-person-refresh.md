# 인물별 수집·포인트 갱신 구현 계획 및 실행 기록

승인: 지정 검색어를 전북 박지원 한 명에게 적용하고, 한 명만 수집·게시하는 기능 및 기존 포인트를 사용하는 회원 갱신을 구현하라는 사용자 요청.
기준: JCS_0_0_31_174, 현재 작업 폴더 유지. 별도 Git 재체크아웃·운영 배포 없음.

- [x] 인물 ID별 수집 프로필: 지정 검색어 검증, 기본 pilot, 서버 저장 및 관리자 편집.
- [x] 수집: 네이버 정확 일치 키워드만 집계, 미확인 보존, 뉴스 이름+지역 필터와 중복 제거, 수집 범위별 이력 분리.
- [x] 개별 처리: 대상만 수집/검증, 결과 미리보기, 현재 공개된 다른 인물 자료를 이용한 전체 순위 재계산.
- [x] 원자적 게시: 자료/순위/포인트를 CAS로 반영, 게시 세대와 수집본 검증, 전체 게시 경합 방지.
- [x] 회원 포인트: 기존 지갑 사용, 관리자 이용료/간격 설정, 기본 비활성, 성공 시 차감, 요청별 멱등성, 실패 복구.
- [x] 화면/API: 관리자 검색어·결과 확인·설정, 회원 비용 확인 및 상태 복구, 포인트 사용 내역 표시, 기존 분석 권한 유지.
- [x] 검증: 테스트에서 먼저 지정 검색어·지역 필터·이력 분리·순위 미갱신·실패 처리·중복 차감 문제를 재현한 뒤 구현. 별도 검토에서 발견한 동시 게시와 UI 경합을 수정하고 회귀 검사.
- [x] 전달: 174 기준 패치와 전체본 ZIP, 바이트 대조 및 배포 파일 구성 확인.
