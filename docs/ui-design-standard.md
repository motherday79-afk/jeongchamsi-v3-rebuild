# 정참시 UI·UX 제작 기준

새 메뉴는 기능 구현에 앞서 기존 메인과의 시각적 통일성, 사용자 동선, 읽기 쉬운 크기를 기준으로 설계한다. 개발 도구처럼 보이는 정보 나열은 피한다.

- 메인 콘텐츠는 기존 보라색 브랜드, 카드 여백·모서리·버튼 표현을 따른다.
- 배너는 일러스트와 짧은 제목, 명확한 한 가지 행동을 중심으로 구성한다. 텍스트가 배경에 묻히지 않아야 한다.
- 목록은 여러 항목을 빠르게 탐색하는 공간이다. 한두 회차가 전체 화면을 채우는 큰 카드 대신 작은 표지와 제목을 사용한다.
- 정치4컷은 설명 카드 네 장이 아니라, 말풍선과 내레이션을 원화 안에 담은 하나의 완성 만화다. 설명문을 컷 아래에 반복하지 않는다.
- 출처와 접근성용 대본은 펼쳐 읽는 보조 정보로 제공한다. 그림 안의 글자도 모바일에서 읽을 수 있어야 한다.
- PC·모바일 모두 검토하되 최종 디자인 확인과 검수는 사용자가 진행한다.
