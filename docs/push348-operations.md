# 관리자 갱신 알림

- 한국갤럽/리얼미터/NBS 최신 공개 데이터의 내용을 전후 비교한다. 수집 시각 변경만으로는 업데이트로 알리지 않는다.
- 한 기관은 기관명, 두 기관은 두 이름, 세 기관은 `전체 여론조사 데이터가 업데이트되었습니다.` 하나로 알린다.
- 나우랭크 게시 완료는 `나우랭크 데이터가 업데이트되었습니다.`로 알린다.
- 정상 수집에 새 자료가 없으면 하루 한 번 확인 완료를 알린다.
- 여론조사 부분 실패는 실패 기관명을 표시하고 해당 기관의 이전 자료를 유지한다. 정상 기관의 데이터 변경은 별도 완료 알림으로 표시한다.
- 수집 복구는 업데이트 여부와 구분한다. 예외 원문/토큰/내부 주소는 푸시에 담지 않는다.
- 실패·일부 실패는 작업 종료 후 보낸다. 예약 누락은 별도 `/api/update-watchdog-cron` 작업이 매일 18:15 KST 예약으로 확인한다. Hobby 요금제의 최대 한 시간 실행 여유가 있으므로 실제 감시는 18:15~19:15에 이루어질 수 있다.
- 나우랭크는 당일 실행 기록/15분 정체/종료 실패를 확인한다. 여론조사는 월·목·금 당일 17시 이후 확인 기록과 기관 상태를 확인한다.
- 같은 대상/날짜/실패 종류는 장치별 한 번 알린다. FCM 전송 실패는 기존 큐의 재시도 대상이다. 별도 감시는 누락된 완료·실패 알림도 다시 전달한다.
- 관리자 로그인 및 앱 알림 동의가 필요하며, 관리자 자격은 발송 직전 다시 검사한다. 기존 APK와 같은 payload 형식이므로 APK 교체는 필요 없다.
- Vercel 또는 Redis/FCM 전체 장애 시 동일 인프라를 이용하는 알림도 지연될 수 있다. 단말 수신은 실제 기기에서 확인한다.

검증: 기관별 변경/문구, 날짜·시간 경계, 부분 실패, 권한, 중복 및 전송 재시도, 기존 수집·스케줄 회귀 테스트.
