# JCS_0_0_31_181 — JCS AI PANEL

## 화면 구성
- 메인: NOW 순위 바로 아래, 전국 평가제 위에 HUMAN ↔ AI 요약 카드와 상세보기만 추가했습니다. 기존 상단 메뉴·사이드바와 퍼플·골드 디자인은 유지합니다.
- 공개 상세: `/ai-panel`. 전체 비교, AI 패널, 과거 조사, 응답 이유, 조사 방법을 상세 안에서 이동합니다.
- AI 번호: AI 패널에서 `1000` 또는 `JCS-AI-1000`을 검색하면 해당 합성 ID의 프로필·이번 응답·과거 회차별 응답 사유를 확인할 수 있습니다. 실제 사람의 정보가 아닙니다.
- 관리자: 기존 관리자 메뉴의 **AI 패널 관리** → `/admin/ai-panel`. 활성 관리자만 접근합니다.

## 처음 사용하는 순서
1. 관리자 → AI 패널 관리 → 패널 버전 관리에서 패널 이름과 실제 인구자료 출처·기준일을 입력합니다.
2. 프로필 JSON을 입력하거나 파일로 불러옵니다. 정식 패널은 JCS-AI-0001~JCS-AI-1000의 1,000개 ID가 필요합니다. 필수 항목은 ID, 성별, 연령대, 지역, 정치관심도, 여론조사 노출 여부입니다. 선택 평가축 비중을 입력하면 합계는 100이어야 합니다.
3. 조사 회차 관리에서 주차(예: 2026-W38), 기준일, 질문, 질문 버전, 저장한 패널과 EXPOSED/BLIND 모드를 선택합니다.
4. 모드별 정보환경과 출처를 저장합니다. BLIND 출처에는 여론조사 수치가 포함되어서는 안 됩니다. 정보환경을 다시 저장하면 해당 모드의 이전 응답과 검수가 초기화됩니다.
5. HUMAN 조사를 기관별로 입력합니다. 원문 URL·질문·기관 식별자를 남기고, 자료에 없는 수치와 N은 빈칸으로 둡니다. 전체 및 하위집단 값을 임의로 채우거나 기관별 결과를 평균하지 않습니다. 질문 비교 적합성을 직접 확인합니다.
6. 외부에서 실행한 AI 응답을 JSON으로 입력합니다. 각 ID마다 5단계 응답 중 하나, 이유, 설명 등을 기록하고 모델 버전과 실행일시를 함께 저장합니다. 실행일시는 입력 기기의 시간대로 해석합니다. 출처 JSON의 publishedAt은 시간대를 포함한 ISO 일시입니다.
7. 응답 수·출처·모델·질문을 검수하고 **검수 완료 → AI 응답 LOCK → 공개 게시** 순서로 진행합니다.

입력 양식 다운로드는 JSON 구조 예시입니다. 실제 자료를 채워 넣어야 합니다. 10개/100개 DEV 샘플 버튼은 개발 확인용이며 공개할 수 없습니다. 운영 화면에는 실제 검수·LOCK·게시된 정식 자료만 나옵니다.

## 잠금과 재실행
LOCK 이후 AI 응답·정보환경·패널 스냅샷은 변경할 수 없습니다. HUMAN 원자료 추가는 가능하지만 잠금된 AI 데이터는 그대로 유지합니다. 잠금 전 HUMAN 자료를 추가하면 재검수가 필요합니다. 같은 주차에서 다시 실행하려면 기존 회차의 재실행 메뉴에서 사유를 적고 새 RUN을 만듭니다. 이전 기록은 남습니다. 동시 저장 충돌이 나면 입력 내용을 복사한 뒤 최신 자료를 다시 읽어야 합니다.

## 계산과 저장 구조
- GAP = AI 비율 − 해당 HUMAN 기관 비율, 단위 %P. 예: 45% − 40% = +5%P. 미제공 수치·비교 미확인 자료는 GAP을 계산하지 않습니다.
- AI는 응답 건수를 전체/성별/연령/지역별로 집계합니다. 실제 인간 표본조사와 같은 오차로 해석하지 않습니다.
- Redis `jcsr2:ai-panel:v1:*` 아래에 불변 패널 버전, 회차, 목록 색인, 주차별 RUN 번호를 별도로 누적 저장합니다. 기존 회원·포인트·모임 데이터와 분리됩니다.
- `/api/v3/ai-panel`: 공개 목록/회차/ID 이력 GET, 관리자 목록·패널·편집 GET, 관리자 저장 POST. 공개 읽기는 로그인한 관리자라도 별도의 편집 요청을 하지 않으면 미공개 자료를 반환하지 않습니다.
- ID 이력은 한 번에 20회차, 화면 ID 목록은 50개씩 표시합니다.

## 검증 범위와 아직 연결하지 않은 기능
기존 테스트와 새 기능 테스트, 배포 서버 파일 추적 검증을 실행합니다. 결과는 `verification/ai-panel-181/tests.txt`를 기준으로 확인합니다. 브라우저 검증은 운영 저장소와 분리한 로컬 가상 자료로 진행했습니다. 메인 배치, 상세 이동, AI 1000번 검색·현재/과거 응답 일치, 관리자 샘플 생성, 소수 퍼센트와 빈 표본오차 저장을 확인했습니다.

실제 AI API 자동 실행·유료 호출·자동 뉴스/여론조사 수집은 이번 1차 범위에 연결하지 않았습니다. 운영용 인구 프로필과 실제 조사 결과를 생성하거나 게시하지 않았으며 첫 정식 자료를 입력하기 전 공개 화면은 준비 중 상태입니다. 전체 기존 화면의 수동 시각 검증을 모두 마쳤다는 의미는 아닙니다.
