# JCS 0.0.31.183

## JCS AI PANEL 관리자 운영화

- 관리자 AI PANEL을 개발자 콘솔형 화면에서 주간 운영형 5단계 화면으로 단순화했습니다.
  1. 조사 시작
  2. HUMAN 여론조사 등록
  3. AI 참고자료 등록
  4. AI 응답 JSON 파일 등록
  5. 결과 확정 및 게시
- `2026-W38` 형태의 주차는 기준일로 자동 계산합니다.
- AI 응답 JSON은 원문 붙여넣기 대신 파일 선택을 기본 흐름으로 변경했습니다.
- 출처 JSON은 일반 제목/URL 입력으로 대체하고 원문 JSON은 고급설정으로 이동했습니다.
- 검수 → LOCK → 게시를 `결과 확정 및 게시` 한 버튼으로 처리합니다. 기존 서버의 검수/LOCK/감사 이력은 그대로 유지합니다.
- 패널 버전/BLIND/원문 JSON/수동 단계는 `고급설정`으로 이동했습니다.

## HUMAN 수집 UX

- 갤럽·리얼미터 자동수집 상태를 기관별 카드로 표시합니다.
- 자동수집 실패 시 해당 주 조사 전체가 막히지 않도록 HUMAN 직접입력 경로를 명확히 노출합니다.
- 갤럽·리얼미터 자동수집 성공 시 기존처럼 수집된 자료를 선택해 입력폼에 불러올 수 있습니다.

## 리얼미터 수집기 보강

- HTTP/HTTPS 및 `www`/비-`www` 공식 도메인 변형을 허용합니다.
- RSS 본문/description 변형을 허용하고, 개별 RSS 항목 하나가 깨져도 나머지 항목 파싱을 계속합니다.
- 리얼미터 문장·메타데이터 정규식의 형식 의존도를 완화했습니다.
- RSS 실패 시 공식 홈페이지 탐색으로 폴백하는 기존 구조를 유지합니다.
- 브라우저 호환 User-Agent 및 RSS/XML Accept 헤더를 적용했습니다.
