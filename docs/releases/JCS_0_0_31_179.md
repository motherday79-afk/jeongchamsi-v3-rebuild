# JCS 0.0.31.179 — 모임 게시판 화면 정리

178 전체 버전에 적용하는 누적 수정입니다.

## 사용 방법

- 모임 상세 상단의 **모임 목록으로**를 누르면 메인을 거치지 않고 모임 목록으로 이동합니다.
- **글** 탭은 공지 우선 목록입니다. 제목을 눌러 내용을 확인하고 **글쓰기**로 작성창을 엽니다.
- **갤러리** 탭은 사진 중심 목록입니다. 사진을 눌러 내용을 확인하고 **사진 올리기**에서 사진과 설명을 등록합니다.
- **일정** 탭은 날짜순 목록입니다. 등록 권한이 있는 운영자는 **일정 등록**에서 일정명, 시작·종료 일시, 장소, 설명을 입력합니다. 종료 일시는 선택 항목입니다.
- 기존 모임별 가입·작성·운영 권한, 예시 모임 읽기 전용, 활동 포인트 규칙을 유지합니다.
- 대표이미지는 모임 생성 후 **설정**에서 등록합니다. 권장 **1200 × 400px**, JPG·PNG·WebP, 최대 **2MB**. 권장 크기와 다른 이미지도 등록할 수 있으며, 화면에 따라 가장자리가 잘릴 수 있어 중요한 내용은 중앙 배치를 권장합니다.

## 설치

- 178 버전 사용 중: `JCS_0_0_31_179_PATCH.zip`을 풀어 동일 경로에 덮어쓰기.
- 전체 교체: `JCS_0_0_31_179.zip`만 사용.
- 실제 배포와 운영 데이터 변경은 수행하지 않았습니다.

## 검증

최종 검사 결과는 `verification/groups-ui-179/`에 포함합니다. 자동 검사는 화면 구조·동작과 서버 권한/저장 회귀를 확인하며, 실제 브라우저의 시각 검수를 대신하지 않습니다. 이 환경에서는 실제 브라우저 화면 검수를 수행하지 않았습니다.

최종 자동 검사: 473/473 통과, 실패·건너뜀 없음.
