# JCS 0.0.31.182 — HUMAN 자동 수집

## 반영 내용
- 한국갤럽·리얼미터 공식 주간 보고서의 대통령 직무수행 평가를 자동 수집합니다.
- 한 번 실행할 때 기관별 최근 4건을 확인합니다. 동일 출처는 중복 저장하지 않으며 최근 104건을 보관합니다.
- 전체 긍정·부정·유보, 조사 기간·발표일·표본수·방법·응답률·표본오차와 원문 링크를 저장합니다.
- 세부집단은 원문 본문에 명시된 값만 수집합니다. 갤럽의 이미지/PDF 속 세부표와 본문에 없는 값은 추정하지 않습니다.
- 본문에서 가져오는 질문은 조사 주제 요약이며 질문지 원문이 아닙니다. AI와 비교할 때 원문·척도·기간 확인은 유지합니다.
- AI 결과가 없어도 메인·상세에 기관별 최신 HUMAN 수치를 보여줍니다. 기존 AI 회차에는 최신 수치를 임의로 끼워 넣지 않습니다.
- 관리자 → AI 패널 관리 → HUMAN 자동 수집에서 최근 확인 결과와 최신 조사 가져오기를 사용할 수 있습니다. 조사 회차에서는 수집된 조사를 선택하면 수치가 채워집니다.
- 실패·누락·중복 실행에는 기존 정상 기록을 유지합니다. 수집 요청과 출처를 검증하고 시간·용량을 제한합니다.

## 정기 실행
Vercel Production 환경에 CRON_SECRET을 등록합니다. 매일 한국 시간 오후 5시를 기준으로 하루 한 번 실행합니다. 현재 Hobby 요금제는 실제 실행이 오후 5시~5시59분 사이에 이뤄질 수 있습니다.
- https://vercel.com/docs/cron-jobs/usage-and-pricing
- https://vercel.com/docs/cron-jobs/manage-cron-jobs
인증키는 ZIP이나 소스에 포함하지 않습니다. 관리자 수집은 기존 로그인으로 실행합니다.

## 검증 범위
실제 자동 요청으로 두 기관 각 4건, 총 8건을 수집하고 최신 원문 수치와 대조했습니다. 운영 배포와 실행 결과는 별도 배포확인 문서에 기록합니다.
이번 버전은 HUMAN 수집입니다. AI 1,000개 응답을 모델 API로 자동 생성하는 기능은 포함하지 않습니다.
