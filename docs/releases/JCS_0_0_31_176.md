# JCS_0_0_31_176

175 버전의 관리자 개별 갱신 설정 카드 가독성 수정입니다.

- 흰색 카드가 어두운 관리자 영역의 밝은 글자색을 물려받던 문제를 수정했습니다.
- 제목·항목명·입력값을 짙은 보라색으로, 설명·입력 안내를 읽기 쉬운 회보라색으로 지정했습니다.
- 활성화 체크박스와 설명을 같은 줄에 배치했습니다.
- 변경된 CSS와 버전 표시를 다시 가져오도록 캐시 버전을 갱신했습니다.

## 적용

175 버전에는 PATCH ZIP을 프로젝트 루트에 덮어쓴 뒤 기존 배포 절차로 반영합니다.
전체 ZIP에는 기존 기능과 이번 수정이 모두 포함되어 있습니다. 두 ZIP을 함께 적용할 필요는 없습니다.

## 확인 범위

CSS 색상 상속 원인을 확인하고, 색상 대비 계산과 기존 개별 갱신 UI·API 검사를 수행했습니다.
175 전체 파일에 패치를 합친 결과가 176 전체 ZIP과 일치하는지 검증했습니다.
실제 브라우저 렌더링과 운영 배포는 수행하지 않았습니다.
