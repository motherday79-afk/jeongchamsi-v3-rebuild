# JCS_0_0_31_177

## 이번 변경

- 정치인 상세 상단의 목록으로·즐겨찾기·비교하기 옆에 갱신하기를 추가했습니다. 기존 하단 갱신도 유지합니다.
- 회원이 포인트 갱신을 완료하면 해당 정치인의 진단 01~10과 전략 처방을 24시간 열람합니다.
- 수집·게시 성공, 포인트 차감, 열람권 부여를 함께 저장합니다. 실패 시 차감하거나 열람권을 새로 만들지 않습니다.
- 구매한 회원과 정치인별로 이용권을 저장합니다. 관리자 전체 재게시·개별 갱신 후에도 기존 종료 시각을 유지하고 최신 분석을 제공합니다.
- 열람권이 유효한 2~4명의 심층 비교에는 추가 포인트를 받지 않습니다. 미개방·만료 인물이 포함된 심층 비교는 개방 안내를 표시합니다.
- 실제 관리자 계정만 사진 편집·수집 설정·게시 등 운영 작업을 수행할 수 있습니다.

## 관리자 설정

관리자 → 데이터 수집 → 회원의 정치인 개별 갱신에서 활성화, 이용료, 재갱신 간격을 저장합니다. 기존 설정과 보유 포인트는 유지됩니다.

## 회원 이용 순서

1. 일반 회원으로 로그인하고 원하는 정치인 상세페이지로 이동합니다.
2. 상단 갱신하기 또는 하단 포인트 갱신에서 이용료와 24시간 제공 내용을 확인합니다.
3. 포인트 사용을 확인하면 수집과 게시를 진행합니다. 성공하면 심층 분석으로 전환됩니다.
4. 표시된 열람 종료 시각까지 다시 방문해 무료로 열람합니다.
5. 다른 정치인도 개방한 뒤 비교하기에서 최대 4명까지 선택합니다. 선택한 전원의 이용권이 유효해야 심층 비교가 열립니다.

단순 재열람·비교에는 추가 차감이 없습니다. 유효기간 중에도 별도로 새 유료 수집을 요청하면 이용료를 다시 확인하고, 성공 시점부터 24시간이 다시 부여됩니다. 재수집에 실패하면 기존 이용권을 그대로 유지합니다. 갱신 판매를 비활성화해도 이미 구매한 이용권은 종료 시각까지 유효합니다.

이용권 부여는 177 적용 후 성공한 유료 갱신부터 적용되며, 175/176의 과거 갱신 내역은 소급 개방하지 않습니다.

## 파일 적용

- 현재 176 버전이면 PATCH ZIP의 파일을 프로젝트 루트에 덮어쓰고 기존 절차로 배포합니다.
- 전체 ZIP에는 이번 변경과 기존 기능이 모두 포함됩니다. 전체 교체 시 전체 ZIP만 사용합니다.
- 운영 서비스 배포·실제 수집·실제 포인트 차감은 이 작업에서 수행하지 않았습니다.

## 검증 결과

- 전체 자동 검사422건 통과. 배포 파일 추적으로 실제 서버 패키지 로딩도 확인했습니다.
- 회원·인물별 권한 격리, 정확한 만료 경계, 실패 시 미차감, 중복 요청, 관리자 재게시 후 유지,2~4명 비교, 브라우저 복귀 시 재확인과 동일 화면 재시도를 검증했습니다.
- 백엔드·비교·최종 통합 검토를 완료했으며 남은 중요 지적 사항은 없습니다.
- 실제 브라우저 렌더링·보조공학 기기 검증은 수행하지 않았습니다.
