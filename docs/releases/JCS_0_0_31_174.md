# JCS_0_0_31_174 — 관리자 NOW 순위 반영 비율

기준 버전: JCS_0_0_31_173

## 사용 방법

1. 관리자 → 데이터수집·게시 → NOW 순위 반영 비율로 이동합니다.
2. 뉴스·검색 비율을 선택합니다. 뉴스 50%·검색 50%, 60%·40%, 70%·30%를 포함하여 0~100%를 10% 단위로 선택할 수 있습니다.
3. ‘비율 저장’을 누릅니다. 기본값은 기존과 같은 뉴스 60%·검색 40%입니다.
4. ‘전체 게시’를 누르면 현재 수집 완료·검증 통과된 자료로 순위를 다시 계산합니다. 비율 변경만을 위해 재수집할 필요는 없습니다. 처음 사용하는 경우에는 자료 수집이 먼저 필요합니다.

## 동작

- 수집량 비율이 아니라 NOW 점수 계산 비율입니다. 뉴스 비중은 기사 수·매체 수·최신성에 동일하게 나누어 적용합니다.
- 현재 공개 비율, 다음 게시 비율, 게시 진행 중인 비율을 구분해 표시합니다.
- 저장만으로 공개 순위가 바뀌지 않습니다. 저장된 비율은 다음 미리보기와 새로 시작하는 전체 게시에 적용됩니다.
- 게시 시작 시 사용 비율을 기록하며, 처리 도중 설정을 변경하거나 중단 후 재개해도 진행 중인 게시의 비율은 유지합니다. 이전 버전에서 시작한 게시 작업은 기존 60:40을 유지합니다.
- 비율 변경으로 발생한 순위 이동은 급상승으로 집계하지 않습니다. 같은 비율로 계산된 다음 수집·게시 결과부터 다시 비교합니다.
- 0%로 설정된 항목은 동점 순서 결정에도 영향을 주지 않습니다.
- 관리자 권한을 서버에서 확인하고, 저장한 관리자·시각·뉴스와 검색의 비율을 기록합니다. 비율 합계가 100%가 아니거나 허용되지 않은 값은 저장하지 않습니다.
- 저장 중 중복 요청·미저장 상태의 게시를 방지하고, 수집·게시 완료에 따른 화면 갱신 중에도 저장 상태를 유지합니다.
- 뉴스·검색 원자료, 상세 진단 1~10번의 개별 계산식, 기존 이미지와 디자인 파일은 유지합니다. 새로운 외부 API나 환경변수는 필요하지 않습니다.

## 파일 적용

- 173 사용 중: `JCS_0_0_31_174_PATCH.zip`을 풀어 프로젝트 루트에 덮어쓴 뒤 기존 절차로 배포합니다.
- 전체 교체 또는 172 이하 사용 중: `JCS_0_0_31_174.zip`을 사용합니다. 전체 소스에는 같은 174 패치를 추가로 적용하지 않습니다.
- 전체 소스에는 앞서 반영한 모임 메뉴·추천 모임·마이페이지 호칭과 캠페인 가로폭 수정이 모두 포함됩니다.
- 운영 배포 및 실제 운영 데이터 변경은 수행하지 않았습니다.

## 검증

- 자동 검사 362개 통과, 실패·건너뜀 0개. 신규 비율 기능 검사 16개 포함.
- 실제 클라이언트 요청 형식, 서버 관리자 권한·감사 기록, 설정 영속성·입력 검증, 게시 시작 비율 고정·재개·재게시, 화면 갱신 도중 저장 처리 검증.
- 통제된 543개 검증용 자료에서 기본 60:40의 점수·전체 순위·분류별 순위가 173과 정확히 일치합니다.
- 검토에서 발견한 저장 중 화면 갱신 문제와 진행 중 비율 표시 문제를 수정했고, 재검토에서 남은 차단 사항은 없습니다.
- 브라우저의 로컬 URL 접근 제한으로 실제 PC·모바일 화면 검증은 수행하지 못했습니다. 화면 렌더 함수·상호작용과 반응형 CSS를 소스 기준으로 확인했습니다.
