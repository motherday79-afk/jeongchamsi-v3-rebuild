# 하비와 할비 · 왼쪽 배너 90초 순환

왼쪽 메인 배너에 「하비와 할비」를 등록했다. 첫 노출은 신규 영화 배너이며 기존 왼쪽 배너와 90초마다 순환한다. 오른쪽 배너의 60초 간격은 유지한다. 하비와 할비는 링크·클릭 동작 없는 이미지 전용 슬라이드다.

PC 832×135, 모바일 720×300, 폴드 펼침/태블릿 1200×300 슬롯에 맞춰 준비했다. 이미지는 `assets/banners/habi-halbi-{pc,mobile,tablet}-356.webp`에 저장한다.

제작은 내장 image_gen으로 첨부 포스터를 재구성했다. 프롬프트 핵심: 카메라를 든 하비와 은발의 할비, 화성의 노을·바닷가·갈대, 원본의 따뜻한 애니메이션 색감. 제목 「하비와 할비」, “가까이 다가가면 보인다.”, “2027년 8월, 화성에서 만납니다”를 가로형 광고의 중심으로 배치. 작은 제작비·줄거리 문단은 가로 배너 가독성을 위해 생략. 링크나 버튼은 넣지 않음.

관리자의 왼쪽 배너 업로드도 기존 이미지를 지우지 않고 순환 목록에 추가한다. 링크 입력은 선택 사항이다. 두 영역은 서로 다른 저장 키와 독립 타이머를 사용한다. 화면 검수는 사용자가 진행한다.
