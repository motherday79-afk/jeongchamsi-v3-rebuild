# 정치4컷 제작·게시

- 메인: 여론조사와 칼럼 사이에 최신 공개 회차를 표시합니다.
- 회차 목록: `/political-comic`, 상세: `/political-comic/{id}`.
- 최고관리자: `/admin/political-comic`. 새 회차 등록, 수정, 비공개 전환이 가능합니다.
- 원화: 동일 크기의 그림 4개를 여백 없이 2×2로 합친 이미지 한 장. 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순서입니다. 권장 1536×1536px, JPG/PNG/WebP, 업로드 최대 1MB입니다. WebP를 권장합니다.
- 말풍선과 짧은 내레이션이 포함된 완성 만화 원고를 등록합니다. PC는 2×2, 모바일은 끊김 없는 세로 만화로 보여줍니다. 따로 입력하는 장면 제목·설명은 접근성용 대본이며 접힌 텍스트 읽기에만 표시합니다.
- 출처: `자료 이름 | https://원문주소`를 한 줄씩 입력합니다. 사건의 기준일, 확인된 사실, 추가 확인이 필요한 사항을 구분합니다.
- 공개를 체크하고 저장하면 메인 최신 회차와 목록에 반영됩니다. 이전 회차도 목록에 남습니다.
- 기존 회차를 비공개로 저장하면 메인과 공개 목록에서 빠집니다. 충돌 감지로 다른 편집 내용을 덮어쓰지 않습니다.

## 첫 회차

2026년 9월 DMZ 지뢰 사건. 9월 30일 공개 자료 기준. 실제 인물·현장을 재현한 사진이 아닌 AI 생성 설명용 삽화입니다. 원본 4컷을 한 번 내려받아 각 장면에 사용하고, 이미지 파일은 WebP로 압축했습니다.

## 저장

기존 저장소 연결을 이용하는 `jcsr2:political-comics:v1` 키입니다. 초기 데이터가 없을 때 첫 회차를 제공하며, 최초 수정부터 저장된 회차 목록을 사용합니다. 비공개 처리한 첫 회차를 다시 자동 생성하지 않습니다. 공개 API는 공개 회차만 반환하고 작성·업로드·비공개 조회는 최고관리자에게만 허용합니다.

## 완성 원고 관리자 (370)
게시 정보, 완성 원고, 선택 표지, 출처·공개 설정 순서로 입력합니다. 컷별 필수 입력은 제거했습니다. 전체 대본은 선택 사항이며 접힌 텍스트 읽기에 표시됩니다. 표지를 등록하면 메인과 회차 목록에 사용하고, 생략하면 원고를 표지로 사용합니다. 상세페이지는 항상 원고를 표시합니다. 원고 업로드 시 정사각형인지 확인합니다.

## 간결한 노출 (372)
메인은 최신 회차 이미지 최대 3개와 전체 회차 링크만 표시합니다. 회차 목록은 이미지·에피소드 번호·날짜·한 줄 제목, 열람 화면은 에피소드 번호·제목·날짜·만화만 표시합니다. 관리자 필수 입력은 제목·날짜·원고이며 회차 번호는 자동 부여합니다. 출처·분류·대본 등 기존 보조 정보는 더 이상 입력하거나 공개하지 않습니다.

## 회차 추가 (373)
2026-10-01 검찰 개편, 추경호 재판의 구형, 주택담보대출 금리 편을 추가했습니다. DMZ와 동일한 1254×1254 완성 만화이며 각 원고는 1MB 미만 WebP입니다. 가상의 설명 인물이 등장하며 실제 취재 장면의 기록 사진이 아닙니다. 확인한 자료는 seed의 sources에 보관합니다.

검찰 개편은 10월 2일 출범 예정으로, 구형은 판결과 구별하여 표현했습니다. 주담대는 한국은행 2026년 8월 신규취급액 기준 평균 금리를 다루며 개인 대출 조건과 구별합니다. 새 seed 회차만 보충하므로 관리자가 변경한 제목·원고·비공개 설정은 유지됩니다. 기존 회차 번호와 중복되지 않도록 다음 번호부터 부여하며, 관리자 저장 시 함께 영속화됩니다.
