# 게시물 조회수: 열람 단위 집계

적용: 자유게시판·케이지(community), 뉴스, 칼럼, 잇츠미의 기존 조회수.

- 새 문서 로드 또는 다른 경로를 방문한 뒤 게시글로 돌아오면 새 방문 ID 발급.
- 같은 글의 댓글·좋아요·케이지 진영 및 페이지 전환 등 내부 갱신은 동일 방문 유지.
- 비회원·작성자도 공개 게시글 열람을 집계. 비공개·없는 글은 제외.
- 같은 방문 ID의 중복 요청은 원자적 Redis Lua로 방지(10분 TTL). 영구 회원별 중복 방지 집합은 더 이상 사용하지 않음.
- 기존 원본 views와 누적 view-count 키를 그대로 보존.
- 게시판 경로의 브라우저 뒤로가기는 오래된 화면 복원 대신 재렌더하여 열람을 반영.

검증: 새 방문·재입장·새로고침·동일 방문 재렌더·비회원·작성자·숨김 글·중복 요청·기존 누적값 회귀 테스트. 사용자 화면 검수는 사용자 담당.

기존 광범위 테스트에서 별도 확인된 실패: badge-api는 삭제된 isActiveAcademySlot export를 여전히 import; navigation의 오래된 snapshot 테스트는 첫 cacheCurrent 호출 누락; stage1의 회원가입·관리권한 fixture는 현재 검증·저장 규칙과 불일치. 해당 기능 코드는 이번 변경 대상이 아님. 조회수 서버 테스트는 별도 파일로 분리하여 실행.
