# JCS 리얼택시 대화 출처와 편집 기준

확인일: 2026-10-08. 카탈로그: `lib/taxi-passengers.js`. 등록된 정치인 12명, 각 5개 카드, 총 60개. 등록 ID·이름·정당은 기존 `POLITICIAN_SEED.profiles`와 대조했다. 정당 표시는 사이트 등록 스냅샷이며 발언 당시 소속·직책 전체 이력을 뜻하지 않는다. 특히 박찬대는 현재 사이트의 `metropolitan-005`에 연결하지만 수록 발언은 2024년 국회의원 당시 연설이다.

모든 카드는 `type:'paraphrase'`다. 실제 발언·공약·발의안에 용어와 제안 범위를 이해하기 위한 설명을 더한 대화 재구성이며, 녹취나 직접 인용이 아니다. 470 업데이트에서 60개 대사를 약 30초~1분의 낭독 분량으로 확장했다. 새 개인 일화, 새 정책 수치, 정책 시행·효과에 관한 단정을 추가하지 않았다. 이름, 소속 정당, 본인 직책을 대사에서 제거했다. 정책 자체로 인물을 추측할 가능성까지 제거하지는 않는다. 출처 제목·맥락·등록 ID는 정체 공개 후에만 보여준다. 법안은 제안 내용이며 통과·시행 여부를 주장하지 않는다. 의견과 제안은 화자의 의견으로 표현하며 정책 효과가 입증되었다고 단정하지 않는다.

## 확인 방법과 한계

- 원문 페이지 또는 검색 도구가 반환한 해당 페이지의 본문을 읽어 수치·대상·제안자·시점을 대조했다. 단순 검색 결과 제목만으로 대사를 작성하지 않았다. 차단된 페이지는 접근 가능한 공식 게시물이나 언론 전재본으로 교체했다. 용혜인 2021년 의원실 페이지는 직접 열기에서 403이 발생했으나 검색 도구가 반환한 공식 보도자료 본문으로 검증했다. 동일 발표는 [기본소득당 공식 보도자료](https://www.basicincomeparty.kr/bikr/press/244?page=209)와도 교차 확인했다. 발표 날짜를 국회 접수 날짜라고 단정하지 않았다.
- 출처는 15개 고유 URL이다. 공식 정당·의원실 자료와 주요 언론의 발언 전문·직접 인터뷰·공약 및 발의 보도를 함께 사용했다. 모든 법안을 국회 원문 PDF와 개별 대조한 것은 아니다. 전문지가 보도한 전공의법 등의 경우 대표발의자와 제안 조항에 한정해 사용했다.
- 2021~2025년의 역사적 자료다. 현재 입장이나 현행법 설명이 아니며, 현재 법안 상태를 표시하지 않는다. 기사에 등장하는 다른 사람의 발언은 해당 승객의 발언으로 옮기지 않았다. 송언석 연설의 당 차원 법안은 본인의 대표발의로 바꾸지 않았다.
- 정당 분포는 국민의힘 4명, 더불어민주당 4명, 개혁신당 2명, 기본소득당 1명, 조국혁신당 1명이다. 의석·여론조사 비례 표본이나 정치성향 측정 표본은 아니다. 반복 탑승이나 반응을 정치 지지 점수로 해석하지 않는다.
- 긴 연설·인터뷰의 서로 다른 정책 항목을 여러 카드로 사용했다. 모든 카드를 서로 다른 발언 날짜·법안으로 구성한 것은 아니다. 법안의 상이한 조항도 독립된 카드로 사용하며, 동일 내용의 표현만 바꿔 채우지 않았다.
- 인물 사진은 모두 `null`이다. 검증되지 않은 이미지 URL이나 사진 사용권을 새로 주장하지 않는다.
- `tests/taxi-content.test.js`는 12명·60개·등록 일치·정당 다양성·날짜·링크 형태·익명 텍스트를 검사한다. 자동 검사는 내용의 진실성을 보증하지 않으며 위 출처 대조가 별도 근거다. 브라우저 플레이·화면 QA는 수행하지 않았다.
