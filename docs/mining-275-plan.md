# 광산 275 구현 기준

사용자가 2026-09-24 전체 화면 게임을 실제 사이트에 적용·배포하도록 승인함. 현재 작업 폴더와 기존 기능 유지. 단계별 재승인·반복 시각 검증 대신 필요한 오류 검사 후 사용자가 플레이 검증.

## 설계
- 독립 /mine 게임 화면: 모바일/PC 모두 전체 뷰포트. 홈페이지 기존 게임 자리 배너 연결. /polimable 제거 유지.
- 회원별 Redis 단일 소형 상태, 기존 포인트와 분리. 서버 시간·난수로 자동 3초, 수동 1.5초. 수동 입력 시 자동 기준 시각 갱신하여 중복 타격 방지.
- 기본 성공률 3%, 성공마다 1금. 강화 시 +2%p. 인부는 자동 간격 감소. 저장고 기본 10, 다음 저장고 단계는 곡괭이 또는 인부 5단계 단위 조건. 최초 골드 0.
- 성인 남성/성인 여성/귀여운 엘프 캐릭터 3종. 투명 타격 프레임과 광산 배경 분리. 이미지 제작은 imagegen 사용.
- 체험 곡괭이는 +12%p, 추가 타격 25%, 결제 없음. 기본 장비로 전환 가능. 첫 버전 체험 상태 명시.
- 꽉 찬 저장고만 회수. 원자적 회수 후 같은 탭 광고 URL 이동, 뒤로가기 시 서버 상태 재조회. 재시도/중복 요청은 한 번만 지급.
- 관리자 광고 제목/HTTPS URL 저장, 이동/고유회원/일별 30일 지표. 외부 URL 미설정 시 내부 테스트 안내. 광고 이동은 리다이렉트 응답 발행 기준, 도착 확인 아님.
- 광고 지표는 90일 TTL, 상태는 무기한 소형 저장. 관리자 테스트 채우기는 테스트 지표로 별도 취급하여 광고 통계 제외.

## 작업과 확인
1. 엔진: 시간 경계, 확률 경계, 풀 저장고, 강화 조건, 추가타격, 중복 회수 테스트를 먼저 작성 후 구현.
2. 저장 서비스: CAS로 회원 상태·광고 지표 원자적 변경. 인증/권한/URL/메서드 검사, 충돌 재시도. HTTP 경계 테스트.
3. 화면: 프레임 타격, 전체화면 배경, 회수·강화·캐릭터·관리자 패널, 재연결/뒤로가기/실패 안내.
4. 배너/리라이트 연동. 필수 테스트와 구문 검사, 최소 화면 확인, 커밋·기존 main 배포, 배포 버전 확인.
5. 274 기준 패치와 275 전체 ZIP 분리 생성. 실제 확인 범위 기록.
