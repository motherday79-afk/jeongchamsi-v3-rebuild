# 모임 공지 알림 (383)

- 별도 회원등급 없음. 승인된 모임의 모임장 및 최고관리자만 발송 가능.
- 기본 모임당 한국시간 하루 2회 / 달력 월 20회 / 최소 30분 간격. 모임장 교체 후에도 사용량 유지.
- 최고관리자가 각 모임의 공지 알림 탭에서 한도(일 1–20, 월 1–200)와 발송 중지를 설정.
- 요청 식별자와 모임/한도 데이터의 CAS로 재전송 및 동시 요청 중복 차감 방지.
- 수신 대상은 발송 시점의 승인된 알림 동의 회원. 처리 시점과 Android 표시 시점에 자격 재확인.
- 일반 회원의 기기 등록은 기존 운영자 갱신 알림 기기 저장소와 분리. 운영자 알림은 최고관리자 전용 유지.
- 본문은 서버에만 저장하고 FCM에는 이벤트 식별자와 제한된 내부 경로만 전달. 앱이 현재 로그인과 모임 권한으로 본문 재조회.
- 5명씩 큐 처리, 각 회원 최대 5개 기기. FCM 접수 결과를 저장해 재시도 시 건너뜀. 전송 직후 프로세스 중단의 중복은 앱 이벤트 ID로도 억제.
- 큐 등록 실패는 Redis pending에 유지. 기존 watchdog 및 모임장 공지 조회에서 재등록. 기존 watchdog 주기는 하루 1회이며, 일반 큐 전송 실패는 60초 간격 재시도.
- 24시간 초과 미완료 작업 종료. 공지/전송 결과 90일 보관, 화면에는 최신 20건. 한도 상태는 모임별 최근 90일 이력만 유지.
- `accepted`는 FCM 접수이며 실제 기기 수신 또는 읽음이 아님. 기기 없는 회원에게도 웹 공지 제공.
- Android 1.1.383 이상에서 일반 회원 모임 알림 지원. 기존 APK는 업데이트 필요. 웹 푸시는 이번 범위에 포함하지 않음.
- 케이지 의견 작성창에도 최고관리자 표시 작성자명 입력란 추가.

운영자 갱신 푸시와 모임 푸시가 같은 completion-push 큐를 사용하되 payload와 worker 진입점을 분리한다. 기존 나우랭크/여론조사 알림 내용과 수신 권한은 유지한다.
