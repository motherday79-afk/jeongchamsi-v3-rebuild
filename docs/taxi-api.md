# Taxi Driver API

GET/POST `/api/v3/taxi`. No point charges. All timestamps milliseconds. Signed-in account history is private. Guest history is keyed by a cryptographically random bearer token; keep it in localStorage and send `X-Taxi-Session`. Never put it in URLs. GET without authentication/token returns a new `sessionToken`; save it before POST so retries use the same identity. Signed-in requests ignore guest tokens.

Success `{ok:true,serverNow,version,sessionToken?,ride:null|Ride,history:CompletedRide[],result?}`. `version` is integer 0 initially, increments per mutation. GET does not increment. POST every action requires `{action,requestId,expectedVersion}`. requestId: 12–100 ASCII letters/digits/hyphen/underscore. Use a fresh ID per intentional operation, retry the same body after network uncertainty. Return state has latest version; duplicate returns latest state with `result:{action,replayed:true}`. Last 128 request receipts kept; older retry rejects VERSION_CHANGED safely. On VERSION_CHANGED reload and do not silently retry a listen/like choice.

Actions: `start` (only when no active ride); `listen` (advance to next card, or finish after final card); `like` (mark current card once, does not advance); `dropoff` (finish early); `finish` (allowed only on final card); `pause`, `resume`, `heartbeat`. POST must have exact same Origin as API URL. Missing/cross-site Origin forbidden. Heartbeat about every 15 seconds only when document is visible; pause on hiding, resume on return. A request credits at most 20 seconds since prior interaction; pause excludes later time. The server never accepts client elapsed time. This is an approximate reading record, not a measure of political support.

Active Ride `{id,status:'active',startedAt,activeMs,heardCount,totalBeats,beatIndex,likedBeatIndexes:number[],paused,beat:{index,text,type:'paraphrase'}}`. It intentionally has no passenger ID, name, party, photo, context, or sources. Current beatIndex is zero-based; heardCount starts at 1, increments on listen. ActiveMs includes only accepted intervals up to the last interaction (GET never adds time).

Completed Ride adds `{status:'completed',endedAt,finishReason:'completed'|'dropoff',firstRide:boolean,visitNumber:number,passenger:{id,personId,name,partyLabel,photoUrl},beats:[{index,text,type,context,sources:[{title,url,date}]}],events:[{at,action,beatIndex}]}` and removes current `beat`. All cards and source links revealed when complete; heardCount records only cards displayed. History contains newest 100 completed rides. First/repeat classification tracks prior completed rides even after journal retention limit. Shuffled deck exhausts every passenger before another shuffle. No political ranking or profile integration.

Errors `{ok:false,error}`: 400 INVALID_INPUT/INVALID_REQUEST_ID/INVALID_SESSION; 403 ORIGIN_INVALID/ACCOUNT_INACTIVE; 409 VERSION_CHANGED/REQUEST_ID_REUSED/RIDE_ACTIVE/NO_ACTIVE_RIDE/ALREADY_LIKED/NOT_LAST_BEAT/RIDE_PAUSED; 503 STORAGE_UNAVAILABLE/CONTENT_UNAVAILABLE; 405 METHOD_NOT_ALLOWED. GET without token is public and reveals no other history.

Backend exports `createTaxiService({command,now,random,passengers})` with `get(user,sessionToken)` and `mutate(user,body,sessionToken)`. `taxiRequest(req,{service,user,url})` returns `{status,body}`; reads `X-Taxi-Session` from headers. Gateway should use no-store for private responses and must not log the token.
