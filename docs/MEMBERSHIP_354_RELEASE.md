# 회원등급 개편 · JCS 0.0.31.354

| 회원등급 | 뉴스·칼럼 작성 | 나우랭크 전체 분석 | 기존 운영 기능 | 관리자 페이지 |
|---|---|---|---|---|
| 일반회원 | 불가 | 기존 일반회원 범위 | 불가 | 불가 |
| 플래티넘 회원 | 가능 | 가능 | 불가 | 불가 |
| 회원관리자 | 가능 | 가능 | 가능 | 불가 |
| 최고관리자 | 가능 | 가능 | 가능 | 가능 |

기존 관리자 계정 중 아이디가 정확히 `admin`인 계정은 최고관리자로, 나머지는 회원관리자로 해석한다. 회원 데이터 전체를 덮어쓰는 마이그레이션 없이 즉시 적용된다. 기존 `partner` 등급은 플래티넘과 호환된다.

최고관리자는 회원관리 화면에서 네 등급을 지정할 수 있다. 내부 운영 호환성을 위해 두 관리자 등급은 `role: admin`을 유지하며, 표시 및 최고관리자 접근은 `membershipTier`로 구분한다. 등급 변경 시 기존 세션은 무효화된다. 본인의 최고관리자 권한 해제 및 마지막 최고관리자 제거는 막는다.

회원관리자는 관리자 콘솔과 회원정보·권한·비밀번호·배지 관리 API에 접근할 수 없다. 광산 관리, 게시판 운영 및 메인 화면의 배너·케이지 등 기존 화면 내 운영 기능은 유지한다. 플래티넘 분석 권한은 조회 전용이며 정치인 사진 편집이나 분석 발행 권한을 부여하지 않는다.

## 검증

등급 분류, 서버 API 직접 호출 차단, 위조된 요청 역할 무시, 등급 변경과 세션 무효화, 자기 권한 상승 방지, 뉴스·칼럼 작성/타인 글 수정 차단, 플래티넘 상세 분석 및 유료 분석 만료 회귀를 검증했다.

기존 `ai-panel-pages.test.js`의 오래된 화면 기대값 3개와 `intelligence-access.test.js`의 기존 분석 투영 기대값 2개는 변경 이전 코드에서도 실패함을 비교 확인했다. 해당 기존 문제는 이번 회원등급 패치에서 변경하지 않았다.

## 최종 종합 ZIP

ZIP은 배포 커밋의 전체 Git 추적 파일(웹·서버 코드, 정적 이미지/음향, 테스트, 배포 설정)을 포함한다. 운영 회원·게시글·골드 등 실시간 DB 데이터, 환경변수 비밀키, 인증서, node_modules와 Git 이력은 포함하지 않는다. 설치는 `npm ci`로 진행하고 기존 운영 환경변수와 외부 데이터 저장소를 연결해야 한다. DB 백업을 대체하는 파일은 아니다.
