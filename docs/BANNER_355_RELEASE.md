# 벨가르드 배너 · 0.0.31.355

오른쪽 배너에 벨가르드 캠페인을 기본 등록했다. 문구는 `하루 / 가장 완벽한 컨설팅이 / 시작됩니다.`와 `벨가르드` 두 블록이다. 클릭하면 https://velgard.store 로 연결된다.

첫 노출은 벨가르드이며 이후 기존 배너를 60초 간격으로 순환한다. 등록 자료가 없으면 기존 정참시 캠페인을 함께 표시한다. 관리자 배너 추가는 기존 이미지를 보존하고 순환 목록에 추가한다. 사이드 배너 저장은 원자적 비교 저장으로 동시 업로드 손실을 방지한다. 왼쪽 메인 배너의 교체 방식은 유지한다.

이미지: `assets/banners/velgard-pc-355.webp` (840×480), `velgard-mobile-355.webp` (720×540), `velgard-tablet-355.webp` (1200×400). 모바일은 문구 손실 없이 여백을 둔 전체 이미지로 표시한다. 총 약 105KB.

제작: 내장 image_gen 도구. 제작 프롬프트 요약: 어두운 차콜, 샴페인 금속, 빛을 받는 추상적인 V 조형물, 여백 있는 고급 컨설팅 광고. 요청한 한국어 문구 두 블록만 사용하고 URL·버튼·추가 문구는 넣지 않는다. 기본 7:4와 태블릿 3:1 구도. 최종 기기별 파일은 비율 유지 리사이즈와 WEBP 압축.

숨겨진 탭이나 키보드로 배너 링크에 초점을 둔 상태에서는 전환을 잠시 멈춘다. 화면 이동·뒤로가기로 다시 연결할 때 타이머가 중복 생성되지 않는다. 화면 검수는 사용자가 진행한다.
