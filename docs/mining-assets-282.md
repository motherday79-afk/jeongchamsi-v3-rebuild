# Integrated miner animations 282

Built-in imagegen edited the three original 277 source atlases. Each request preserved the fully clothed miner's face, outfit, stance, gaze, foot placement, camera and eight poses while replacing only the complete held pickaxe. Each frame remains a single integrated illustration, not an assembled skeleton.

Prompt variants, one call for each character and tool:

- Silver: polished silver steel head, blue sapphire hub, silver fittings, blue wrapped handle.
- Gold: polished gold head, amber hub, gold fittings, brown wrapped handle.
- Amethyst: faceted purple crystal head, violet hub, gold fittings, purple wrapped handle.

All requested exactly four columns by two rows of complete isolated poses on alpha, no labels, scenery or added effects, both hands retaining natural contact with the handle. Nine generated atlases were segmented and registered to the original planted-boot anchor. Each final WebP has eight 540×710 cells in a horizontal 4320×710 strip.

Final assets: `assets/mine/{strong,glamour,elf}-pick-{1,2,3}-282.webp`. Iron uses the existing `*-motion-277.webp`.
