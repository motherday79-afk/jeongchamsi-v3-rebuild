## 확인한 원인

- 수집을 시작한 사실과 새 순위를 게시한 사실을 구분. 340의 배포 및 모의 테스트만으로 운영 성공을 확인하지 못한 문제를 실제 전체 실행으로 검증.

## 수정
- Cron은 작업 큐에 첫 단계를 저장하고 응답. Vercel Queue의 비공개 소비 함수가 수집·검증·게시를 독립적으로 이어감.
- 단계 저장 후 다음 메시지 전송 전 실패해도 재전달된 메시지가 저장된 다음 단계를 복구. 중복 단계는 다시 수집하지 않음.
- 큐 전송/잠금 실패는 재전달, 메시지 보관 및 실행은 6시간 제한. 완료 전에는 기존 공개 스냅샷 유지.
- 실패한 당일 작업은 수정 배포 후 다시 실행 가능. 완료된 당일 작업은 중복 실행하지 않음.
- 자동 갱신 진행 중 관리자 화면의 수동 자동 재개 차단.
- 35개 관련 테스트 통과 및 실제 큐 소비 함수 import 확인.
