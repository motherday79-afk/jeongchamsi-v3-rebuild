# JCS 0.0.31.161 — 초기 로딩 중단 핫픽스

160 버전 적용 후 ‘정참시를 불러오고 있습니다’ 화면에서 멈출 수 있는 오류를 수정했습니다.

배너 조회 결과가 비어 있거나 실패하면 정상적으로 null이 전달됩니다. 메인 배너를 그리는 코드가 이 값에서 설명 문구(alt)를 바로 읽으면서 예외가 발생해, 로딩 화면을 실제 메인 화면으로 교체하지 못했습니다. 배너가 없는 경우도 안전하게 처리하도록 수정했습니다. 일반 이용자에게는 없는 배너를 표시하지 않고, 관리자에게는 기존 배너 등록 기능을 제공합니다.

로고 확대·검색 하단 캠페인과 별빛 친구들·케이지 붓글씨 및 줄바꿈·기존 배지와 데이터는 160 버전을 유지합니다. 재수집이나 데이터 초기화, 환경변수 변경은 필요하지 않습니다.

## 적용

- 현재 160 버전이면 JCS_0_0_31_161_PATCH.zip을 풀어 같은 경로의 파일을 덮어쓴 뒤 배포합니다.
- 전체 파일로 교체하려면 JCS_0_0_31_161.zip을 사용합니다. 두 ZIP을 중복 적용하지 않습니다.
- 배포 완료 후 새로고침합니다. 시작 코드의 버전도 변경해 수정 파일을 새로 불러오도록 했습니다.
- 버전 확인: /api/v3/health → JCS_0_0_31_161

## 검증

배너 없음, 배너 조회 실패, 배너 정상 등록의 세 가지 응답으로 index.html의 실제 시작 모듈과 연결된 코드 전체를 실행했습니다. 오류가 있을 때 실패했던 검사가 수정 후 통과하며, 로딩 문구가 사라지고 메인 화면이 생성되는 것을 확인했습니다. 관리자 등록 버튼과 비회원 미노출도 검사했습니다. 이 검사는 로컬의 메모리 기반 DOM/API 환경이며 실제 브라우저의 시각 검수는 아닙니다.

브라우저 미리보기는 이 환경의 정책상 확인하지 못했으며 운영 배포도 수행하지 않았습니다. 검증 기록은 verification/home-startup-161/에 포함했습니다.
