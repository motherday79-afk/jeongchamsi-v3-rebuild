# JCS 0.0.31.199 — HUMAN 상태 구분 + AI 표기 위치 수정

적용 기준: 0.0.31.198 위에 덮어쓰기

## 1. 공개 AI 표기 수정
- 상단/카드 주요 표기: `JCS AI`
- 하단 표기: `AI ID INTELLIGENT AGENT N1000`
- 실제 집계 N이 있는 화면은 `AI ID INTELLIGENT AGENT N{실제 N}`으로 표시

## 2. HUMAN 데이터 V2 지원
JCS HUMAN POLL V2에서 각 수치에 상태를 기록할 수 있습니다.
- `verified`: 검증됨
- `unconfirmed`: 미확인 — 이번 수집에서 직접 확인하지 못함
- `not_provided`: 미제공 — 원자료 자체가 수치를 제시하지 않음

기존 null 값을 모두 `미제공`으로 표시하던 문제를 수정했습니다.
공개 비교표에서 상태에 따라 `미확인`과 `미제공`을 구분합니다.

## 3. 사례수 확장
각 HUMAN 교차집계 버킷에 다음을 함께 저장할 수 있습니다.
- `n`: 조사완료 사례수
- `weightedN`: 가중값 적용 기준 사례수

두 값이 모두 있으면 `N (가중 N)` 형태로 표시됩니다.

## 4. 이전 데이터 호환
기존 JCS_HUMAN_POLL_V1 자료도 계속 읽습니다.
상태 정보가 없는 기존 null은 기본적으로 `미확인`으로 처리합니다.

## 5. 관리자 붙여넣기
권장 형식은 `JCS_HUMAN_POLL_V2`입니다.
ChatGPT가 원기관/교차집계표/중앙여심위까지 확인한 JSON 전체를 관리자 HUMAN 입력창에 그대로 붙여넣습니다.

## 적용
1. 이 패치 파일을 동일 경로에 덮어씁니다.
2. Vercel 배포 완료를 확인합니다.
3. 관리자/공개 페이지에서 Ctrl+F5로 새 버전을 불러옵니다.
4. 새 JCS HUMAN POLL V2 JSON을 등록합니다.
