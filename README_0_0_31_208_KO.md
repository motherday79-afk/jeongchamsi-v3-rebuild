# JCS 0.0.31.208 · 폴리마블 타일 가독성 + 이동 액션 패치

## 적용 기준
- **31.207 위에 그대로 덮어쓰기**
- 승인된 1200×675 배경, 24칸 연결 구조, 게임말, 주사위 이동 규칙은 변경하지 않음

## 이번 패치에서 바꾼 것만
1. **23개 칸 불투명화**
   - `지역공감 +150` 칸(index 16)만 국회의사당 윗부분을 가리므로 반투명 유지
   - 나머지 23개는 배경색 opacity 1로 고정
2. **글씨/아이콘 확대**
   - 제목, 아이콘, 점수 표시를 칸 크기 안에서 최대한 크게 보이도록 확대
   - 상단의 낮은 칸만 별도 크기 조정
3. **칸 이동 액션**
   - 게임말이 한 칸씩 이동할 때, 도착하는 각 칸이 약 0.23초 동안 살짝 들리고 밝아지는 반응 추가
   - 이동 로직이나 주사위 결과에는 영향 없음

## 그대로 유지한 것
- 1200×675 배경
- 24개 독립 객체 / 시각적으로 연결된 하나의 띠
- 오른쪽 하단 START
- 왼쪽 방향 진행
- 게임말 크기와 이미지
- 한 칸씩 총총 이동
- 테스트용 주사위
