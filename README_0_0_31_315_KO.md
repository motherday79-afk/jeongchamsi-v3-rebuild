# 315 · 망자의 계곡

- 월드맵 중앙 하단에 망자의 계곡 입구 추가. 전체 화면 Canvas 게임.
- 고블린 금화 수레 90초 운송, 내구도 3칸. 좌우 버튼/방향키/A·D 회피.
- 첫 60초는 공격 1초 전 방향 안내. 마지막 30초는 예고 없이 손이 나타나고 650ms 후 충돌.
- 겹치는 양방향 공격 없음, 충돌 후 1.1초 보호. 백그라운드 전환 시 일시정지.
- 신규 고블린·수레·망자의 손 이미지와 곡선 길, 안개, 이동 애니메이션 연결.
- 서버 발급 공격 패턴과 조작 기록으로 판정 재계산, 경과 시간/세션/중복 완료 검사.
- 골드 차감 및 보상 지급 없음. 재도전 가능, 일일 운송 성공 기록 추가. 일일퀘스트 총 4개.
- 시작/결과 저장 실패 안내와 결과 재저장 제공. 뒤로가기 시 게임 정리.
- 관련 판정/저장/자정 초기화/기존 퀘스트 검사 8개 통과. 화면·플레이 검수는 사용자 진행.

현재 관리자 전용 공개 범위를 유지합니다. 클라이언트 조작 기록은 서버 재계산에 사용되지만 외부 입력 위조까지 막는 부정행위 방지 시스템은 아닙니다. 경제 보상 도입 시 별도 검토가 필요합니다.
