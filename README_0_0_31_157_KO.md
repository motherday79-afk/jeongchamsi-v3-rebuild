# JCS 0.0.31.157 — CAMPAIGN 게시판 · 상세 · 더보기 연결

## 적용
현재 156 버전이면 `JCS_0_0_31_157_PATCH.zip`을 풀어 기존 프로젝트의 같은 경로에 합친 뒤 배포하세요. `api`, `lib`, `src`, `css`, `tests`, `verification` 폴더와 `index.html`을 함께 반영합니다.

이전 버전이거나 전체 소스가 필요한 경우에는 `JCS_0_0_31_157.zip`을 사용하세요. 전체 ZIP에는 기존 배지 리뉴얼과 156 케이지·응원/후원 배너 작업이 포함되어 있습니다. 전체 ZIP과 패치를 중복 적용할 필요는 없습니다.

기존 의존성과 환경 설정을 사용합니다. Redis 연결은 기존 프로젝트의 연결을 유지하며, 캠페인 사진 업로드에는 기존 Vercel Blob 연결이 필요합니다. 기존 정치인 사진이나 HTTPS 사진 URL도 사용할 수 있습니다. 데이터 초기화·재수집·기존 자료 마이그레이션은 필요하지 않습니다.

배포 후 오래 열린 탭을 다시 열면 새 코드가 적용됩니다. `/api/v3/health`의 버전은 `JCS_0_0_31_157`입니다. 이번 전달물은 적용용 소스이며 운영 사이트 배포는 수행하지 않았습니다.

## 확인 경로
- 더보기 → 퍼플·골드 아이콘의 **캠페인** → `/campaigns`
- 진행 중 캠페인: 대표 캠페인과 일반 카드 목록, 상세페이지 연결
- ARCHIVE: `/campaigns?view=archive`
- 상세페이지: `/campaigns/{캠페인 ID}`
- 관리자로 접속하면 게시판 상단에 **캠페인 등록 / 캠페인 관리** 표시
- 등록: `/campaigns/write`, 관리: `/campaigns?view=manage`, 수정: `/campaigns/{ID}/edit`

실제 캠페인은 등록되어 있지 않은 상태로 시작합니다. 승인 시안의 가상 인물·사진·후원계좌는 운영 데이터로 넣지 않았습니다.

## 운영
정치인 이름 검색은 기존 자동완성 검색을 사용합니다. 선택한 정치인의 정보로 캠페인 프로필을 채우며, 캠페인 편집이 기존 정치인 원본 정보를 수정하지는 않습니다. 등록 항목에 이름·사진·정책·스토리·출처·YouTube 영상·캠페인 기간을 입력할 수 있습니다.

임시저장은 일부 항목만 입력해도 가능합니다. **게시 필수** 표시 항목과 적어도 한 개의 완성된 정책을 입력한 뒤 게시합니다. 의뢰 제작·광고를 선택한 경우 제작 관계 고지도 입력해야 합니다.

- 임시저장한 수정 내용은 이미 공개된 내용에 즉시 반영되지 않습니다. 게시를 눌러야 공개본이 갱신됩니다.
- 최초 게시 때 캠페인 번호가 자동 부여되고 이후 유지됩니다.
- 시작일 이전에 게시한 글은 관리자에게 **공개 예정**으로 보이며 시작일에 공개됩니다.
- 기간은 한국 시간 기준입니다. 종료일 23:59:59까지 진행 중이며 다음 날 ARCHIVE로 이동합니다. 별도 스케줄러 없이 요청 시점을 기준으로 표시합니다.
- **종료**한 글은 ARCHIVE에 보존됩니다. **비공개**는 공개 목록과 상세 접근을 함께 중단합니다.
- 한 번 게시한 캠페인은 영구 삭제할 수 없습니다. 게시하지 않은 초안만 삭제할 수 있습니다.
- 서로 다른 편집기의 저장이 겹치면 후속 저장을 막고 작성 내용을 유지합니다. 안내에 따라 최신 내용과 비교 후 반영하세요.
- **대표 캠페인**은 CAMPAIGN 게시판 안에서만 노출됩니다. 여러 개를 선택하면 현재 진행 중인 글 중 최근 게시한 하나를 대표로 보여줍니다.
- 영상·출처 등 선택 정보는 등록된 경우에만 표시됩니다.

## 이번 범위
승인한 CAMPAIGN 전체보기와 상세페이지 디자인을 기존 정참시 화면에 연결했습니다. 어두운 배경의 제목·정치인 이름 등에 명시적인 밝은 글자색을 유지했습니다. 더보기 아이콘은 기존 퍼플·골드 SVG 재질 체계를 사용합니다.

메인·오른쪽 배너의 이미지, 크기, 노출 방식과 기존 케이지·응원/후원 배너는 그대로입니다. 이번 버전은 배너에 캠페인을 연결하지 않습니다.

상시 정치후원 디렉터리, 공식 후원정보 관리·등록 연동, 결제·수수료·정참시의 정치후원금 수취는 이번 개발 범위에 포함되지 않습니다. 실제 연결된 후원정보가 없는 상세페이지는 후원 영역 자체를 표시하지 않습니다.

## 검증과 한계
전체 자동검사 결과와 원본 자산·시안 대조 결과는 `verification/campaigns-157/verification.json`에 기록했습니다. 원본 156 + PATCH 결과와 157 전체 ZIP을 바이트 단위로 비교했습니다.

저장 Lua는 로컬 Redis 기본 명령 어댑터로 실행하여 초안/공개 분리, 번호, 빈 배열 보존, 게시 이력, 충돌 방지, 종료·비공개·초안 삭제를 확인했습니다. 실제 운영 Redis나 Blob에 테스트 데이터를 쓰지는 않았습니다.

이 환경에서는 로컬 미리보기 접근이 브라우저 보안 정책에 차단되어 실제 브라우저·휴대폰 클릭 검수는 수행하지 못했습니다. 배포 후 PC/휴대폰의 더보기→목록→상세 이동과 관리자 임시저장·예약 게시·종료를 확인하세요.

검사 실행: `npm ci` 후 `npm test`.
