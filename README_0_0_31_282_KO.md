# 정참시 282 — 캐릭터·곡괭이 통합 모션

281의 부품 조립형 캐릭터를 플레이 화면에서 제거하고, 이전의 완성 일러스트 모션 방식으로 복구했습니다. 캐릭터와 손에 든 곡괭이가 하나로 그려진 이미지를 강화 단계에 맞춰 통째로 교체합니다.

| 단계 | 캐릭터가 드는 곡괭이 |
|---|---|
| Lv.1 | 기존 철 곡괭이 |
| Lv.2~6 | 은빛·푸른 보석 곡괭이 |
| Lv.7~13 | 황금 곡괭이 |
| Lv.14~20 | 자수정 곡괭이 |

황금 곡괭이 무료 체험 장비는 황금 모션을 사용합니다. 남성·성인 여성·미니미 엘프 모두 같은 단계 구성이며, 총 12개 모션 묶음입니다. 기존 철 곡괭이 3개 묶음은 유지하고 나머지 9개를 새로 제작했습니다. 묶음마다 8개 동작이 들어 있습니다.

채굴은 기존 1.5초 주기입니다. 들어 올리는 준비 동작은 천천히, 내려치기는 빠르게, 충돌 후에는 짧은 멈춤과 회복 동작을 유지합니다. 프레임의 왼발 기준점과 여백을 기존 모션에 맞춰 등록했습니다.

부위별 의상 변경과 옷장 진입은 보류했습니다. 기존 의상 저장 데이터는 지우지 않습니다. 골드·강화·복권·잭팟·광고 이미지·관리자 전용 접근 제한은 유지합니다.

관련 테스트 7개 통과. 9개 새 이미지의 8프레임 구성과 잘림 여부를 처리 과정에서 검사했고, 전체 단계 비교 이미지 및 로컬 은빛 곡괭이 플레이 화면 연결을 확인했습니다. 운영 플레이 검수는 사용자에게 맡깁니다.

281 FULL에 282 PATCH를 적용합니다. FULL은 전체 소스입니다.
