- 광고판에 천장 고정대와 이어지는 연결 줄을 추가했습니다.

- PC·모바일 상단에 전체보기/화면복귀 버튼을 추가했습니다. Esc 등 브라우저에서 종료해도 버튼 상태가 맞춰집니다.

검사: 수정 JavaScript 문법 검사 및 git diff --check 통과. 추가 동작 검사는 실행 권한 거절로 미실행. 실제 PC·모바일 시각 및 전체보기 검수는 사용자가 진행합니다.
