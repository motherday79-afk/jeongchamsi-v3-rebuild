# 317 · 계곡 난이도·금화 수집·환경

- 망자의 계곡 메뉴 hover/focus 밝기 효과 추가.
- 60초 운송. 처음 20초는 손 출현 100ms 전 예고와 출현 후 350ms 충돌(총 반응 450ms).
- 이후 40초는 예고 없이 출현 후 350ms 충돌, 출현 간격 900~1200ms로 단축. 초기 간격 1700~2150ms.
- 공격 쪽 금화를 충돌 220ms 전에 수집하는 위험/보상 동선. 화면에 수집 개수 표시.
- 서버가 조작 기록으로 수집량과 생존 여부 재계산. 생존 + 전부 수집 시 날짜별 완료 기록 저장.
- 보너스 내용/금액 안내 및 지급 없음. 보유 골드 변경 없음.
- 계곡 전용 환경과 흙길/목재 이미지 질감 적용. 가로 띠를 만들던 안개 사각 영역 삭제.
- 구버전 운송 결과에는 새 게임 시작 안내. 판정·금화 수집·기록 검사 5개 통과.
- 실제 화면/플레이 검수는 사용자 진행.
