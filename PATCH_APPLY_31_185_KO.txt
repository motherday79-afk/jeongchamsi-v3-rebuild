JCS 0.0.31.185 — AI 여론조사 관리자 3클릭 패치

적용 기준
- JCS 0.0.31.182 / 31.183 / 31.184 위에 적용 가능한 누적형 패치입니다.
- 기존 프로젝트 전체를 삭제하지 마세요.
- ZIP을 풀고 내부 파일만 GitHub의 동일 경로에 덮어쓰세요.

관리자 운영 방식
1) 최신 조사 가져오기
   - 한국갤럽 최신 1건
   - 리얼미터 최신 1건
   - 과거 3~4주 자료를 운영 화면에 나열하지 않음

2) AI 응답파일 등록
   - ChatGPT에서 만든 1,000명 응답 JSON 파일 선택
   - 파일 선택 즉시 자동 처리
     · 정식 1,000명 패널 선택
     · 주차/RUN 자동 생성 또는 기존 초안 사용
     · 최신 HUMAN 자료 자동 연결
     · EXPOSED 환경 자동 기록
     · 1,000개 ID 검증 및 집계

3) 메인에 게시
   - HUMAN ↔ AI 결과 확인
   - 버튼 한 번으로 검수 → LOCK → 게시 자동 처리

추가 변경
- 동일 주차 재실행 사유 직접입력 제거
- 내부 기록에는 자동 사유 보존
- 갤럽/리얼미터 수집은 기관별 최신 1건만 요청
- 저장소에는 과거 수집 이력을 유지하되 운영 API/UI에는 기관별 최신 1건만 제공
- 리얼미터 수집기 31.183 개선사항 포함

기본 화면에서 제거/숨김
- RUN 직접 생성
- EXPOSED/BLIND 직접 선택
- Sources JSON
- AI Responses JSON 원문 입력
- 수동 검수/LOCK 단계
- 과거 3~4주 HUMAN 목록

고급설정
- 1,000명 패널 등록/교체
- 자동수집 실패 시 HUMAN 직접입력
- 지난 조사/작업 이력

주의
- 정식 게시에는 기존과 동일하게 1,000명 정식 패널이 필요합니다.
- AI 응답 파일 형식과 ID는 기존 검증 규칙을 그대로 따릅니다.
- 기존 DB/Redis 키와 공개 데이터 구조는 변경하지 않았습니다.
