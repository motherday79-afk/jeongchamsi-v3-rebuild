# JCS 0.0.31.290 — 시안 기반 곡괭이 효과

## 변경
- 신비·차원·어둠·천상·번개·바람용 투명 효과 텍스처 6종을 추가했습니다.
- 신비의 결정, 차원의 무지개 기운, 어둠의 검붉은 연기, 천상의 깃털·후광, 번개의 전기, 바람의 곡괭이 분신을 이미지 기반으로 표시합니다.
- 5종족 × 10종 장비의 8개 자세에 곡괭이 머리·손잡이 기준점을 연결했습니다. 동작에 맞춰 효과가 이동·회전합니다.
- 장착 중 대기 상태에서도 지속 효과를 표시하고, 들어 올림·타격·여운을 구분했습니다.
- 캐릭터 뒤의 무기 기운과 앞의 반짝임·충돌 효과를 별도 캔버스로 분리했습니다.
- 효과는 최대 약 30fps로 그리며 선택한 장비 텍스처만 불러옵니다. 숨긴 창에서는 렌더링을 멈추고 움직임 줄이기 설정을 따릅니다.

기존 통합 캐릭터·곡괭이 모션 이미지와 게임 경제·계정 데이터는 유지했습니다. 시안 원본을 그대로 움직이는 방식이 아니라, 시안에 맞춘 효과 텍스처를 기존 모션에 합성하는 구현입니다.

## 확인 방법
관리자 계정 → 곡괭이 상점 → 원하는 곡괭이 장착. 대기 상태의 효과와 자동채굴 중 휘두름·충돌 효과를 확인해 주세요.

요청에 따라 문법·변경 파일 공백 검사만 수행했습니다. 실제 PC·모바일 화면과 효과의 시각 검수는 사용자 진행입니다.
