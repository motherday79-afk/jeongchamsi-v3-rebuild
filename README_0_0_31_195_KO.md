# JCS 0.0.31.195 여론조사 UI 핫픽스

기준: 0.0.31.194 위에 덮어쓰기

## 변경 사항
1. 여론조사 공개 상세페이지의 원문 보기/외부 원문 링크 표시 제거
   - 기관별 결과 카드
   - 기관 조사 정보
   - 조사 방법/정보환경의 원문 링크
   - URL은 내부 수집/관리 데이터로는 유지하되 공개 상세 화면에서는 링크를 노출하지 않음

2. 메인 여론조사 모듈의 상세보기 액션을 다른 메인 게시판과 동일한 아이콘 버튼으로 통일

3. 관리자 과거 조사 기록 관리 상시 노출
   - 접힌 고급 메뉴에서 꺼냄
   - 각 기록에 `상세보기` + `기록 삭제`
   - 과거 기록 상세 진입 시 `이 기록 삭제` 유지
   - 삭제는 기존 서버의 영구 삭제 + 게시 포인터 폴백 로직 사용

4. 캐시 버전 0.0.31.195로 갱신

## 적용
현재 프로젝트는 삭제하지 말고 이 ZIP의 파일만 같은 경로에 덮어쓰세요.
배포 완료 후 Ctrl+F5 또는 Ctrl+Shift+R로 한 번 새로고침하세요.
