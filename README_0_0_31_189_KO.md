# JCS 0.0.31.189 · AI 관리자 무새로고침 핫픽스

적용 기준: 31.188 위에 동일 경로로 덮어쓰기.

## 수정 내용
- 최신 조사 가져오기 성공 후 관리자 전체 페이지 이동/재진입 제거
- AI 통합파일 업로드 성공 후 새 RUN URL로 강제 이동 제거
- AI 관리자 영역만 즉시 다시 불러와 현재 스크롤/운영 흐름 유지
- AI 통합파일 등록 후 ③ 메인 게시 영역으로 바로 이어짐
- 평상시 관리자 화면은 URL에 과거 id가 남아 있어도 최신 미게시 RUN 또는 최신 RUN 우선
- 과거 조사 보기(history=1)에서만 선택한 과거 RUN을 명시적으로 표시

## 운영 흐름
1. 최신 조사 가져오기
2. AI 통합파일 선택
3. 같은 화면에서 메인에 게시/재게시

## 주의
- 기존 프로젝트 전체를 삭제하지 말고 패치 파일만 같은 경로에 덮어쓰기.
