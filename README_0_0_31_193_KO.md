# JCS 0.0.31.193 - AI PANEL 저장소 경량화 핫픽스

적용 기준: 31.192 위에 동일 경로로 덮어쓰기

## 수정 내용
1. AI 패널/AI RUN 전체 레코드를 Redis 저장 시 gzip 압축 후 저장합니다.
2. 기존 비압축 레코드도 자동으로 읽으므로 과거 자료 삭제나 DB 초기화가 필요 없습니다.
3. 통합 JSON 업로드 시 응답 저장 요청에는 프로필 필드를 중복 전송하지 않고 id/choice/reason/explanation/factors만 전달합니다.
4. AI_PANEL_STORAGE_FAILED 공통 문구를 게시 전용 문구에서 일반 저장소 문구로 수정했습니다.
5. 통합파일 업로드 중 저장소 실패와 최종 게시 중 저장소 실패를 서로 다른 안내문으로 표시합니다.

## 검증
- 실제 JCS-AI-PANEL-A-1000-INTEGRATED.json 1,000명으로 저장/집계 재현
- Redis 저장 레코드(테스트 저장소 기준): 패널 약 43KB, 응답 포함 RUN 약 57KB
- 긍정 40.7 / 부정 50.9 / 유보 8.4 정상 집계
- AI PANEL 핵심 테스트 36개 통과
- 기존 pages 테스트 3건은 31.192 기준에서도 동일하게 실패하는 기존 기대문구 불일치이며 본 패치와 무관
