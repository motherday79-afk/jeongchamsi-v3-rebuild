# 정참시 0.0.31.260 — 타일 눌림과 착지 빛

칸 윗면·이름·깃발·건물·말을 같은 깊이로 내려 칸을 밟는 동작을 표현합니다. 옆면 아래는 고정되어 타일 두께가 실제로 줄어듭니다. 통과는 240ms, 마지막 착지는 520ms이며 마지막에 더 큰 금빛 번짐·빛기둥·14개 별 입자가 나타납니다. 네모 윤곽이나 소유 점선은 추가하지 않습니다. 운명의 선택 위 1P TURN 표시를 제거했습니다.

기존 주사위·캐릭터 이미지·게임 규칙 및 서버에 저장된 배치값은 유지합니다. 배치 편집을 열거나 게임 화면을 떠나면 진행 중 효과를 정리합니다. 기기에서 동작 줄이기를 사용하면 새 눌림·착지 효과는 생략됩니다.

사용: 폴리마블을 새로고침하고 주사위를 굴리면 적용됩니다. 별도 배치 저장은 필요하지 않습니다. PATCH는 259 전체 소스에 덮어쓰는 변경분이며 FULL은 260 전체 소스입니다.

검증: 관련 자동 테스트 35개 통과, 변경 JS 구문 확인. 로컬 브라우저에서 실제 주사위 3+3 → 제주도 도착 → 구매, 효과 종료 후 변위·입자 제거, TURN 제거를 확인했습니다. PC 및 모바일 가로·세로 크기 화면 확인은 브라우저 뷰포트 검사이며 실제 휴대전화 성능 측정은 아닙니다.

이미지: 기존 승인 보드의 타일 아래 받침만 이미지 편집으로 생성한 tile-platform-260.png를 사용합니다. 타일이 차지하는 영역으로 잘라 표시하므로 외부 배경은 기존 이미지를 사용합니다. 윗면은 기존 tile-clean-255.png를 사용합니다.
