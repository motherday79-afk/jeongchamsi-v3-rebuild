# JCS_0_0_31_170 — 늦은 귀갓길 캠페인 배너

웹 기준 버전: JCS_0_0_31_167. Android 168·169는 별도 앱 버전이며 이번 파일은 웹 패치입니다.

## 적용 내용

- 승인받은 밝은 아이보리·라벤더·퍼플·골드 배너 원본 3종을 그대로 사용합니다.
- 오른쪽 기존 유튜브 안내 배너 자리를 한도윤의 「늦은 귀갓길에도, 멈추지 않는 이동을.」 예시 캠페인으로 연결합니다.
- 배너 전체 클릭 시 `/campaigns/example-002` 상세를 현재 화면에서 엽니다. 앱 안에서도 기존 내부 이동 방식을 사용합니다.
- PC 기본 420×240, 고해상도 PC 840×480, 휴대폰 720×540, 펼친 폴드·태블릿 1200×400 이미지를 포함합니다.
- 창 너비 600px 이하에서는 휴대폰용, 601~1024px에서는 가로형, 그보다 넓으면 PC용을 선택합니다. 접힘·펼침과 회전 후에도 화면 너비에 따라 선택됩니다.
- 좁은 PC 사이드바에서도 문구와 얼굴을 자르지 않도록 전체 구도를 유지합니다. 기존 배너 자리의 크기·순서는 유지합니다.
- 관리자에서 새로 등록한 배너(`designVersion: upload`)는 관리자 설정이 우선합니다. 기존 업로드 기능과 메인 상단 광고는 유지합니다.
- 배지·로고·케이지·캠페인 데이터·서버/API·Android 소스는 변경하지 않습니다. 원본 이미지를 재생성하거나 자르지 않았습니다.

## 파일 적용

1. 웹 167 사용 중이면 `JCS_0_0_31_170_PATCH.zip`을 풀고 저장소 루트에 같은 경로로 덮어씁니다. 최상위에는 index.html, src, css, assets가 있어야 합니다.
2. 변경 파일을 저장소에 반영한 뒤 기존 웹 배포 방식으로 배포합니다. 전체 소스가 필요하면 `JCS_0_0_31_170.zip`을 사용합니다.
3. 홈 오른쪽 배너 전체를 클릭해 한도윤 예시 캠페인으로 이동하는지 확인합니다. PC, 접힌 폴드/휴대폰, 펼친 폴드에서 각각 확인합니다.

기존 APK를 다시 빌드할 필요는 없습니다. 웹 배포 후 앱의 웹 화면에서 반영됩니다.
별도 이미지 ZIP은 관리자 업로드 또는 이미지 보관용입니다. 웹 패치에는 이미지가 이미 포함되어 있어 별도 업로드가 필요하지 않습니다.

## 검증과 범위

- 전체 자동 테스트 270개 통과(새 배너 관련 7개 포함).
- 실제 앱 진입 스크립트의 로딩 종료, 기존 비교/케이지/캠페인, 서버 배포 패키지 회귀 포함.
- 전체 클릭 → 기존 라우터 이벤트 → 실제 예시 데이터 서비스 → 캠페인 상세 표시 검증.
- 원본 3종의 비율과 구도, 내보낸 이미지 크기·용량 확인. PC 2배 이미지는 동일 구도의 해상도 변형입니다.
- 기존 167 소스 및 자산과 파일 단위로 비교했습니다.
- 실행 중인 사이트에 직접 배포하지 않았습니다. 실제 Galaxy·iPhone·Fold에서의 실행은 검증하지 않았습니다.
- 운영 배너 정보는 기존 유튜브 배너로 확인했습니다. 운영 캠페인 API의 직접 요청은 시간 초과되어, 상세 연결은 기존 예시 데이터와 코드로 검증했습니다.

검증 자료: verification/release-170/.
