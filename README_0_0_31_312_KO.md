# 0.0.31.312 · 화면별 BGM 및 음향 조정

- 광산, 월드맵, 후회없는 약탈 각각 반복형 BGM 추가.
- 오늘의 퀘스트는 월드맵 음악 유지. 재렌더/퀘스트 이동 때 처음부터 시작하지 않음.
- 화면 간 0.65초 크로스페이드, 영상 중 음악 음량 감소, 종료 후 복원.
- 기존 음향 버튼과 저장된 설정이 BGM/효과음에 함께 적용. 기기 미디어 음량 유지.
- 백그라운드/페이지 이탈 시 음악 중지, 복귀 때 재개. 음악 로드 경쟁과 중복 루프 방지.
- 성공 영상의 귀여운 차임을 저음 타악·승리 화음으로 교체. 실패/채굴/장착/획득/회수/메뉴/복권 사운드도 재제작.
- 처음 사용자 조작 후 브라우저가 음향을 허용하면 재생. 사운드 파일 실패는 게임 진행에 영향 없음.

검증: 음향 설정·장면 전환·중복 루프·기존 영상 음향 테스트 및 JS 구문 검사.
최종 음악 취향과 PC/모바일 체감 검수는 사용자 진행.
