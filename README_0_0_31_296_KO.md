# JCS 0.0.31.296 — 곡괭이별 전용 애니메이션 효과

- 어둠의 곡괭이 대기 오라의 폭을 약 28%, 베기 효과 크기를 약 21% 확대했습니다. 승인된 바닥 타격 효과는 유지합니다.
- 나머지 9종에 대기·베기·충돌 전용 이미지 프레임을 추가합니다. 기본 2종은 마법 오라 없이 먼지·금속 타격으로 표현합니다.
- 은빛은 은빛 입자, 금빛은 황금빛, 신비는 자수정, 차원은 오팔색 공간 균열, 천상은 빛·깃털, 번개는 전격, 바람은 바람과 곡괭이 잔상으로 구분합니다.
- 효과는 기존 5종족의 곡괭이 위치에 맞춰 움직이며, 두 번 채굴 시 빠르게 두 번 내리치는 모션은 유지합니다.
- 새 이미지 가장자리는 투명하게 처리하고 장착한 장비의 이미지만 필요할 때 불러옵니다. 새 효과 캐시는 최근 3종으로 제한합니다.
- 코드 문법과 배포 파일만 확인합니다. 실제 게임 화면과 체감 효과는 사용자가 검수합니다.
