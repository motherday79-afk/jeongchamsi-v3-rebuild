# JCS 0.0.31.218 · 폴리마블 주사위/캐릭터 연출 강화 패치

적용 기준: `0.0.31.217` 위에 덮어쓰기

## 이번 패치 범위
기존 1200×675 배경, 24칸, 게임룰, 점수, 전략카드, 랭킹은 **변경하지 않음**.
애니메이션/효과만 강화.

### 1. 주사위 투척 연출
- 버튼 클릭 후 주사위가 위에서 던져져 내려오는 느낌
- 빠른 회전 및 랜덤 눈금 변화
- 착지 후 짧은 바운스
- 실제 결과값 확정
- 약 0.2초 보여준 뒤 캐릭터 이동 시작

### 2. 캐릭터 한 칸 이동 연출
- 칸마다 점프
- 공중에서 그림자 축소
- 착지 시 짧은 눌림/복원
- 기존 칸 반응 애니메이션 유지

### 3. 최종 도착칸 결과 이펙트
- 점수 상승/보너스: 별, 스파클, 미니 축하 파티클 + 점수 팝업
- 점수 하락: 붉은 충격파, 깨진 하트/충격 파티클 + 감점 팝업 + 짧은 화면 흔들림
- 전략카드: 카드/보라 파티클
- 민심카드: 하트/물음표 파티클
- 운명의 선택: 물음표/저울 계열 파티클
- 이동 중간 칸에는 큰 이펙트 없이 점프/착지만 적용
