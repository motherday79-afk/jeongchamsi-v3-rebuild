# JCS 0.0.31.288 — 광고주 회차와 광산 성장 분리

광고주 변경 및 새 회차 시작 시 복권 참여·당첨 횟수와 현재 복권을 새로 시작합니다. 새 경품의 전체 당첨 수는 새 회차 기준으로 집계됩니다.

유지: 골드, 저장 광물, 채굴·인부·저장고 레벨, 일반·유료 곡괭이와 장착 상태, 캐릭터, 이전 당첨 및 경품 지급 기록. 진행 중인 채굴 시간도 초기화하지 않습니다.

상점·도움말·관리자 화면 안내를 같은 정책으로 수정했습니다. 이전 회차의 중복 회수 요청 방지 장치는 유지합니다.

곡괭이 제안 가격과 일반 회원 구매 레벨 조건은 이번 패치에서 변경하지 않았습니다.

문법 및 공백 검사만 수행했습니다. 화면·플레이 검수는 사용자 진행입니다.
