# 310 — 월드맵 상단 띠 제거 · 제목 그래픽 · 퀘스트 판 축소

- 월드맵 상단의 색상 띠, 테두리, 그림자를 제거했습니다. 광산으로 버튼은 유지합니다.
- 월드맵 제목을 투명 배경의 금색 입체 로고 이미지로 변경했습니다.
- 오늘의 퀘스트 제목을 짧은 두루마리 안에 직접 디자인했습니다.
- 퀘스트 판 최대 폭을 610px에서 380px로 줄였습니다.
- 지도에는 오늘의 퀘스트와 0/1 또는 1/1만 표시하고 진행률 문구를 삭제했습니다.
