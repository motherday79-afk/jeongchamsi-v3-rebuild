# 정참시 0.0.31.183 — JCS AI PANEL 관리자 단순화

기준본: `JCS_0_0_31_182(1).zip`

이번 패치는 JCS AI PANEL의 기존 저장/집계/LOCK/공개 엔진을 유지하면서 관리자 운영 화면을 비개발자 기준으로 단순화합니다.

## 관리자에서 매주 하는 일

1. `이번 주 조사 시작`
2. 갤럽·리얼미터 자료를 자동으로 불러오거나, 실패하면 HUMAN 숫자를 직접 입력
3. AI에게 보여줄 기사/자료 링크 등록
4. AI 응답 JSON 파일 선택
5. `결과 확정 및 게시`

패널 JSON, 출처 JSON 원문, BLIND 대조실험, 수동 검수/LOCK/게시 단계는 고급설정에 있습니다.

## 리얼미터

자동수집 코드는 존재하며 31.183에서 RSS/본문 형식 변화에 대한 허용 범위를 넓혔습니다. 다만 외부 사이트의 접속 제한·Cloudflare·사이트 개편 등은 서비스 외부 요인이므로 자동수집 실패 시 HUMAN 직접입력으로 계속 진행할 수 있게 했습니다.

## GitHub 적용

이 ZIP은 풀 프로젝트 기준입니다. 현재 31.182 위에 파일별로 선별 병합하기보다, 저장소 백업 후 이 버전을 기준으로 업로드하는 방식을 권장합니다.
