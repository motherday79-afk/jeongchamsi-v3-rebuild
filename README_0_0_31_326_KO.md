# 326 — 오만의 탑
- 월드맵에 전용 간판과 전체화면 탑 추가. 캐릭터 없이 마법 사슬의 자동 타격.
- 제한시간 30초, 1.5초 주기. 장비 채굴량·추가 타격 반영. 금덩어리는 채굴량에 따라 축소.
- 목표량 ceil(10 × 1.015^(층-1)). 서버에서 시작 장비·타격 계획과 결과 확정.
- 가장 강력한 보유 곡괭이 사용. 관리자는 전체 장비 테스트 권한 적용.
- 성공 시 다음 층 저장, 실패 시 현재 층 재도전. 광산 골드 지급/차감 없음.
- 다이아와 탑 전용 낫·해머 뽑기는 수치 미정으로 미구현. 기존 일일퀘스트 6개 유지.
- 사용자 화면·플레이 검수. 필수 로직 검증 후 배포.
