## 적용 기준
- 0.0.31.187 위에 덮어쓰기 하는 소형 패치입니다.
- 기존 프로젝트를 삭제하지 마세요.
- ZIP 내부 파일을 동일 경로에 덮어쓰면 됩니다.

## 핵심 변경
관리자 2단계 업로드를 `AI 응답파일`에서 `AI 통합파일` 방식으로 변경했습니다.

통합 JSON 한 파일에 다음을 함께 넣을 수 있습니다.
- ID
- 성별 / 연령 / 지역
- 직업군 / 학력 / 소득구간
- 가구형태 / 주거형태
- 정치관심도 / 뉴스소비 / 정치뉴스 노출 / 여론조사 노출
- 주요 판단 기준 / 주요 평가축
- choice / reason / explanation / factors

관리자에서 통합파일을 선택하면 내부적으로 다음을 자동 처리합니다.
1. 1,000개 ID 및 응답값 검증
2. 프로필 1,000개 추출
3. 기존 정식 패널의 인구구조 출처/기준일을 승계한 새 불변 패널 자동 생성
4. 같은 주차 새 RUN 생성(기존 게시본/과거 RUN 보존)
5. 최신 HUMAN 자료 자동 연결
6. EXPOSED 환경 자동 저장
7. 응답 1,000개 저장 및 자동 집계
8. `메인에 게시` 또는 `메인에 재게시` 가능

## 호환
- 기존 `응답 전용 JSON`도 계속 등록할 수 있습니다.
- 통합파일을 사용할 때는 기존 정식 1,000명 패널의 인구구조 출처와 기준일을 자동 승계합니다.
