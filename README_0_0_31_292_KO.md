# JCS 0.0.31.292 — 연속 타격과 무기 밀착 효과

- 2회 타격은 첫 타격 후 짧게 들어 올려 230ms 뒤 다시 내리칩니다. 3회 타격도 동일하게 연결합니다.
- 매 타격마다 충돌 효과를 따로 호출하며 마지막 타격 후 대기 자세로 복귀합니다.
- 무기 효과 범위를 날과 손잡이 주변으로 제한하고 몸 전체를 감싸는 확산을 줄였습니다.
- 내려칠 때만 150ms의 짧은 면 형태 섬광을 표시합니다. 이동 경로를 연결하는 선 잔상은 없습니다.
- 무기별 기존 텍스처, 광채, 번개, 깃털, 바람 분신은 유지하며 충돌 효과를 타격 지점에 집중시킵니다.
- 계정 데이터, 채굴 확률, 지급량, 코스튬은 변경하지 않습니다.

문법과 타격 스케줄을 확인했습니다. 실제 PC·모바일 플레이 및 시각 검수는 사용자가 진행합니다.
