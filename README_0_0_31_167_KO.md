# JCS_0_0_31_167 — 케이지 제목 중앙정렬·Android 인트로 연결

기준 버전: `JCS_0_0_31_166`.

- 케이지 제목의 실제 글자 높이를 측정하여, 상단 검정 스크린의 중앙에 한 줄 또는 두 줄을 하나의 묶음으로 배치합니다. 특정 제목에만 고정 위치를 주지 않습니다.
- 승인한 2번 Black Han Sans 폰트, 첫째/둘째 줄 강조, 관리자 줄바꿈 선택을 유지합니다. 글자를 가로로 늘리거나 줄바꿈을 새로 결정하지 않습니다.
- LIVE는 기존 166과 동일하게 VS 위에 둡니다. 원본 배경·좌우 50:50 진영 글쓰기·백분율 표시·클릭 영역도 유지합니다.
- Android 1.1.167이 웹 화면 준비를 확인할 수 있도록 `#app`에 준비 상태만 표시합니다. JavaScript 네이티브 인터페이스나 서버 호출은 추가하지 않습니다.

## 적용

이미 166을 사용 중이면 PATCH ZIP을 압축 해제하여 같은 경로 파일을 덮어씁니다.
전체 소스가 필요하면 FULL인 `JCS_0_0_31_167.zip`을 사용합니다. PATCH 기준이 다른 버전이면 먼저 166 또는 전체 167 소스를 사용하세요.
Android 소스는 별도 앱 빌드 ZIP에 있습니다. 이 웹 패치는 APK를 생성하지 않습니다.

## 검증

- 웹 전체 263개 테스트 통과. 서버 배포 패키지·홈 로딩·비교/케이지 진영 선택 등 기존 회귀 포함.
- 원본 폰트의 글리프 메트릭 12,266개와 93개 제목 배치 검증.
- 이전 버전 대비 관리자 줄바꿈 유효성 588개 사례 동일.
- 실제 글자 묶음 중심 Y=206.5: 원본 1774×887 배너의 상단 스크린 내부 기준.
- 모든 기존 배너/로고/배지/폰트/데이터/API/의존성 바이트 유지.
- 실제 브라우저 화면·운영 데이터·배포는 검증 범위에 포함하지 않습니다.
