# JCS 0.0.31.243 · 전략카드 확인 UX + 거점 소유 표시 통합 패치

## 이번 패치 범위
31.242까지 승인된 1P/2P 정보, TODAY RANKING, 전략카드 4슬롯 좌표는 유지합니다.
이번 패치는 아래 두 기능만 추가/교정합니다.

### 1. 전략카드 클릭 UX
- 전략카드를 한 번 클릭했다고 즉시 소모되지 않습니다.
- 클릭 시 중앙 확인 팝업에 카드 아이콘 / 카드명 / 효과 설명을 표시합니다.
- `사용하기`를 눌렀을 때만 효과가 적용되고 카드가 소모됩니다.
- `취소` 시 카드는 그대로 보유합니다.
- 이미 같은 지속 효과가 활성화된 경우 `사용하기` 버튼을 비활성화하고 이유를 표시합니다.
- 이동권은 확인 후 카드가 소모되고 기존 정참시 투어 선택 흐름으로 이어집니다.
- AI의 전략카드 자동 사용 로직은 기존 그대로 유지합니다.

### 2. 거점 소유 표시
- 기존 타일 `::after` 기반 `1P·L1 / AI·L1` 표시 방식은 완전히 비활성화합니다.
- 1672×941 논리 캔버스 안에 별도의 소유 마커 레이어를 사용합니다.
- 실제 구매 가능한 거점에만 픽셀 좌표를 지정해 소유 마커를 표시합니다.
- 이벤트 / 카드 / 코너 칸에는 소유 마커를 만들지 않습니다.
- 1P는 블루, AI는 핑크 마커를 사용하며 강화 단계 `L1~L4`를 표시합니다.
