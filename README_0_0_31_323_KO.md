# 0.0.31.323 — 숲 나뭇잎 음표와 계곡 금화 분산

- 노래하는 숲 PC 키를 A/S/D/F/G로 변경. 버튼/접근성 이름/도움말 함께 변경.
- 다이아몬드 음표를 잎맥·줄기·그라데이션이 있는 5색 벡터 나뭇잎으로 변경. 버튼에도 같은 잎 테마 적용.
- 망자의 계곡은 묶음별 고정 방향 대신 매 금화마다 좌우를 정함. 440~700ms 간격으로 지속 등장하며 같은 쪽 연속도 가능.
- 타격 전후 320ms 위험 위치 회피 유지. 세션 규칙 버전 갱신으로 구버전 플레이와 혼합 방지.
- 게임 판정/서버/금화 전량수집 회피 테스트 10개 통과. 구문 및 diff 검사 통과.
- 실제 화면·플레이 검수는 사용자가 진행.
