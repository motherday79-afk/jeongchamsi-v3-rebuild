# JCS 0.0.31.228 · POLIMARBLE 남2 캐릭터 테스트 패치

## 이번 단계 범위
- 31.227에서 승인한 단일 보드/백그라운드 구조를 그대로 유지합니다.
- 게임 규칙, 주사위, 민심 계산, 타일 이동 로직은 추가하지 않습니다.
- 남2 캐릭터 시트를 실제 사용 객체 7개로 분리했습니다.

## 캐릭터 개별 PNG
- `male2-front.png` : 선택창용 정면
- `male2-token.png` : 게임말
- `male2-profile.png` : 1P 프로필
- `male2-move.png` : 이동 반응
- `male2-win.png` : 승리 반응
- `male2-fail.png` : 실패/당황 반응
- `male2-emotion.png` : 감정컷

모두 투명 PNG이며 서로 독립 파일입니다.

## 화면 적용
- 1P 프로필 빈 원형 영역에 `male2-profile.png` 적용
- START 칸 위에 `male2-token.png` 적용
- 게임말을 클릭하면 `이동 → 승리 → 실패 → 감정컷` 순서로 중앙에서 테스트 표시
- 이는 캐릭터 자산 확인용 인터랙션일 뿐 게임 규칙이 아닙니다.

## 중요
- 기존 보드 이미지를 새 이미지로 덮어씌우지 않습니다.
- 보드 베이스는 31.227의 `polimable-board-base-31-227.png` 단 한 장을 계속 사용합니다.
- 캐릭터는 보드 이미지에 합성하지 않고 독립 DOM/PNG 객체로만 올립니다.
