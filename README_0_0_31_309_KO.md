# 309 — 월드맵 제목 정렬 및 전체 화면 퀘스트 기록

- 광산·약탈 간판 내부에 제목을 이미지로 직접 디자인했습니다.
- 나의 광산의 돌아가기, 지도 위 약탈 횟수를 제거했습니다. 횟수는 약탈 내부에서 확인합니다.
- 상단 제목은 월드맵으로 변경하고 X를 제거했습니다. 광산으로는 유지합니다.
- 오늘의 퀘스트에는 완료 개수와 진행률만 표시합니다.
- 퀘스트 판을 누르면 전체 화면 두루마리에서 완료한 일·앞으로 할 일·남은 도전을 확인합니다.
- 퀘스트 페이지도 뒤로가기 이동 기록에 포함됩니다.
- 상단과 퀘스트 제목에는 붓글씨·금속색 장식 타이포그래피를 적용했습니다.

## 남은 요청
캐릭터가 실제로 행동하는 새 성공·실패 영상은 현재 영상 생성 도구가 없어 제작하지 못했습니다.
기존 이미지 연출을 영상으로 바꾸었다고 표시하지 않았으며, 이번 패치에는 새 영상이 포함되지 않습니다.

검사: 수정 JS 문법 및 퀘스트 페이지 이동 기록 검사. 화면 검수는 사용자 진행.
