# JCS 0.0.31.206 · POLIMARBLE CURRENT POSITION CLEANUP

## 이번 수정의 단일 목적
폴리마블의 현재 위치를 표시하던 **노란 반짝임/펄스/테두리 표시를 완전히 제거**합니다.
현재 위치는 오직 실제 플레이어 미니미 하나만 보여줍니다.

## 제거
- 현재 칸 노란 테두리
- 현재 칸 반복 반짝임(pulse)
- 게임 보드 위에 추가로 얹던 S/1/2/... 위치 번호 배지
- `is-active` 시각 상태

## 유지
- 정확히 24칸 이동 경로
- 주사위 수만큼 한 칸씩 순차 이동
- 이동 중 캐릭터의 짧은 `총총` hop 애니메이션
- 이동 완료 후 캐릭터 정지
- 점수/카드/게임오버/기록/Redis 랭킹 로직
- PC / 모바일 가로모드 레이아웃

## 완료 기준
- 정지 상태에서 어떤 보드 칸도 깜빡이거나 빛나지 않는다.
- 현재 위치는 미니미의 위치만으로 확인한다.
- 이동 중에도 칸 자체는 점멸하지 않는다.
