# JCS 0.0.31.206 · 폴리마블 24칸 보드 패치

## 적용 기준
- **JCS 0.0.31.205 위에 그대로 덮어쓰기**
- 기존 `1200 × 675px` 폴리마블 백그라운드 이미지는 **수정하지 않음**

## 승인 반영 사항
1. 24개 칸은 하나의 이미지가 아니라 **각각 독립된 게임 객체**로 구성
2. START 위치는 **오른쪽 하단**
3. 진행 방향은 **오른쪽 하단 → 왼쪽 → 왼쪽 위 → 상단 오른쪽 → 오른쪽 아래 → START 복귀**
4. 배치 수
   - 하단 8칸
   - 좌측 4칸
   - 상단 8칸
   - 우측 4칸
   - 총 24칸
5. 각 칸은 기존 폴리마블 게임 요소를 그대로 사용
   - 점수 + / -
   - 전략 카드
   - 민심 카드
   - 운명의 선택
   - 안전지대
   - 퍼센트 감점 등
6. 배경의 국회의사당/도시가 가려지지 않도록 **모든 칸을 반투명 처리**
7. 특히 상단 8칸은 국회의사당 윗부분과 배경이 더 잘 보이도록 **다른 구간보다 투명도를 더 높임**
8. 백그라운드와 홈 사이드바 게임 바로가기 디자인은 그대로 유지
