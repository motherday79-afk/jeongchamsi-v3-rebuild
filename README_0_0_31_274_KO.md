# 정참시 0.0.31.274 — 폴리마블 서비스 제거

- PC·모바일 공통 홈의 폴리마블 카드와 진입 버튼을 제거했습니다.
- 게임 모듈·스타일·이벤트 연결과 홈 순위 조회를 제거했습니다.
- 기존 /polimable 주소 및 하위 경로는 정참시 홈으로 이동합니다. 해시 주소도 홈으로 이동합니다.

이미 열어둔 화면은 새로고침해야 제거가 반영됩니다.

검증: 제거·홈 구성·홈 시작·페이지 이동 관련 테스트 25개 통과. PATCH를 273에 적용한 결과가 274 FULL과 일치하는지 검증합니다.
