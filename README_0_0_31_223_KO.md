# JCS 0.0.31.223 · 아이폰 가로 화면 플레이 패치

적용 대상: `0.0.31.222`

## 반영 내용
- 아이폰 세로 상태에서 `/polimable` 진입 시 `가로 화면으로 플레이` 버튼 표시
- 버튼을 누르면 기기 방향을 강제하지 않고 **게임판 자체를 90도 회전**하여 가로형으로 표시
- 1200×675 게임판 비율 유지
- 현재 아이폰 화면 크기에 맞춰 자동 축소
- 게임 기능/버튼/24칸/게임말/주사위/점수/카드/랭킹은 그대로 동작
- 상단에 `세로 화면으로 돌아가기` 버튼 제공
- 아이폰을 실제 가로로 돌린 경우에는 기존 가로형 보드 그대로 표시
- PC/안드로이드 동작에는 영향 없음
