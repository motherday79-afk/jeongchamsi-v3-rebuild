# JCS 0.0.31.191 — AI PANEL 원클릭 게시 핫픽스

## 적용 기준
- 31.190 적용 상태 위에 덮어쓰기
- 기존 프로젝트 전체 삭제 금지
- ZIP 내부 파일을 동일 경로에 덮어쓰기

## 수정 내용
1. `메인에 게시/재게시` 클릭 시 기존의 `검수 -> LOCK -> 게시` 3회 API 요청을 제거했습니다.
2. 서버에서 `finalize` 1회 요청으로 검수/LOCK/게시를 한 번에 처리합니다.
3. 이전 게시 실패로 RUN 상태가 `reviewed` 또는 `locked`에 남아 있어도 같은 버튼으로 이어서 게시할 수 있습니다.
4. Redis/저장소 계층 오류를 `AI_PANEL_REQUEST_FAILED`로 뭉개지 않고 `AI_PANEL_STORAGE_FAILED`로 구분합니다.
5. 저장소가 일시적으로 실패한 경우 AI/HUMAN 데이터는 유지되며 게시 버튼만 다시 누를 수 있도록 안내합니다.
6. 브라우저 캐시 무효화를 위해 AI PANEL 관련 모듈 버전을 `0.0.31.191`로 올렸습니다.

## 검증
- AI PANEL 핵심 테스트 35개 통과
- 실제 통합 1,000명 파일로 프로필/응답/HUMAN 연결 후 `finalize` 실행 확인
- 최종 게시 상태 `published` 확인
- finalize 단계 Redis commit 1회 확인
- JS 구문 검사 통과
