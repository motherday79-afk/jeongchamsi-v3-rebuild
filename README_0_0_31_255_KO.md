# 정참시 255 · 폴리마블 칸 디자인 편집

## 사용 순서

1. 관리자 로그인 후 폴리마블에서 **배치 편집**을 누릅니다.
2. **칸 디자인 · 이름·색상·방향**을 선택합니다.
3. 칸을 선택하고 이름, 글자색, 배경색, 가로/세로쓰기, 회전 각도, 글자 크기를 바꿉니다.
4. 두 가지 색의 특수 모양은 **위·아래 5:5 색상 사용**을 켜고 위/아래 색을 각각 고릅니다. 소유 여부와 무관하게 표시됩니다.
5. 글자를 끌어 위치를 바꾸거나 방향 버튼으로 조금씩 옮깁니다. **칸 방향 맞춤**은 해당 줄의 기본 기울기에 맞춥니다.
6. **미리보기**로 확인하고 **전체 반영**을 누릅니다. 전체 반영 전 변경은 이 기기에만 임시저장됩니다.

## 깃발·건물

**깃발·건물 · 위치·크기** 메뉴를 따로 제공합니다. 구매 가능한 칸을 선택한 뒤 **소유 깃발 / 건물 강화 1·2·3단계**를 선택하세요. 아직 구매하지 않은 칸도 편집용 오브젝트가 표시됩니다. 끌어서 이동하거나 크기를 조절하고 전체 반영하면 실제 구매·강화 시 그 설정을 사용합니다. 시작·전략카드·큰 이벤트 칸은 구매 대상이 아니므로 깃발·건물 위치 선택에서 제외됩니다.

각 단계의 위치는 독립적으로 저장됩니다. 깃발만 옮겼다면 건물 1~3단계도 필요에 따라 각각 맞춰주세요. 캐릭터 위치는 **캐릭터 · 칸별 위치**에서 조절합니다.

## 유지되는 사항

- 기존 캐릭터·깃발·건물 위치 및 숨김 설정을 이전 저장 형식에서 자동으로 읽어옵니다.
- 변경 이름은 보드, 칸 선택 목록, 구매·강화 안내에 반영됩니다.
- 이름·색상 변경은 게임 가격, 효과, 소유·강화 규칙을 바꾸지 않습니다.
- 기존 보드 이미지는 보관하며, 글자가 있던 칸 표면만 글자 없는 이미지로 덮고 편집 가능한 글자를 별도로 표시합니다.
- 되돌리기, 이전 전체 배치 복구, 설정 파일 내보내기·불러오기와 동시 저장 충돌 차단을 유지합니다.

## 검증

- 관련 자동 테스트 25개 통과, 실패·건너뜀 없음. 전체 프로젝트 테스트를 의미하지 않습니다.
- 실제 로컬 브라우저에서 이름·5:5 색상·회전·세로쓰기·색상 변경·되돌리기를 확인했습니다.
- 로컬 저장 후 새로고침 및 이름 동기화 확인.
- 로컬 게임 소유 상태를 1~4단계로 설정한 검증 화면에서, 편집한 깃발/건물의 위치·크기가 실제 게임 렌더링에 동일하게 적용되는지 확인했습니다. 해당 검증용 상태 주입은 배포 소스에 포함하지 않습니다.
- PC 및 844×390 모바일 가로 뷰포트 확인. 실제 휴대폰 기기 테스트는 하지 않았습니다.
- 운영 배포 결과는 별도 배포 확인 기록을 참조하세요.
