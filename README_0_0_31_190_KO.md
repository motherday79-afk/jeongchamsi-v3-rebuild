# JCS 0.0.31.190 · AI 통합파일 업로드 유지 핫픽스

기준: 31.189 적용 상태

## 수정 내용
- AI 통합파일 업로드 성공 후 2번 파일 선택 영역을 다시 렌더링하지 않음
- 선택한 파일명이 브라우저에서 사라지는 현상 제거
- 업로드 성공 후 3번 메인 게시/재게시 카드만 새 RUN 기준으로 갱신
- 새 RUN ID를 명시적으로 우선 선택해 과거 RUN이 다시 잡히는 문제 방지
- 처리 진행상태를 단계별로 표시
  - 1,000명 검증
  - 정식 패널/HUMAN 확인
  - 프로필 저장
  - 새 RUN 생성
  - HUMAN 연결
  - 정보환경 저장
  - AI 응답 저장/집계

## 적용
현재 프로젝트는 삭제하지 말고, ZIP 안의 파일을 동일 경로에 덮어쓰기 합니다.
