로그인하러 가기

설정은 브라우저별로 적용됩니다. 삼성인터넷과 Chrome을 모두 켜면 같은 소식을 두 번 받을 수 있습니다. 로그아웃하면 해당 계정의 기기 알림이 해제되므로 다시 켜 주세요.

내 휴대폰에서 시작하기

ANDROID

삼성인터넷 · Chrome

  1. 삼성인터넷 또는 Chrome에서 www.jeongchamsi.com을 열고 로그인합니다.
  2. 마이페이지 → 웹 알림 설정으로 들어옵니다.
  3. 알림 켜기를 누르고 브라우저의 알림 요청을 허용합니다.
  4. 내 기기로 테스트 알림 보내기를 누른 뒤 상단 알림창을 내려 확인합니다.

APK 설치나 홈 화면 아이콘 추가는 필수가 아닙니다. 알림은 삼성인터넷 또는 Chrome을 통해 표시됩니다.

iPHONE · iOS 16.4 이상

Safari에서 홈 화면으로

  1. Safari에서 www.jeongchamsi.com/notifications를 엽니다.
  2. 공유 버튼 → 홈 화면에 추가 → 추가를 누릅니다. 공유 버튼이 안 보이면 메뉴(···) 안을 확인해 주세요. ‘웹 앱으로 열기’가 보이면 켭니다.
  3. Safari 화면을 나와 홈 화면의 정참시 아이콘을 누릅니다.
  4. 필요하면 다시 로그인한 뒤 마이페이지 → 웹 알림 설정 → 알림 켜기 → 허용을 누릅니다.
  5. 내 기기로 테스트 알림 보내기를 누릅니다. 알림 센터나 잠금 화면에서 확인할 수 있습니다.

Safari 탭만 열어서는 iPhone 웹 푸시를 켤 수 없습니다. ‘홈 화면에 추가’가 없으면 공유 메뉴의 동작 편집에서 추가해 주세요.

알림이 보이지 않을 때

  • 안드로이드: 휴대폰 설정 → 알림 → 앱 알림에서 삼성인터넷 또는 Chrome의 알림을 허용해 주세요. 브라우저의 사이트 설정에서도 정참시 알림이 차단되어 있지 않은지 확인합니다.
  • 아이폰: 설정 → 알림 → 정참시에서 알림을 허용하고, 홈 화면 아이콘으로 접속했는지 확인해 주세요.
  • 카카오톡 안에서 열었나요? 메뉴에서 다른 브라우저로 열기를 선택해 삼성인터넷·Chrome 또는 Safari로 이동해 주세요.
  • 방해금지·집중 모드, 절전 설정과 네트워크 상태에 따라 표시가 늦어질 수 있습니다. 이미 차단했다면 기기 설정에서 허용한 뒤 이 페이지를 다시 열어 주세요.

‘발송 접수’는 푸시 서비스가 요청을 받았다는 뜻입니다. 실제 도착 여부는 기기의 알림창에서 확인해 주세요.
