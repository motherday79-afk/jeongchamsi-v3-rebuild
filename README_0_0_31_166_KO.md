# 정참시 0.0.31.166 — 케이지 제목 폰트 · LIVE 위치

이번 파일은 165 작업 상태에 다음 두 변경을 더한 배포용 소스입니다.

- 선택한 **2번 Black Han Sans**를 케이지 제목에 적용했습니다. 승인한 예시의 글자 크기·자간·비율·아이보리에서 골드로 이어지는 색상을 기준으로 합니다. 제목은 실제 게시글 텍스트이며, 다른 제목으로 바꾸어도 같은 폰트를 사용합니다.

## 적용 방법

1. 현재 소스가 **165까지 적용된 상태**라면 `JCS_0_0_31_166_PATCH.zip`을 풀어 기존 프로젝트의 같은 경로에 덮어쓰세요. 이번 패치의 새 폰트·이미지·CSS 파일도 함께 올려야 합니다.
2. 전체 소스를 교체하거나 현재 적용 버전이 불확실하면 `JCS_0_0_31_166.zip`만 사용하세요. 전체 파일에는 166 패치 내용이 모두 포함돼 있습니다.
3. ZIP 자체를 웹사이트 파일로 올리는 방식이 아니라, 압축을 푼 내용을 기존 프로젝트 루트에 적용한 뒤 기존 방식대로 배포합니다. 환경변수는 기존 설정을 유지합니다.

두 ZIP을 모두 적용할 필요는 없습니다. 배포 후에는 새로고침으로 최신 화면을 확인하세요.
