# 327 — 탑 중심 월드맵과 손잡이 축 타격
- PC/모바일 월드맵을 새 일러스트로 교체. 탑을 중앙 대형 건축물로, 5개 장소를 주변에 배치.
- 간판을 각 장소 좌표에 정렬하고 오만의 탑을 가장 크게 표시.
- 최신 요청 반영: 새 곡괭이 원본에서 시계 방향 90도 고정, 손잡이 끝을 축으로 들어 올리고 빠르게 호를 그려 타격. 단순 상하 이동 아님.
- 사다리처럼 보이던 사슬 제거. 축소된 금덩어리에 맞춰 타격 높이 조정.
- 시작/다음 층/재도전/성공/실패를 디자인 이미지로 교체. 동적 숫자와 오류 안내는 텍스트 유지.
- 서버 난이도·장비·층 저장은 변경 없음. 사용자 화면 검수.
