# JCS 0.0.31.209 · 폴리마블 게임룰 연결 패치

## 적용 기준
- **31.208 위에 그대로 덮어쓰기**
- 승인된 1200×675 배경, 24칸 연결 띠, 타일 색/크기, 게임말 디자인과 이동 애니메이션은 변경하지 않음

## 이번 패치에서 연결한 실제 게임룰
- 로그인 회원 GAME START / 기존 세션 이어하기
- 서버 주사위 결과 사용 (로컬 랜덤 주사위 제거)
- 주사위 결과만큼 게임말이 24칸을 한 칸씩 총총 이동
- 도착한 칸의 서버 게임룰 적용
  - 점수 상승 / 하락
  - 비율 감점
  - 전략카드 획득
  - 민심카드 랜덤 이벤트
  - 운명의 선택(안전 / 승부수)
  - 안전지대
  - START 보너스
- 민심 SCORE / 최고기록 / STAGE 표시
- 전략카드 최대 3장 표시 및 클릭 사용
- 적용 중인 카드 효과 요약 표시
- 기록하고 종료 → TODAY RANKING 저장
- TODAY RANKING 상위 4명 표시
- GAME OVER / 기록보험 처리
- 진행 중 게임은 기존 2시간 서버 세션 + 브라우저 세션키로 이어하기

## 디자인 관련
- 31.208의 보드 디자인은 그대로 유지
- `지역공감 +150` 한 칸만 반투명 유지
- 나머지 23개 칸 불투명 유지
- 오른쪽 배경에 이미 존재하는 빈 주사위/점수/전략카드/랭킹 영역 위에 실제 데이터만 얹음
- 새로운 페이지 구조나 임의 디자인 추가 없음
