# JCS 0.0.31.283

- 공동 잭팟 클릭 시 적립액과 잭팟 설명만 표시합니다. 추첨·지급은 준비 중이라는 현재 상태를 명시합니다.
- 관리 → 내 계정에 테스트 골드 지급: 1~1,000,000 G를 입력해 즉시 추가합니다. 관리자 본인만 가능하며 요청 재시도 시 중복 지급하지 않습니다. 최근 50건의 지급 기록을 저장합니다.
- 광고주 이미지: 관리 → 광고주 이미지·링크에서 JPG/PNG/WebP(1MB 이하)를 선택하고 광고 설정 저장을 누르세요. 권장 크기는 800×450px입니다. 기존 업로드 기능을 유지하며 관리 메뉴를 광고·골드로 표시합니다.
- 골드 지급과 광고 이미지 권한, 잭팟 적립 등 관련 테스트 6개 통과. 운영 화면 검수는 사용자 진행.
