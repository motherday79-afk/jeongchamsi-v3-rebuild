# JCS 0.0.31.198 — HUMAN POLL 붙여넣기 운영 전환

## 적용 기준
- 0.0.31.197 위에 덮어쓰는 패치입니다.
- 기존 AI PANEL / 게시 / 과거기록 구조는 유지합니다.

## 핵심 변경
1. 관리자 HUMAN 입력을 `JCS HUMAN POLL 붙여넣기` 중심으로 변경
   - ChatGPT에서 조사·검증한 한국갤럽 / 리얼미터 / NBS 최신 데이터를 JSON 하나로 붙여넣습니다.
   - `HUMAN 데이터 검증·등록` 버튼 1회로 3기관을 함께 저장합니다.
   - 기존 단일 기관 텍스트 붙여넣기도 계속 호환됩니다.
2. 자동수집은 보조 기능으로 이동
   - `보조 · 자동수집 시도` 안에 접어서 유지합니다.
   - 자동수집 결과는 초안/확인용이며 최종 HUMAN 데이터는 JCS HUMAN POLL 붙여넣기를 권장합니다.
3. HUMAN 상세 교차자료 지원 확대
   - 전체 / 성별 / 연령 / 지역의 N, 긍정, 부정, 유보 값을 JSON에서 일괄 등록할 수 있습니다.
   - 확인되지 않은 값은 null로 둘 수 있습니다. 임의 추정하지 않습니다.
4. HUMAN 붙여넣기 본문 허용량 확대
   - 최대 약 240KB JSON 입력을 받을 수 있도록 HTTP 본문 제한을 확대했습니다.
5. 공개 AI 명칭 변경
   - 메인 및 여론조사 상세의 AI 표기를 `JCS AI ID INTELLIGENT AGENT · N1000` 기준으로 변경했습니다.
   - 공개 화면의 `CHATGPT 관리자 통합파일 업로드` 문구는 제거했습니다.

## 관리자 운영 흐름
1. ChatGPT에서 `이번 주 JCS HUMAN POLL 실행해줘` 요청
2. 생성된 `JCS_HUMAN_POLL_V1` JSON 전체 복사
3. 관리자 > AI 여론조사 > `JCS HUMAN POLL` 입력창에 붙여넣기
4. `HUMAN 데이터 검증·등록`
5. AI 통합파일 등록
6. 메인 게시 / 재게시

## 검증
- 2026-09-19 JCS HUMAN POLL 3기관 JSON 파싱 성공
- 한국갤럽 / 리얼미터 / NBS 3건 일괄 저장 모의 테스트 성공
- 과거 단일 기관 수동 붙여넣기 형식 호환 유지
- 변경 JavaScript Node syntax check 통과

## 주의
- 기관별 최신 조사 발표일과 조사기간은 서로 다를 수 있습니다.
- 성별/연령/지역의 N 또는 유보 수치가 현재 확인된 출처에서 직접 검증되지 않은 경우 null을 유지합니다.
- null은 0이 아니며, 정참시 화면에서는 미제공으로 처리합니다.
