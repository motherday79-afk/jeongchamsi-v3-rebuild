# JCS 0.0.31.294 — 어둠의 곡괭이 전용 연출

- 어둠의 곡괭이만 전용 이미지 기반 효과로 교체합니다.
- 검은 불꽃 4장, 흑적색 참격 4장, 붉은 균열 폭발 4장의 투명 아틀라스를 새로 제작했습니다.
- 대기 중 불꽃을 이어 재생하고, 무기를 들어 올리면 기운이 좁아지고 날의 붉은 빛이 강해집니다.
- 휘두름에 맞춘 190ms 참격과 타격 지점의 720ms 균열·검은 불꽃·잔불을 연결합니다.
- 검은 질감은 기본 합성으로, 붉은 발광은 별도 가산 합성으로 표시합니다.
- 곡괭이 위치와 각도를 따라가며 얼굴과 몸을 덮는 화면 전체 효과는 추가하지 않습니다.
- 5종족의 어둠 곡괭이에 공통 적용하며 다른 무기, 코스튬, 연속 타격 시간, 게임 데이터는 유지합니다.
- 해당 무기 선택 시 전용 WebP 1장만 로딩합니다. 숨긴 창의 중지·움직임 줄이기를 따릅니다.

문법 및 렌더러 호출 검사만 수행했습니다. 실제 플레이·시각 검수는 사용자가 진행합니다.
