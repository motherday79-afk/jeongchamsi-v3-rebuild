# JCS 0.0.31.251 · POLIMARBLE DIAMOND PRECISION REMAP

## 목적
31.250 신규 다이아몬드 보드 객체 시스템에서 확인된 좌표/배치 문제를 해결합니다.

이번 패치는 게임룰을 확장하지 않고 다음 세 영역만 정밀 재매핑합니다.

1. 1P / 2P 프로필과 민심·바퀴·자산 정보
2. 32개 모든 칸의 캐릭터 착지 좌표 + 동일 칸 2인 분리 좌표
3. 24개 기업칸의 소유깃발/강화오브젝트 공용 좌표

## 변경사항

### 플레이어 HUD
- 1P 프로필 원형 프레임 내부로 크기/위치 재조정
- 2P 프로필도 동일 기준 적용
- 플레이어명 / 민심 / 바퀴·자산을 각각 픽셀 좌표로 고정
- 흰색/아이보리 텍스트 + 짙은 그림자로 모바일 가독성 강화

### 캐릭터 착지
- 기존 CSS `left:50%; top:50%` 중앙 고정 문제 제거
- `--pm-token-x`, `--pm-token-y` 좌표만 캐릭터 위치를 결정하도록 통일
- 게임 시작 시 두 캐릭터 모두 START에 배치
- 모든 32칸에 `solo / p1 / p2` 착지점을 정의
- 혼자 도착하면 칸 중심
- 두 플레이어가 같은 칸이면 해당 칸 방향에 맞춰 나란히 분리

### 소유 / 강화 오브젝트
- 24개 기업칸 각각의 실제 중심에서 보드 외곽 방향으로 공용 오브젝트 좌표를 계산
- 기업명 위를 가리지 않도록 보드 외곽쪽으로 이동
- 최초 소유: 1P/2P 깃발
- 강화 1/2/3: 동일 좌표에서 해당 단계 건물 하나만 표시
- 카드칸 / START / 희망의 재단 / 운명의 선택 / 욕망의 굴레에는 소유 오브젝트 없음

### 디버그
- URL에 `?pmdebug=1`을 붙이면 객체/앵커 검수용 디버그 표시 사용 가능
- 일반 사용자 화면에서는 표시되지 않음

## 변경하지 않은 것
- 보드 백그라운드 이미지
- 기업명/가격
- 게임 경제 룰
- AI 판단 룰
- 주사위 확률/액션
- BGM/효과음
- 모바일 전체화면/중앙정렬 로직
- 특수칸 룰

## 검수 포인트
1. 게임 진입 즉시 1P/2P가 START에 정확히 보이는지
2. 1P/2P 프로필과 텍스트가 상단 박스 안에 정확히 들어가는지
3. 32칸 이동 후 캐릭터 발 위치가 각 칸 중앙에 맞는지
4. 같은 칸에 1P/2P가 도착했을 때 서로 가려지지 않는지
5. 기업 구매 후 깃발이 해당 기업과 명확히 연결되어 보이는지
6. 강화 시 깃발 → 건물1 → 건물2 → 건물3이 같은 위치에서 교체되는지
