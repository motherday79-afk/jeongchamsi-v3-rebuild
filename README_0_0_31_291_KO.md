# JCS 0.0.31.291 — 곡괭이별 코스튬과 잔상 정리

- 동작 경로를 선으로 연결하는 잔상을 제거했습니다. 광채, 무기 기운, 타격 효과는 유지합니다.
- 신비한·차원·어둠·천상·번개·바람 곡괭이 장착 시 5종족의 의상이 함께 바뀝니다.
- 총 30개 조합, 조합별 8프레임의 통합 캐릭터·곡괭이 모션을 추가했습니다.
- 숙련자의 곡괭이까지 4종은 기존 의상을 유지합니다.
- 코스튬은 장착 곡괭이에 자동 연동되며 별도 구매나 설정은 없습니다.
- 골드, 레벨, 구매 조건, 채굴 수치 등 계정과 경제 데이터는 변경하지 않습니다.

관리자 계정에서 곡괭이 상점 → 장착 후 캐릭터를 바꿔 확인할 수 있습니다.
이미지는 내장 이미지 생성 도구로 의상만 편집했습니다. 제작 프롬프트는 별도 제작 기록에 보관합니다.
문법과 파일 구성만 확인하며 실제 PC·모바일 시각 검수는 사용자가 진행합니다.
