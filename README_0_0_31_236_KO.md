# JCS 0.0.31.236 · POLIMARBLE HUD Pixel Alignment 2차

## 목적
31.235 실제 정참시 화면에서 확인된 HUD 정렬 문제만 보정합니다.

## 변경 범위
- 1P 정보(이름 / 민심 / 바퀴·자산) 각각 독립 좌표화
- 2P 정보(이름 / 민심 / 바퀴·자산) 각각 독립 좌표화
- TODAY RANKING 1·2·3행 각각 독립 좌표화
- 전략카드 4칸 각각 실제 슬롯 좌표로 고정
- 전략카드 크기 축소 및 슬롯 중앙 정렬
- 전략카드 보드에는 설명문을 제거하고 카드명 중심으로 표시
- 타일 소유 배지(AI·L1 등)가 타일 밖으로 튀어나오지 않도록 오버플로우 제한 및 내부 위치 보정

## 변경하지 않은 것
- 게임룰
- 캐릭터 이동 좌표 및 이동 속도
- AI 턴 로직
- 주사위 로직 및 더블 판정
- 배경 이미지
- 거점 구매 / 강화 / 인수 계산

## 적용 기준
배경 이미지(1672×941)를 기준으로 HUD 요소를 퍼센트 좌표로 직접 고정했습니다. 브라우저에서 1200×675 등으로 축소되어도 같은 상대 위치를 유지합니다.
