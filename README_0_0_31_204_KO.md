# JCS 0.0.31.204 · POLIMARBLE DESIGN REBUILD

## 적용 기준
- **31.203 위에 그대로 덮어쓰기**
- 기존 게임 엔진 / Redis 저장 / 랭킹 / 전략카드 / 순차 이동 로직은 유지
- 이번 버전은 **게임 화면 디자인 레이어를 다시 구축한 패치**입니다.

## 가장 중요한 수정 원칙
사용자가 승인한 `폴리마블(2).png`의 디자인을 재해석하지 않습니다.

이번 버전에서는 31.203처럼 승인 이미지를 게임 화면 전체의 background로 깔지 않습니다.
로고, 풍경, 건물, 보드 타일, 퍼플 조작 패널, 주사위, 전략카드, 랭킹을 **실제 HTML/CSS/SVG UI로 다시 만들었습니다.**

승인안과 달라지는 구조는 게임을 실제로 진행하기 위한 **보드 칸 수 확장(24칸)** 뿐입니다.

## 31.204 변경사항

### 1. 전체 승인 이미지 background 제거
- 게임 본문 CSS에서 `DESIGN_SOURCE_OF_TRUTH` 이미지 참조 제거
- 승인 이미지는 더 이상 실제 게임 화면의 밑그림으로 사용하지 않음
- 따라서 승인 이미지 안에 있던 고정 캐릭터 / 기존 칸 / 기존 점수판이 실제 UI와 겹치지 않음

### 2. 보드 자체를 실제 UI로 구축
- 24칸 모두 실제 DOM 타일
- 승인 시안처럼 파스텔 블루 / 핑크 / 민트 / 옐로 / 퍼플 타일
- 원형 광장, 국회의사당, 한옥, 강, 다리, 나무, 표지판을 CSS 장면으로 구성
- 가로 1672:941 비율 유지
- PC에서는 브라우저 높이와 폭에 맞춰 한 화면 안에서 축소

### 3. 플레이 캐릭터 교체
- 31.201~31.203의 단순 `miniAvatar()` 플레이 말을 제거
- 승인 시안의 캐릭터 비율을 기준으로 **큰 머리 / 갈색 머리 / 흰색 재킷 / 파란 포인트 / 붉은 타이의 치비 말**로 교체
- 보드 위에 실제 이동 캐릭터는 **1개만** 존재
- `지역 공감 +150` 등에 고정 장식 캐릭터를 두지 않음

### 4. 총총총 이동 유지
- 서버에서 주사위 결과를 받은 뒤 최종 칸으로 순간이동하지 않음
- `1 / N → 2 / N → ... → N / N` 순서로 한 칸씩 이동
- 이동 중 캐릭터 바운스 애니메이션 유지
- 도착 후 최종 이벤트 / 점수 / 카드 / 선택 로직 반영

### 5. 우측 게임 패널 재구축
승인 시안의 구성 순서를 그대로 유지합니다.

1. 주사위 굴리기
2. 민심 SCORE
3. 전략카드 3칸
4. TODAY RANKING

각 영역은 실제 데이터가 들어가는 UI이며 정적인 이미지가 아닙니다.

### 6. 홈 오른쪽 사이드바
- 임의의 별도 카드 디자인을 다시 만들지 않음
- 승인 폴리마블 디자인을 사이드바 비율로 만든 `sidebar-entry-31-204.webp`를 그대로 사용
- 별도의 랭킹/점수 오버레이를 덧붙이지 않음
- 이미지 전체가 게임 입구이며 `GAME START` 버튼만 표시
