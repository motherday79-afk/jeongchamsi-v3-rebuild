# 0.0.31.320 — 망자의 계곡 운송·금화 개선

- 투명 배경의 16프레임 고블린/수레 이미지로 교체. 고블린이 앞, 수레가 뒤인 후면 정렬로 전진한다.
- 좌우 이동 시 260ms 방향 전환 자세를 사용한 후 직진 보행으로 복귀한다. 피해 단계마다 적재 금화가 줄어든다.
- 검은 사각형을 흐리게 가리던 처리를 제거하고 투명 알파를 사용한다. 스프라이트 로더는 마젠타 잔여 배경도 제거한다.
- 금화는 독립적인 3~5개 묶음으로 반복 등장한다. 손의 타격 전후 320ms에는 같은 위치에 회수 금화를 배치하지 않는다.
- 60초/내구도 3/20초 안내/40초 무안내 및 보상 미지급 정책 유지.
- 최소 규칙 테스트 7개 통과. 100개 시드에서 모든 금화 수집 및 무피해 경로가 입력 제한 안에서 가능함을 확인.
- 화면 및 실제 플레이 검수는 사용자가 진행한다.
