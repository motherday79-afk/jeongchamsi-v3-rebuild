# JCS 0.0.31.152 — 푸터 이메일의 외부 앱 연결 제거

## 확인된 현상과 수정 범위

삼성인터넷에서 내부 항목을 누른 뒤 연결 프로그램 선택창이 나타났고,
Gmail을 선택하면 받는 사람이 자동 지정된 작성 화면으로 이동했습니다.
사용자는 해당 주소가 자신의 주소이며 푸터에 등록된 이메일의 당사자라고 설명했습니다.
복사 제한을 제외하는 R2 테스트에서도 현상은 같았습니다.

푸터의 5종 이메일 항목(개인정보·광고·고객센터·파트너·경영지원)을
메일 앱을 실행하는 mailto 링크에서 복사 가능한 일반 텍스트로 변경했습니다.
메인과 상세페이지가 같은 푸터 함수를 사용하므로 공통 적용됩니다.
연락처 값과 기존 글자 크기·배치는 유지하며, 이메일은 선택해서 복사할 수 있습니다.
새로운 전역 터치 차단이나 외부 링크 차단은 추가하지 않았습니다.

터치 위치와 다른 이메일 연결이 실행된 근본 원인은 아직 확인되지 않았습니다.
이번 변경은 확인된 이메일 연결 경로를 제거하는 조치이며,
실제 삼성인터넷 단말에서 선택창이 사라지는지는 배포 후 확인해야 합니다.
메일 화면의 undefined 문구가 정참시에서 전달됐다는 증거는 없습니다.

## 적용

- 151 또는 151 진단 R1/R2 사용 중: PATCH.zip의 파일을 같은 경로에 덮어씁니다.
- 전체 교체: 전체 ZIP 하나를 사용합니다. PATCH를 추가 적용하지 않습니다.
- ZIP 내부의 src, tests 등의 경로를 유지해 배포합니다.
- 진단 스크립트의 자동 실행 코드는 제거했습니다. 패치 적용 후 남아 있는
  tap-diagnostics.js는 페이지에서 불러오지 않으므로 별도 삭제가 필요하지 않습니다.

## 배포 후 확인

기존 정참시 탭을 닫고 새 탭에서 https://www.jeongchamsi.com 에 접속합니다.
정치인 카드 및 상세페이지 더보기를 눌러 연결 프로그램 창이 다시 뜨는지 확인합니다.
푸터 이메일은 주소가 보이고 선택·복사가 가능하되, 탭만으로 메일 앱을 열지 않아야 합니다.
증상이 남으면 이번 조치를 해결 완료로 보지 않습니다.

이번 ZIP에는 APK 변경이 없습니다.
