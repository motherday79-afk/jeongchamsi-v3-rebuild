# JCS 0.0.31.233 · 폴리마블 타일 중심좌표 정밀 보정 패치

이번 패치는 **이미지를 재생성하거나 배경을 교체하지 않습니다.**
31.232에서 정참시에 적용된 동일한 `polimable-board-base-31-232.png`를 그대로 사용합니다.

## 변경 범위
- 게임 규칙 추가 없음
- 민심/거점/카드/특수칸 효과 추가 없음
- 주사위 로직 변경 없음
- 캐릭터 이동 시 멈추는 위치만 정밀 보정
- 기존의 `타일 사각형을 단순 등분한 중심값` 대신, 승인된 실제 보드 이미지의 **시각적 타일 중심점 좌표를 개별 지정**
- 캐릭터 발 위치가 각 시각적 칸 중심에 오도록 기존 발 기준 앵커 방식을 유지

## 확인 중 발견된 구조 이슈
현재 승인된 배경 이미지에는 시각적으로 구분되는 칸이 총 **33개**입니다.
특히 하단의 두 코너 사이에 일반칸이 8개가 보입니다.
따라서 이번 31.233은 이미지 재생성 없이 좌표 정확도만 검수하기 위해 **33개 보이는 칸 모두에 이동 중심점**을 설정했습니다.

이는 게임룰 확정이 아니라 `캐릭터가 실제 보이는 칸 중앙에 정확히 서는가`만 검증하기 위한 단계입니다.
최종 32칸 게임룰을 연결하기 전에는 33개 시각칸 중 어떤 칸을 제거/통합할지 반드시 정리해야 합니다.
