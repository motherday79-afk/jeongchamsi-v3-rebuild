# JCS 0.0.31.226 · 폴리마블 보드 제작 STEP 2

이번 패치는 **게임룰 구현 패치가 아닙니다.**
31.225에서 만든 32개 독립 보드 객체 위에, 승인한 참고시안 방식의 **라벨 + 아이콘만** 올리는 단계입니다.

## 이번 단계에서 적용한 것
- 베이스 이미지를 사용자가 지정한 `백그라운드 이미지2.0`으로 교체
- 화면 비율: 원본 그대로 **1672×941 (사실상 16:9)**
- 보드 칸: 정확히 **32개 독립 DOM 객체** 유지
- 모서리 큰 칸: 0 / 8 / 16 / 24
- 각 객체 내부에만 `아이콘 + 디자인된 명칭 라벨` 배치
- 라벨은 단순 텍스트 투입이 아니라 참고시안처럼 굵은 타이포, 외곽선/그림자, 아이콘 상단 배치로 구성
- 베이스 PNG에는 텍스트나 아이콘을 합성하지 않음
- 따라서 이후 각 칸의 라벨/아이콘을 독립적으로 수정 가능

### 참고 이미지의 중복 칸 처리
라벨 참고시안 하단에는 `민심 급등`이 한 칸 더 그려져 있어 전체가 33칸처럼 보이는 오류가 있습니다.
현재 승인된 빈 보드는 정확히 32칸이므로, **하단의 중복 민심 급등만 제외**하고 우측 31번 `민심 급등`을 유지했습니다.
