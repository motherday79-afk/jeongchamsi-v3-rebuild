## 케이지
- 2026-09-14에 확정한 경기장 이미지와 이미지 안에 디자인된 ‘케이지 참전하기’ 버튼을 사용합니다.
- 박스 전체를 2:1 경기장 디자인으로 채우며 제목, 경기장, 버튼, 여백 어디를 눌러도 표시 중인 케이지 본문으로 이동합니다.
- 제목과 진보·보수 비율은 선택된 실제 케이지 데이터를 사용합니다. 비율은 기존 게시글 집계 기준이며, 참여가 없을 때는 양쪽 0%입니다.
- 실제 제목이 승인 시안의 인사청문회 제목과 같을 때는 원본 붓글씨 이미지를 그대로 표시합니다. 제목이 바뀌면 함께 제공한 붓글씨 글꼴로 자동 표시합니다. 서로 다른 글꼴의 글자 형태가 완전히 동일하다는 의미는 아닙니다.
- 바뀐 제목은 두 줄 안에서 크기를 조정합니다. 아주 긴 제목은 말줄임표를 사용하며, 전체 제목은 접근성 이름과 마우스 설명 및 본문에서 확인할 수 있습니다.
- 메인의 설정 톱니바퀴를 제거했습니다. 관리자로 케이지 본문에 들어가 ‘메인 케이지 설정 · 관리자’를 펼쳐 노출할 케이지 또는 최신 자동 선택을 저장할 수 있습니다.
- 기존 관리자 페이지 설정도 유지합니다. 설정 저장 후 뒤로가기로 돌아와도 새 케이지가 표시되도록 화면 캐시를 갱신했습니다.
