# JCS 0.0.31.254 — 폴리마블 배치 편집 확장

253 전체 소스를 기준으로 만든 작업본입니다. 운영 배포는 아직 하지 않았습니다.

## 사용 방법

1. 관리자로 로그인하고 폴리마블에서 **배치 편집**을 누릅니다. 게임 진행 중이면 턴이 끝난 뒤 열립니다.
2. **편집 종류 → 칸별 위치**를 선택합니다. 칸 선택 목록이나 보드의 칸을 눌러 대상을 고릅니다.
3. **대상·강화 단계**에서 캐릭터, 소유 깃발, 건물 1·2·3단계를 선택합니다. 실제 그림을 끌어 옮기거나 방향 버튼으로 1픽셀씩 움직입니다. 키보드 Shift+방향키는 10픽셀 이동입니다.
4. 캐릭터는 **혼자 도착**, **함께 도착 1P**, **함께 도착 2P** 위치를 따로 조절합니다. 함께 도착을 선택하면 두 캐릭터를 함께 보여줍니다. 깃발·건물은 소유 가능한 칸에만 나타납니다.
5. **편집 종류 → 화면 요소**에서 **상단 중앙 로고**를 선택해 크기를 줄이거나 **화면에서 숨기기**를 누릅니다. **플레이어 이름**, **바퀴 수**도 1P와 2P 각각 숨길 수 있습니다.
6. 숨긴 요소는 편집 중 흐리게 표시됩니다. 목록에서 선택하고 **다시 표시**를 누르면 복원됩니다. 미리보기와 실제 게임에서는 보이지 않습니다.
7. **미리보기 → 전체 반영 → 닫기** 순서로 마칩니다. 닫기만 하면 내 임시 작업으로 남고 전체에는 반영되지 않습니다.

## 저장과 복구

- 기존 프로필·정보 배치는 자동으로 새 형식으로 읽습니다. 기존 좌표는 유지합니다.
- **이 요소 초기화**, 되돌리기·다시, JSON 백업·불러오기, 이전 전체 배치 복구를 사용할 수 있습니다.
- 다른 관리자가 먼저 저장하면 충돌 안내를 보여주며 덮어쓰지 않습니다.
- PC·휴대폰이 동일한 보드 좌표를 사용합니다. 휴대폰 가로 화면에서는 편집 도구를 오른쪽에 배치했습니다.
- 바퀴 수나 이름을 숨겨도 게임 계산과 진행 규칙은 바뀌지 않습니다.
- 설정은 서버의 기존 배치 키에 저장됩니다. 기존에 열려 있던 다른 이용자 게임에는 즉시 끼어들지 않고 새로 불러온 게임에 적용됩니다.

## 적용 파일

- PATCH ZIP: **253 버전에만** 압축 내부 파일을 프로젝트 최상위 경로에 덮어씁니다. 새 core 모듈 2개, 배경 이미지, 서버 검증 파일도 함께 필요합니다.
- FULL ZIP: 변경 사항을 포함한 전체 소스입니다. 패치와 중복 적용할 필요는 없습니다.
- 정적 파일만 업로드하지 말고 서버 파일을 포함해 함께 배포해야 합니다.

## 확인 결과와 범위

- 자동 테스트 20개 통과: 설정 검증, 253 이전 형식 호환, 비관리자 차단, 출처 검사, 저장·조회·충돌·복구, 기존 게임 규칙 및 오브젝트 연결.
- 실제 로컬 브라우저: 칸·단계 선택, 방향 이동, 드래그, 로고 숨김, 이름·바퀴 수 숨김, 저장 후 새로고침 유지, 실제 시작 게임말 좌표 적용 확인.
- 1280×720 및 844×390 가로 화면 확인. 실제 휴대폰 하드웨어 테스트와 운영 Redis 저장·운영 배포 검증은 하지 않았습니다.
- 운영 저장소 용량 복구 작업의 연결 정보나 백업 데이터는 이 소스와 ZIP에 포함하지 않습니다.

## 이미지 변경 범위

기존 로고가 보드 그림에 합쳐져 있어, 내장 imagegen으로 상단 로고 뒤 배경을 생성했습니다. 실제 화면에는 원래 로고 영역에만 잘라 적용합니다. 보드 전체를 새 그림으로 교체하지 않습니다. 기존 로고는 원본 그림에서 CSS로 표시해 이동·크기·숨김을 조절합니다.
