# JCS 0.0.31.213 · 폴리마블 새 백그라운드 제작 패치

적용 대상: 현재 폴리마블 배경 교체 단계

이번 패치는 **새 백그라운드 제작만** 먼저 진행한 파일 묶음입니다.

## 반영 원칙
- 기존 백그라운드 위를 억지로 가리는 방식이 아님
- **새로 정리한 배경 이미지 1장**만 교체 대상으로 제공
- 이후 단계에서 기존 배경을 제거하고, 이 이미지를 새 배경으로 교체하면 됨

## 새 배경 정리 내용
1. **전략카드 영역**
   - 기존 슬롯/다이아/텍스트 잔상 제거
   - 제목/외곽 패널은 유지
   - 내부는 **깨끗한 빈 퍼플 공간**으로 재구성

2. **TODAY RANKING 영역**
   - 기존 줄/숫자칸/placeholder 요소 제거
   - 제목/외곽 패널은 유지
   - 내부는 **깨끗한 흰 패널**로 재구성
   - 오른쪽에는 **아주 옅은 워터마크 아이콘**만 남김
