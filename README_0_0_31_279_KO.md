# 정참시 279 — 나의 광산 관리자 전용

개발 중인 나의 광산은 관리자 계정만 이용할 수 있습니다.

- 일반 회원과 비로그인 방문자는 게임 대신 **권한이 없습니다. 관리자에게 권한을 요청해 주세요.** 안내와 메인으로 돌아가기 버튼을 봅니다.
- 서버에서도 일반 회원의 광산 조회·채굴·회수·복권·광고 이동 API를 403으로 차단합니다. 화면만 숨기는 방식이 아닙니다.
- 기존 골드, 강화, 경품 기록은 삭제하거나 초기화하지 않습니다.
- 회원별 별도 승인 기능은 추가하지 않았습니다. 현재는 기존 관리자 계정만 입장 가능합니다.
- 278 전체에 279 PATCH를 적용합니다. FULL은 전체 소스입니다.
