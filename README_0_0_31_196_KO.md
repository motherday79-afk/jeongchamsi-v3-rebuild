# JCS 0.0.31.196 — AI 응답 INTELLIGENCE 표기 / 조사 방법 탭 삭제

## 변경
- 여론조사 상세페이지의 `조사 방법` 카테고리(탭)를 삭제했습니다.
- 기존 저장된 AI 응답 설명도 화면에서 `JCS AI PANEL의 INTELLIGENCE 데이터입니다.` 형식으로 자동 표시합니다.
- 앞으로 업로드되는 AI 통합/응답 파일은 저장 단계에서 설명문을 같은 INTELLIGENCE 형식으로 자동 정규화합니다.
- `개발용 샘플 응답입니다`, `예시 응답입니다`, `샘플 응답입니다` 등의 과거 꼬리문구는 자동 치환합니다.
- 응답 이유(reason)는 원래 핵심 문구를 그대로 유지합니다.

## 적용
31.195 이상에 같은 경로로 덮어쓰기 후 Vercel 배포, Ctrl+F5 권장.
