# 정참시 256 · 깃발 위치 연동과 같은 줄 글자 정렬

## 깃발과 건물 함께 이동

배치 편집 → **깃발·건물 · 위치·크기** → **소유 깃발**을 선택하세요.
**깃발·건물 위치 연동**이 기본으로 켜져 있습니다. 깃발을 끌거나 방향 버튼으로 옮기면 그 칸의 건물 1·2·3단계가 같은 중심 위치로 이동합니다. 각 단계의 크기는 유지됩니다.

이미 맞춘 깃발 위치에 건물만 맞추려면 **현재 깃발 위치에 건물 맞추기**를 누르세요. 연동을 끄면 개별 편집할 수 있습니다. 연동 체크는 현재 편집 화면의 작업 옵션이며, 새로고침하면 기본값인 켜짐으로 돌아갑니다. 기존 저장 위치는 체크만으로 바뀌지 않습니다.

## 같은 줄에 지명 배치 적용

배치 편집 → **칸 디자인 · 이름·색상·방향**에서 일반 칸 하나를 선택합니다. 글자 크기·회전·가로/세로쓰기·위치를 맞춘 뒤 **이 줄에 같은 배치 적용**을 누르세요.

같은 줄의 다른 일반 칸 5개에 같은 글자 크기·각도·쓰기 방향·글자 영역 크기와 각 칸 중심으로부터의 상대 위치가 적용됩니다. 이름과 색상은 유지됩니다. 전략카드와 큰 모서리 칸은 제외됩니다.

## 저장과 복구

미리보기 후 **전체 반영**을 눌러 저장하세요. 한 번의 연동 이동이나 줄 정렬은 **되돌리기** 한 번으로 복원됩니다. 기존 저장 형식과 캐릭터·건물·지명 설정은 유지됩니다.

## 확인 범위

관련 자동 테스트 21개 통과. 깃발과 세 건물의 좌표 일치·크기 유지, 연동 해제, 네 줄의 상대 위치 정렬, 이름·색상·다른 줄·특수칸 보존 및 기존 저장·복구를 확인했습니다. 로컬 브라우저에서 연동 이동, 줄 정렬, 되돌리기·다시 적용, 저장을 확인했습니다. 운영 배포 결과는 별도 배포 확인 기록을 참조하세요.
