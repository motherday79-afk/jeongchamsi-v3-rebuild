# 정참시 281 — 분리형 곡괭이·옷장

## 적용한 기능

- 캐릭터 몸·팔·손·장비를 별도 이미지 객체로 조립합니다. 기존 프레임 속에 붙어 있던 곡괭이와 보석 덧붙이기 방식은 플레이 화면에서 사용하지 않습니다.
- 철·은빛·황금·자수정 곡괭이를 전체 이미지로 손에 장착합니다. 실제 강화 레벨과 선택 장비에 따라 자동으로 바뀝니다. 손과 곡괭이가 함께 회전합니다.
- **캐릭터 → 선택한 광부의 옷장 열기**에서 상의·하의·헬멧·장갑·신발을 선택합니다. 채굴 동작 미리보기 후 **이 의상으로 저장**을 누르세요.
- 기본 작업복과 다른 색상의 상·하의, 헬멧·장갑·신발의 착용·해제를 제공합니다. 엘프는 상·하의 해제 시 내복이 남습니다.
- 캐릭터별 의상 선택은 서버에 저장되며 새 광고주 회차에서도 유지됩니다. 의상 변경은 채굴 능력·보유 골드·강화 수치에 영향을 주지 않습니다.
- 관리자 전용 접근 제한을 유지합니다.

## 아직 구현되지 않은 범위

성인 남녀의 속옷 기본형 생성은 이미지 도구에서 차단되어 확보하지 못했습니다. 사용자 동의 없이 운동복으로 대체하지 않았습니다. **성인 상·하의 해제는 화면과 서버에서 잠겨 있으며 이번 패치의 완료 기능이 아닙니다.** 작업복 종류 교체와 나머지 장비 해제는 사용할 수 있습니다. 따라서 전체 의상 업그레이드 요청은 아직 모두 완료된 상태가 아닙니다.

## 확인 및 전달

의상 데이터 검증·저장·회차 유지, 관리자 접근 제한 및 관련 광산 테스트 11개 통과. 로컬에서 객체가 조립되는 연결 화면을 확인했습니다. 실제 운영 화면의 동작과 디자인 검수는 사용자에게 맡깁니다.
