# JCS 0.0.31.230 · 폴리마블 주사위 액션 테스트 패치

이번 패치는 **주사위만** 적용하는 단계입니다.

## 적용 내용
- 우하단 `주사위 굴리기` HUD에 실제 주사위 2개 객체 배치
- `굴리기` 클릭 시 중앙으로 주사위 2개 등장
- 회전 → 낙하 → 바운스 → 최종 결과 확정 연출
- 각 주사위 결과 1~6
- 합계 표시
- 같은 숫자일 경우 `DOUBLE!` 표시
- 결과는 `data-last-dice`, `data-last-dice-total`, `data-last-dice-double` 상태와 `polimable:dice-result` 이벤트로 보관
- 난수는 가능하면 `crypto.getRandomValues()` 기반 균등 1~6 사용

## 이번 단계에서 하지 않은 것
- 캐릭터 이동 **연결하지 않음**
- START 보너스/민심/거점/카드/특수칸 등 게임룰 **연결하지 않음**
- 기존 보드 이미지/32칸/HUD 디자인 **변경하지 않음**
- 남2 프로필/게임말 위치 **변경하지 않음**

주사위 액션 확인 후 다음 패치에서 주사위 결과값을 남2 캐릭터의 1칸씩 이동과 연결합니다.
