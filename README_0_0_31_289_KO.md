# JCS 0.0.31.289 — 회원별 광산 초기화·곡괭이 효과

## 회원별 초기화
관리 → 회원 광산 초기화 → 회원 검색·선택 → 현재 정보 확인 → 회원 아이디 직접 입력 → 초기화 버튼.

대상 한 명만 처리하며 관리자 본인도 선택할 수 있습니다. 골드·광물은 0, 채굴·인부·저장고는 Lv.1, 일반·유료 곡괭이 보유·장착과 캐릭터 선택은 시작 상태로 돌아갑니다. 공동 잭팟, 다른 회원, 복권 참여 및 당첨·경품 지급 기록은 유지됩니다. 초기화 전 상태와 실행 관리자 기록을 최근 10회 보관합니다. 현재 열린 채굴 세션을 해제하며 중복 초기화 요청을 방지합니다.

이번 패치에서 실제 회원 초기화를 실행하지 않았습니다.

## 곡괭이 효과
캐릭터 프레임 밖으로 효과가 펼쳐지도록 캔버스를 확장했습니다. 은빛·황금은 광채와 궤적, 신비는 보라 결정과 문양, 차원은 무지개 고리, 어둠은 검붉은 기운, 천상은 빛기둥, 번개는 낙뢰, 바람은 회전하는 곡괭이와 회오리를 표시합니다. 타격 후 여운이 즉시 잘리지 않도록 조정했습니다. 움직임 줄이기 설정에서는 큰 움직임을 줄입니다.

광고주 변경 시 광산 성장은 유지하는 288 정책을 유지합니다. 곡괭이 가격·구매 레벨 조건은 이번 패치에서 변경하지 않았습니다.

요청에 따라 문법 검사·변경 파일 공백 검사만 수행했습니다. 실제 화면·플레이 검수는 사용자 진행입니다.
