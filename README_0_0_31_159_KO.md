## 화면 변경

- 대표 캠페인 이동 문구는 **이야기를 / 만나보세요**, 네 개 카드의 문구는 **이야기 / 만나보기** 두 줄을 유지합니다. ‘요’나 ‘기’가 따로 떨어지지 않습니다. 목록 화살표 아이콘의 크기도 고정했습니다.
- 메인 메뉴의 세대별 자리에 캠페인을 올리고, 세대별 메뉴는 더보기 영역으로 옮겼습니다. 기존 메뉴 개수·클릭 경로·아이콘 디자인을 유지합니다.
- 상단 로고, 검색창 로고, 푸터, 로딩 화면, 브라우저 아이콘과 공유 미리보기는 첨부한 골드 로고를 사용합니다. 원본1536×1024투명PNG를 그대로 복사했으며 모양·색상·비율을 재생성하거나 변경하지 않았습니다. 원본 파일은 `assets/brand/jcs-gold-159.png`입니다.

## 캠페인 후원 안내와 모금 현황

캠페인 상세의 후원 영역에 후원처, 계좌, 후원 안내, 공식 후원 링크와 QR 안내 링크, 모금 현황을 표시할 수 있습니다. 관리자로 **캠페인 수정**에서 입력하고 게시하면 공개본에 반영됩니다. 초안 저장은 기존 공개본을 바꾸지 않습니다.

실제 후원은 캠페인 후원처의 계좌나 공식 페이지로 직접 연결합니다. 정참시가 후원금을 받거나 결제를 처리하는 기능은 추가하지 않았습니다. 계좌 복사는 공개·확인된 실제 캠페인의 계좌만 대상으로 합니다.

모금 현황은 후원처 자료를 확인하여 관리자가 등록하는 **기준일 현재의 집계**입니다. 외부 계좌와 자동 연동한 실시간 잔액이 아닙니다. 목표금액, 모금액, 후원자 수, 기준일과 자료 출처를 기록합니다. 확인되지 않은 값이나 입력하지 않은 값은 임의로0을 채우지 않습니다. 목표를 넘으면 실제 달성률을 표시하고 진행 막대만 최대100%로 제한합니다.

공개하지 않거나 확인되지 않은 후원정보는 방문자에게 전달하지 않습니다. 종료한 캠페인은 당시의 모금 기록을 보존하고 후원 실행은 중단합니다. 현재 캠페인에 필요한 정보가 없으면 해당 부분 자체를 숨깁니다.

## 예시5개

정치2명·문화예술2명·기업창업1명의 기존 예시는 그대로 유지하면서, 계좌 안내와 모금 현황의 예시를 추가했습니다. 모금액·달성률·후원자 수에는 예시임을 표시합니다. 계좌는 송금할 수 없는 예시 표기이며, 실제 후원 링크·QR·계좌 복사가 실행되지 않습니다.

예시의 관리자 편집 화면에서는 후원·모금 항목을 읽기 전용으로 확인할 수 있습니다. 실제 캠페인에서는 해당 항목을 직접 입력하고 수정할 수 있습니다.

관리자가158에서 이미 수정한 예시의 기존 이야기·사진은 덮어쓰지 않습니다. 예시에는 EXAMPLE 표시가 유지되며 실제 캠페인은 새로 등록해 사용합니다. 공식 캠페인 번호와 예시 번호는 계속 분리됩니다.

검사 결과와 코드 검토 내용은 `verification/campaign-support-159/`에 포함했습니다.158에159패치를 합친 결과와159전체 ZIP의 일치 여부, 기존 배지·정치인 데이터와 승인 사진의 보존을 확인합니다.

4. 메인 메뉴에서 캠페인, 더보기에서 세대별을 열고 상단·검색창·푸터의 로고를 확인합니다.
