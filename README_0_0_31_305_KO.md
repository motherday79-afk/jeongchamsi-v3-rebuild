# 305 — 후회없는 약탈

광산 메뉴의 **후회없는 약탈**을 누르고 A/B/C 중 한 장을 고릅니다.

- 매회 성공 1장, 실패 2장. 서버에서 무작위 결정합니다.
- 선택 시 현재 보유 골드의 10%를 지급하거나 차감합니다. 소수점은 버리며 최소 10G가 필요합니다.
- 한국 시간 기준 하루 3회. 입장만 하거나 닫으면 횟수가 차감되지 않습니다.
- 승패와 관계없이 1회 참여하면 일일퀘스트 완료. 별도 퀘스트 보상은 아직 없습니다.
- 성공/실패 이미지 기반 짧은 연출 후 모든 카드 공개. 결과 바로 보기 가능.
- 가상의 광산으로 실제 회원 골드를 빼앗지 않습니다.
- 재전송·동시 선택은 한 번만 정산합니다. 관리자 초기화로도 당일 도전 횟수는 보존됩니다.
- 기존 관리자 전용 입장 제한과 채굴·복권 규칙은 유지합니다.

검사: 전용 정산 테스트 4개, 수정 JS 문법 검사. 화면·플레이 검수는 사용자 진행.
