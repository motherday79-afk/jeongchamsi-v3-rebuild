# JCS 0.0.31.301 — 중앙 광부와 타격 기준 금맥

- 화면별 임의 좌우 이동을 없애고, 종족별 몸체 중심을 화면의 가로 중앙에 맞춥니다.
- 승인된 발 높이와 캐릭터 크기를 유지합니다.
- 장착 캐릭터·곡괭이의 5번 타격 프레임과 충돌 효과 좌표를 이용해 금맥의 앞부분을 배치합니다.
- 종족·곡괭이를 바꾸거나 화면 크기를 바꿀 때 다시 계산하며, 채굴 애니메이션 도중에는 금맥을 이동하지 않습니다.
- PC 광고판 오른쪽 정렬과 접힌 모바일의 이미지 광고는 유지합니다.
- 문법 확인만 진행했습니다. 실제 화면과 타격 검수는 사용자가 진행합니다.
