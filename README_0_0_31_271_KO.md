# 정참시 0.0.31.271 — 폴리마블 전체 아트 재설계

- 강변의 저녁 풍경, 퍼플·골드 백보드, 네 모서리 장식, 블루·핑크 플레이어 창, 주사위 버튼을 별도 아트로 제작했습니다.
- 32칸은 직사각형 입체 객체로 백보드와 분리되어 있으며 기존 눌림·이동 효과가 연결됩니다.
- 중앙은 주사위·획득 카드가 잘 보이도록 낮은 대비의 장식으로 정리했습니다.
- 기존 게임 규칙, 지명·회전·크기·숨김 등 저장된 설정은 유지됩니다. 새 정보창에 맞춘 위치 보정은 표시할 때만 적용합니다.
- 배치 편집의 깃발/건물 연결과 같은 줄 글자 정렬 기능을 유지합니다.

## 적용
270 전체 소스에 PATCH ZIP의 파일을 같은 경로로 덮어쓰거나, FULL ZIP을 사용합니다.
화면이 이전 모습이면 Ctrl+F5로 새로고침하세요.

## 확인 범위
보드 겹침·좌표 변환·칸 눌림·배치 편집·구매 금액·PC/모바일 화면 비율 관련 12개 테스트 통과.
로컬 브라우저에서 저장된 배치를 불러온 전체 화면의 아트 조합과 정보 표시를 확인했습니다.
전체 게임 반복 플레이와 모든 기기에서의 시각 검증을 완료한 것은 아닙니다.
