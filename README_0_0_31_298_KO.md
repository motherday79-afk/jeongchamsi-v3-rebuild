# JCS 0.0.31.298 — 광산 입장 배너와 광부 바닥 배치

- 운영 화면에서 엘프의 양발이 광맥 위로 떠 보이는 배치를 확인했습니다.
- 플레이어와 광맥에 따로 지정하던 %/px 위치 대신, 채굴 조작창 위의 공통 바닥 좌표를 기준으로 함께 배치합니다.
- 540×710 캐릭터 프레임의 발바닥 위치(약 649행)를 바닥에 맞추고, 광맥은 오른쪽으로 이동시켰습니다. 발밑 접지 그림자를 추가했습니다.
- 이름표를 캐릭터 크기 계산에서 분리하고, 화면·조작창 크기 변경 시 배치를 다시 계산합니다.
- 입장 배너를 현재 다섯 종족이 등장하는 새로운 일러스트로 교체했습니다.
- 짧은 모바일 화면은 최소 장면 높이를 확보하고 페이지 스크롤로 조작할 수 있습니다.
- 채굴 수치, 곡괭이 효과, 모션은 변경하지 않습니다. 수정 후 실제 플레이 검수는 사용자가 진행합니다.
