# JCS 0.0.31.154 — 모바일 일반 텍스트 터치 시 외부 메일 앱 전환 조치

## 실기기 확인 근거

2026-09-14 JCS SELECTION CHECK R2에서 같은 휴대폰·브라우저·화면으로 확인했습니다.
- 화면: 368×773, 배율 1. 제목 위치와 크기 및 푸터 위치 동일.
- body의 user-select / -webkit-user-select가 text일 때: 제목 8회 터치 모두 정상 click 기록, 메일 앱 안 열림.
- 같은 화면에서 원래 none으로 복원: 첫 터치 후 click 없이 약 1.56초 뒤 화면 hidden, 사용자가 메일 앱 열림 확인.
- 제목은 링크가 아니며, 푸터 이메일은 화면에서 약 6,400px 아래에 있었습니다.
- 두 조건 모두 nativeSchemes는 빈 배열이었습니다.

이 결과는 페이지 전체 선택 금지가 증상을 유발하는 조건임을 보여 줍니다.
브라우저 내부에서 어떤 경로로 외부 메일 앱 요청을 생성하는지까지 확인한 것은 아닙니다.
푸터가 제목을 덮었다거나 제목에 메일 링크가 있었다고 판정하지 않습니다.

## 변경

공통 CSS의 기존 선택 정책 위치에 터치 입력용 규칙을 추가했습니다.
(any-pointer: coarse) 또는 (hover: none) 환경에서는 body의 두 user-select 값을 text로 설정합니다.
가로 폭에 의존하지 않으므로 모바일·태블릿·펼친 폴드, 터치와 마우스를 함께 사용하는 기기를 포함합니다.
마우스만 사용하는 일반 PC에서는 기존 none 정책을 유지합니다.

모바일에서는 글자 선택 자체가 가능해집니다. 기존 JavaScript의 복사/우클릭 제한 처리와
입력창·푸터 연락처의 복사 허용 예외는 그대로입니다. 이 패치는 복사를 완전히 차단한다고 보장하지 않습니다.
색상·아이콘·배치·크기·데이터·링크·내부 페이지 이동 코드는 변경하지 않았습니다.
기존 스타일 파일을 갱신하고 index.html의 해당 CSS 주소 버전을 0.0.31.154로 올렸습니다.
앱 JavaScript는 변경하지 않아 /src/app.js?v=0.0.31.153을 그대로 사용합니다.

JCS_0_0_31_154_PATCH.zip에서 아래 두 파일을 같은 경로에 덮어쓴 뒤 배포합니다.

- css/hotfix-31-36-main-shell-footer.css

README와 verification 폴더는 설명·검증용이며 서비스 적용에 필요하지 않습니다.
전체 교체를 원하면 JCS_0_0_31_154.zip 하나만 사용합니다. 전체 ZIP 뒤에 PATCH를 추가 적용하지 않습니다.
현재 153 원본을 바탕으로 만들었으므로 직접 추가한 별도 수정이 있다면 PATCH 적용을 권장합니다.

## 배포 후 휴대폰에서 확인

1. 기존 정참시 탭을 닫고 새 탭에서 https://www.jeongchamsi.com/ 에 접속합니다.
2. 진단 주소가 아닌 일반 메인에서 '나는 이렇게 제안합니다' 제목과 주변 빈 공간을 누릅니다.
3. 나우랭크의 정치인 → 상세페이지 더보기 → 뒤로가기를 확인합니다.
4. 폴드는 접은 상태와 펼친 상태에서 확인합니다.

확인했던 실기기 진단에서는 선택 제한 해제가 증상을 멈췄습니다.
이번 정식 패치가 배포된 일반 페이지의 실제 동작은 위 순서로 최종 확인해야 합니다.
Redis 데이터 재수집이나 APK 재빌드는 필요하지 않습니다.
