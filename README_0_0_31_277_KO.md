# 정참시 277 — 광부 모션·휴식·공동 잭팟 표시

## 사용 방법

- 게임에 들어오면 왼쪽 인부는 철로 침목에 앉아 쉽니다. PC와 모바일 모두 같은 휴식 이미지를 사용합니다.
- 자동채굴하기를 누르면 선택한 광부가 1.5초 주기로 채굴합니다. 세 캐릭터 모두 8개 동작 이미지로 준비·들기·내려치기·반동·회복을 표현하며 고개와 시선을 광물 방향으로 조정했습니다.
- 저장고가 가득 찼다는 서버 결과를 받으면 채굴 상태를 종료하고 예약된 타격 모션도 취소합니다. 회수하고 돌아온 뒤 자동채굴하기를 다시 눌러야 플레이어가 재개합니다.
- 게임을 떠나면 인부 채굴로 전환되는 276의 동작은 유지합니다. 타격 결과는 약 4초마다 반영됩니다.
- 왼쪽 위 **공동 잭팟** 버튼에서 공동 실패 적립 횟수와 등급별 보상을 볼 수 있습니다.

## 잭팟의 현재 범위

보상은 브론즈 **100G**, 실버 **300G**, 골드 **1,000G**로 확정했습니다. 당첨 확률과 실패 횟수의 기금 환산·차감 기준은 아직 미정이므로 **추첨과 지급은 비활성화**되어 있습니다. 화면에도 이 상태를 표시합니다. 공동 실패 횟수를 골드 잔액인 것처럼 표시하지 않습니다.

277 적용 이후 서버에서 정산한 채굴 중 금을 얻지 못한 주기마다 실패 1회를 기록합니다. 추가 타격 장비는 한 주기의 두 번 타격 모두 금을 얻지 못했을 때 실패 1회로 집계합니다. 접속·비접속 채굴 모두 포함하며, 비접속 결과는 다음 서버 정산 때 합산됩니다. 이전 버전에서 이미 정산한 실패 기록을 추정해 넣지 않습니다.

회원의 채굴 저장과 공동 실패 누적은 동일한 Redis Lua 연산으로 처리하여 재전송이나 동시 접속으로 중복 적립되지 않게 했습니다. 이 숫자는 추후 지급 기준을 연결할 기반이며 현재 현금·정참시 포인트 또는 지급 가능한 공동 골드로 환전되지 않습니다.

## 전달 및 확인

276 전체에 PATCH를 덮어쓰면 277 전체와 일치합니다. FULL은 전체 소스입니다.

채굴·회수·접속 모드·모션 취소·공동 적립 관련 테스트 25개를 통과했습니다. 실제 운영 화면의 시각·플레이 확인은 사용자에게 맡깁니다.
