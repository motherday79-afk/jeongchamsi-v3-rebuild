# 정참시 278 — 광고주 경품 복권과 광산 디자인

## 회원 사용 방법

1. 광산에서 골드를 모은 뒤 아래 **복권 긁기**를 누릅니다.
2. **20G · 복권 긁기**로 구매하고 은색 부분을 손가락 또는 마우스로 긁습니다. 결과 확인 버튼으로도 공개할 수 있습니다.
3. 구매마다 독립적인 당첨 확률은 **5%**입니다. 새로고침하거나 다시 접속해도 구매한 복권은 유지됩니다.
4. 복권 창에서 나의 참여 횟수, 당첨 횟수, 남은 경품, 과거 당첨 내역을 확인합니다.

초기 경품은 **영화예매 티켓**, 전체 당첨 한도는 **50회**입니다. 한도에 도달하면 복권만 종료되며 채굴은 계속됩니다. 구매 시 20G가 차감되고 결과와 참여 횟수가 저장됩니다.

## 관리자 사용 방법

- 광산 아래 **관리 · 광고·회차**에서 경품 이름과 전체 당첨 한도를 설정합니다. 현재 회차 설정 저장은 회원 골드를 초기화하지 않습니다. 이미 당첨된 경품은 다른 이름으로 바꿀 수 없습니다.
- **다음 광고주 · 새 회차 시작**을 펼쳐 새 경품, 한도, 광고주 이름과 HTTPS 주소를 입력합니다. 초기화 안내 확인 후 시작하면 모든 회원의 골드·저장 광물·일반 곡괭이·인부·저장고 강화가 다음 접속 때 초기화됩니다.
- 캐릭터 선택, 서버에 등록된 유료 장비 소유권, 과거 경품 당첨 내역은 유지합니다. 이번 버전 배포 자체는 기존 277 회원의 잔액을 초기화하지 않습니다.
- 당첨자 표에서 경품을 실제 전달한 뒤 **전달 완료로 표시**를 누릅니다. 과거 회차 당첨자도 조회할 수 있습니다.
- 표시되는 확인 번호는 내부 당첨 기록 번호입니다. 실제 영화관 예매권 발급 서비스는 연결하지 않았으므로 경품은 관리자가 별도로 전달합니다.

## 디자인 및 유지 사항

- 떨어진 작은 돌 대신 전경으로 연결되는 큰 광맥을 배치했습니다.
- 곡괭이는 1단계 철, 2단계부터 은빛, 7단계부터 황금, 14단계부터 자수정 디자인으로 구분합니다. 장비창 이미지와 채굴 중 곡괭이 장식을 함께 바꿉니다.
- 광고 팻말에서 광고주 주소로 바로 이동할 수 있습니다. 광물 회수 후 광고주 이동도 유지합니다. 팻말 직접 방문은 기존 회수 광고 통계에 섞지 않습니다.
- 기존 황금 곡괭이는 무료 체험입니다. 실제 유료 구매·결제 기능은 이번 작업에 포함되지 않습니다.
- 공동 잭팟은 복권과 별개입니다. 브론즈·실버·골드 잭팟의 추첨 확률이 미정이므로 기존처럼 추첨·지급은 비활성 상태입니다.

## 확인 및 전달

광산 관련 테스트 31개 통과(실패·건너뜀 없음), 변경 스크립트 문법 검사 통과. 로컬 가상 데이터로 구매·차감·당첨 결과 공개 연결을 확인했습니다. 전체 프로젝트 테스트는 다른 영역의 실패가 남아 있어 전체 통과로 보고하지 않습니다. 운영 플레이 확인은 사용자에게 맡깁니다.

277 전체 소스에 278 PATCH를 덮어쓰는 방식입니다. FULL은 전체 소스입니다. 저장된 운영 데이터나 인증키는 ZIP에 포함하지 않습니다.
