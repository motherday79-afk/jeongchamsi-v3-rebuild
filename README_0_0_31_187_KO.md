# JCS 0.0.31.187 재게시 핫픽스

기준: 31.186 적용 상태

## 변경
- 같은 주차에 이미 게시본이 있어도 새 AI 응답파일 업로드 시 새 RUN을 우선 표시합니다.
- 새 RUN은 `메인에 재게시` 버튼으로 게시할 수 있습니다.
- 기존 게시 RUN은 삭제하지 않고 과거 기록으로 보존합니다.
- 새 RUN 게시 후 메인에서는 같은 주차의 더 높은 RUN 번호가 최신값으로 노출됩니다.
- 과거 게시 RUN을 직접 확인할 때만 history=1 경로로 해당 RUN을 고정 표시합니다.
- 캐시 방지를 위해 AI 패널 관련 모듈 버전을 0.0.31.187로 갱신했습니다.
