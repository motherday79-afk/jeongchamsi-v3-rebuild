# JCS 0.0.31.165 — 검색 로고 새로고침·케이지 진영별 바로 글쓰기

## 변경 내용

- 검색창 안의 로고를 누르면 F5처럼 현재 주소를 새로고침합니다. 검색어·현재 경로를 유지하며, 로고 버튼은 검색 제출을 실행하지 않습니다. 최상단의 ‘정치에 참여할 시간’ 문구는 기존대로 홈으로 연결됩니다.
- 오른쪽 케이지 배너 전체를 좌우 50:50 클릭 영역으로 나눴습니다. 왼쪽은 진보, 오른쪽은 보수가 선택된 현재 케이지 글쓰기로 연결됩니다. 제목·본문 작성 칸을 바로 열고 제목 입력란으로 이동합니다. 실제 글 등록은 사용자가 등록 버튼을 눌렀을 때만 진행합니다.
- 비로그인 사용자는 선택한 진영을 안내받고 로그인할 수 있습니다. 로그인 후 같은 케이지·진영의 작성 화면으로 돌아옵니다. 잘못된 비밀번호로 로그인에 실패한 뒤 재시도해도 선택한 진영이 유지됩니다.
- 마우스를 올리거나 키보드로 선택한 쪽의 기존 진영 점수판과 실제 참여 퍼센트가 함께 밝아졌다 돌아옵니다. 반대편은 그대로 유지됩니다. 동작 줄이기를 사용하는 환경에서는 반복 효과 대신 밝기 강조만 적용합니다.
- 종료된 케이지는 참여 기록으로 연결하고 새 글 작성 칸은 열지 않습니다. 등록된 케이지가 없으면 기존 커뮤니티 연결을 유지합니다.

## 유지한 내용

기존 배너 이미지·버튼 그림·2:1 비율, 수동 제목 줄바꿈과 글꼴, 집계 데이터, 배지, 로고 원본, 캠페인 자산을 유지했습니다. 이미지를 새로 생성하지 않았습니다. 162 서버 배포 수정, 163 검색 카드 정리, 164 비교 복귀·라이브 펄스·로딩 로고·풋터 수정이 포함된 상태를 기준으로 합니다.

## 적용 방법

현재 164이면 `JCS_0_0_31_165_PATCH.zip`을 풀어 같은 경로에 덮어쓰고 재배포합니다. 전체 파일이 필요하거나 더 오래된 버전이면 `JCS_0_0_31_165.zip`을 사용합니다.

데이터 초기화, 배너 재등록, 재수집, 환경변수 변경은 필요하지 않습니다. 운영 사이트 배포와 운영 데이터 변경은 수행하지 않았습니다.

## 검증

- 기능 검사 259개 통과. 양쪽 배너 경로, 진영 체크·작성 필드 활성화, 로그인 재시도, 실제 등록 분기, 종료·잘못된 진영 처리, 새로고침 중복 연결 방지를 포함합니다.
- 기존 서버 배포 묶음의 API 시작·읽기 회귀 검사도 통과했습니다.
- 5개 화면 폭 × 동작 줄이기 ON/OFF × 기본/좌우 호버/좌우 포커스, 총 50개 조건에서 CSS 우선순위 2,050개를 확인했습니다. 호버·포커스는 선택자 상태를 모사한 검사입니다.
- 독립 코드 검토 후 로그인 401 실패 시 복귀 주소를 잃는 경로를 수정하고 다시 확인했습니다.
- 기존 이미지·데이터·API·서버 코드·기존 CSS 파일의 일치를 검사했고, 164 전체본에 165 패치를 덮어쓴 결과가 165 전체본과 일치함을 확인했습니다.

실제 브라우저 화면, 클릭 좌표, 애니메이션 프레임은 현재 연결 제한으로 확인하지 못했습니다. 실행 코드·메모리 내 DOM 경계와 CSS 선언을 검증한 결과이며 운영 화면 검증을 대신하지 않습니다.
