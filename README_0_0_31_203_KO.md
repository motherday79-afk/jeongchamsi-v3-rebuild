# JCS 0.0.31.203 · POLIMARBLE DESIGN SOURCE 패치

## 적용 기준
- **31.202 위에 그대로 덮어쓰기**

## 이번 수정 원칙
이번 버전부터 첨부된 `폴리마블(2).png`를 **DESIGN SOURCE OF TRUTH**로 고정합니다.

즉, 더 이상 폴리마블 화면을 새로 해석하거나 다른 분위기로 재디자인하지 않습니다.

- 전체 화면 비율
- 로고 위치
- 배경 풍경
- 보드게임 톤
- 퍼플 게임 패널
- 주사위 / 민심 SCORE / 전략카드 / TODAY RANKING 배치
- 색감과 둥근 패널 감성

위 요소는 승인 시안의 구성을 그대로 기준으로 사용합니다.

## 이번 패치에서 실제로 바뀐 것
### 1. 승인 시안 자체를 화면의 디자인 베이스로 사용
- `assets/polimable/DESIGN_SOURCE_OF_TRUTH_31_203.png`
- 사용자가 첨부한 두 번째 디자인을 그대로 포함
- 화면이 세로로 길어지지 않도록 **1672:941 비율**로 고정
- 데스크톱에서는 현재 브라우저 높이를 기준으로 한 화면 안에 들어오도록 제한

### 2. 칸만 24칸으로 확장
- 승인 시안의 보드 분위기는 유지
- 실제 게임 엔진의 24칸을 시안 위에 촘촘하게 배치
- 기존 게임 룰과 점수 계산 방식은 그대로 유지

### 3. 캐릭터는 게임 말 1개만 동적으로 사용
- 이전 31.202에서 추가했던 장식용 고정 캐릭터 제거
- 실제 플레이어 캐릭터만 현재 위치에 표시
- 주사위 결과가 나오면 한 칸씩 `총총총` 이동

### 4. 우측 게임 패널도 승인 시안 구조로 고정
- 상단: 주사위 + 민심 SCORE
- 중단: 전략카드 3칸
- 하단: TODAY RANKING
- 승인 시안의 퍼플 패널 비율에 맞춰 재배치

### 5. 홈 오른쪽 사이드바
- 별도 임의 카드 디자인을 만들지 않음
- 승인 시안 이미지를 잘라 **게임 바로가기 카드**의 비주얼로 그대로 사용
- 버튼만 `GAME START`로 동작
