# JCS 0.0.31.210 · 폴리마블 UI 가독성 보정 패치

적용 대상: `0.0.31.209`

이번 패치는 디자인 구조를 건드리지 않고, 아래 4개만 보정합니다.

1. **주사위 굴리기 설명 글씨 확대**
   - 설명 문구를 2줄까지 허용
   - 폰트 크기 확대 및 줄간격 개선

2. **전략카드 슬롯 획득 상태 배경 화이트화**
   - 획득한 전략카드 슬롯은 반투명 대신 `#ffffff` 배경 사용
   - 뒤의 다이아 장식이 카드 뒤로 비치지 않도록 정리

3. **민심 SCORE 하단 정보 가독성 확대**
   - `최고 기록`, `STAGE`, 효과 문구, `기록하고 종료` 버튼 텍스트 확대
   - 버튼 높이도 함께 키워 눌림성과 가독성 개선

4. **TODAY RANKING 정보 영역 배경 정리**
   - 왼쪽/중앙 랭킹 정보 영역 뒤에 거의 불투명한 화이트 패널을 추가
   - 오른쪽 왕관/월계수 장식은 약한 워터마크처럼 유지

파일 수: 기존 패치 기준과 동일, 핵심 수정은 `css/polimable-201.css` 중심.
