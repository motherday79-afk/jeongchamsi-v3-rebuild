# JCS 0.0.31.300 — 화면별 광부 이동·광고판 배치

- PC 광고판 오른쪽 끝을 오른쪽 메뉴의 실제 끝선에 맞춥니다.
- 299 대비 캐릭터의 보이는 몸체 폭 기준으로 600px 이하에서는 0.5배, 601~1024px에서는 1.5배, 1025px 이상에서는 1배 오른쪽 이동합니다.
- 화면 폭만으로 접힘/펼침 구간을 나눕니다. 이동 시 곡괭이가 화면 밖으로 잘리는 경우 오른쪽 이동량을 제한합니다.
- 발 높이·크기·광맥 위치는 유지합니다.
- 600px 이하에서 등록된 광고 이미지가 있으면 문구를 숨기고 이미지만 표시하며, 광고주 링크는 유지합니다. 이미지가 없으면 기존 문자 안내를 유지합니다.
- 문법 확인만 진행하며 실제 화면 검수는 사용자가 진행합니다.
