중요한 해석 조건
- A는 현재 배포 중인 0.0.31.153 진입 파일의 스타일/모듈 경로를 그대로 사용합니다.
- 별도의 iframe이나 삼성인터넷 전용 처리 없이 해당 휴대폰의 실제 브라우저에서 실행합니다.
- 다만 진단 기록 코드와 표시줄이 추가되므로 A에서 재현되지 않으면 비교 결과로 원인을 판단할 수 없습니다.
- B는 A가 불러온 화면을 새 문서에 복사합니다. 정참시 스크립트/이벤트 속성을 제거합니다.
  일반 링크와 메일 링크가 있다면 그대로 유지합니다. 입력 폼의 값과 실행 가능한 삽입물은 제외합니다.
  진단 기록/결과 버튼에 필요한 코드만 실행합니다. 운영 사이트의 회원 정보/게시물을 변경하지 않습니다.
- C는 현재 정참시 실행 코드를 유지하고 스타일시트와 인라인 CSS를 제거합니다.
  결과는 조사 방향을 좁히는 단서이며 어느 한 기능의 결함을 자동 확정하지 않습니다.
- 기록은 현재 탭의 sessionStorage에만 보관합니다. 서버로 자동 전송하지 않습니다.
  이메일/전화 URI는 주소를 가리고, HTTP 주소의 쿼리와 해시를 제외합니다.
- 새로고침하거나 다른 페이지로 이동해 아래 진단 표시가 사라졌다면 진단 목록에서 다시 여세요.
- 실기기 앱 실행 현상을 이 도구 제작 환경에서 재현하거나 해결한 것은 아닙니다.
