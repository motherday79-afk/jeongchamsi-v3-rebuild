# JCS 0.0.31.234 · 폴리마블 1P vs AI 게임룰 플레이 테스트

## 이번 패치의 목적
31.233에서 검수한 타일 중심좌표와 현재 정참시에 이미 적용된 보드 이미지를 그대로 유지한 채, 실제 게임룰을 붙여 1P가 가상 2P(AI)와 번갈아 플레이할 수 있도록 합니다.

## 절대 변경하지 않은 것
- 백그라운드/보드 PNG 교체 없음
- 기존 보드 위에 새 보드 이미지를 덮지 않음
- 31.233 이동 중심좌표 유지
- 남2 캐릭터 프로필/게임말 자산 유지

## 적용된 플레이 규칙
- 1P 시작 민심 10,000 / AI 시작 민심 10,000
- 1P가 주사위를 굴린 뒤 이동 및 도착칸 처리
- 1P 턴 종료 후 AI가 자동으로 주사위를 굴리고 이동
- AI 턴 종료 후 다시 1P 턴
- START는 정확히 도착할 필요 없이 통과하는 순간 월급 지급
  - 1바퀴 +1,000
  - 2바퀴 +1,200
  - 3바퀴 +1,400
  - 4바퀴 이상 +1,500
- 더블이면 같은 플레이어가 추가 턴
- 빈 거점 구매
- 내 거점 도착 시 강화 또는 매각
- 상대 거점 도착 시 민심 영향 비용 이동
- 대표거점(L4)은 인수 불가
- 상대 거점 인수 지원
- 같은 그룹 거점 완성 시 NETWORK 효과(민심 영향 x2)
- 전략/정책/민심 카드로 보이는 4개 카드칸은 전략카드 획득칸으로 테스트
- 전략카드 보유 한도 3장, 초과 시 1P는 버릴 카드 선택
- 정참시 광장 +500
- 민심 급등 +700 / 급락 -500
- 긴급이슈 랜덤 +/- 효과
- 운명의 선택: 안전 +300 또는 위험 ±1,200
- 정참시 투어: 1P 선택 이동 / AI 임의 이동
- 민심 0 이하 시 게임 종료

## 1P 조작
- 우하단 기존 `주사위 굴리기` 디자인 영역 클릭
- 구매/강화/매각/인수/운명의 선택은 중앙 선택창 사용
- 보유 전략카드는 좌하단 카드 슬롯 클릭으로 사용

## AI 2P
- 이름: AI 시민
- 1P 턴 다음 자동 진행
- 민심 여유에 따라 거점 구매/강화/인수
- 일부 전략카드 자동 사용

## 현재 보드 칸 수 관련
현재 승인되어 배포 중인 보드 이미지에는 시각적으로 33개의 정지 위치가 존재합니다. 31.233에서 캐릭터가 이미지의 각 실제 칸 중심에 정확히 서도록 33개 이동 앵커를 잡았으며, 이번 플레이 테스트도 그 실제 시각 경로를 유지합니다. 최종 32칸 규칙으로 확정할 때는 배경 또는 한 칸의 게임 규칙을 별도로 통합해야 합니다.

## 검수 포인트
1. START를 지나갈 때 즉시 월급이 지급되는지
2. 1P → AI → 1P 턴 전환이 자연스러운지
3. 구매/강화/매각/인수가 정상 동작하는지
4. 상대 거점 도착 시 민심이 이동하는지
5. 카드/특수칸 이벤트가 정상 동작하는지
6. 캐릭터가 31.233 중심좌표를 따라 정확히 멈추는지
