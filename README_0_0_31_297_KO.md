# JCS 0.0.31.297 — 정참시 의류·스니커즈 예시 상품

- 쇼핑몰에 맨투맨·팬츠·후디·쇼츠·티셔츠·스니커즈 6종을 추가했습니다.
- 제공된 대표 이미지와 상품별 성인 남녀 착용·야외 모임 연출 이미지를 상세페이지에 배치합니다.
- 예시 상품 표시와 연출 이미지 안내를 넣고, 가격·소재·사이즈를 확정 정보로 표시하지 않습니다.
- 기존 제작 문의에 선택 상품명이 자동으로 입력됩니다. 실제 결제 기능은 추가하지 않습니다.
- 모바일은 한 열, 중간 화면은 두 열, 넓은 화면은 세 열로 상품 목록을 표시합니다.
- 실제 화면 검수는 사용자가 진행합니다.
