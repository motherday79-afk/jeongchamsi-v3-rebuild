# 0.0.31.311 · 약탈 실제 영상과 광산 음향

- 선택한 픽사베이 성공/해골 전사 영상을 5초로 편집. H.264/AAC MP4, faststart, 각 약 2.5MB.
- 2.45초부터 서버 정산값으로 성공/실패와 골드 증감을 표시. 영상 종료 후 기존 결과/다음 도전 화면.
- 메인 영상은 contain으로 보존하고 화면 비율 차이는 흐린 배경으로 처리. 문구는 영상과 별도 공간.
- 재생 차단 시 재생 버튼, 실패/장시간 지연 시 저장된 결과 표시. 건너뛰기·뒤로가기 시 음향/영상 해제. 정산 재요청 없음.
- 채굴 타격, 금 획득, 저장고 완료, 회수 버튼, 강화/장착, 메뉴 선택, 복권 긁기/결과 음향.
- 광산/월드맵/메뉴에 음향 버튼. 켜기·끄기 localStorage 저장. 모바일 OS 미디어 음량을 따르며 웹에서 기기 음량을 변경하지 않음.
- Web Audio는 첫 사용자 조작 후 활성화. 백그라운드 음향 중지. 동영상 복귀 시 재생 버튼으로 이어보기.
- 관리 권한/경제/확률/횟수/결과 정산 규칙 변경 없음.

검증: JavaScript 문법, 음향 상태 및 약탈·탐색 회귀 테스트. 실제 PC/모바일 시청·음량 검수는 사용자 진행.
