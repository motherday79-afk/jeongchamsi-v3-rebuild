# JCS 0.0.31.268 — 전략카드 개별 외곽

공통 확대 계수를 제거하고 1672×941 보드 원본에서 전략카드 네 칸을 각각 추적한 좌표로 교체했습니다.

| 줄 | 윗면 꼭짓점 기준 폭×높이 | 측면 기준 두께 |
|---|---|---|
| 초록 | 132×74px | 14px |
| 파랑 | 126.5×65.5px | 12px |
| 퍼플 | 131.5×69.5px | 11px |
| 주황 | 134×74.5px | 14px |

수치는 원본 좌표 기준이며 화면에서는 보드 배율에 따라 함께 확대·축소됩니다. 둥근 외곽과 바닥 경계는 각 칸별 곡선으로 지정합니다. 수작업으로 추적한 경계이며 원본의 안티앨리어싱 픽셀까지 완전히 일치함을 보장하는 측정은 아닙니다.

카드 이미지는 네 꼭짓점에 두 삼각형으로 투영합니다. 측면은 원본 칸의 입체 음영을 은색으로 변환하여 개별 외곽에 맞춥니다. 칸 전체 눌림 연결은 유지합니다. 지역 칸·게임 규칙·사용자 배치 설정은 변경하지 않습니다.
