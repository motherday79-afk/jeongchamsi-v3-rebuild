# 0.0.31.321 — 오늘의 퀘스트 디자인 핫픽스

- 오늘의 퀘스트 중앙 제목과 계곡/약탈 항목을 기존 디자인 간판으로 통일.
- 자동채굴/광물 회수 항목, 계곡/약탈/광산 바로가기 버튼에 새 간판 이미지 적용.
- 제목 텍스트 및 버튼 접근성 이름은 유지. 기존 이동 이벤트/퀘스트 판정 변경 없음.
- 오늘의 모험 기록, 하단 자정 안내문, 본문을 읽기 쉬운 글꼴과 진한 색상으로 조정.
- PC/모바일 제목 크기 대응, 버튼 hover/focus/pressed 제공.
- JavaScript 구문/패치 공백 검사 수행. 실제 화면 검수는 사용자가 진행.
- 노래하는 숲은 이번 핫픽스에 플레이 가능한 게임으로 추가하지 않음. 위치와 5버튼 난이도 설계를 별도 제안.
