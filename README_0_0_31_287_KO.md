# JCS 0.0.31.287 — 관리자 곡괭이 전체 장착

관리자는 곡괭이 상점에서 10종 전부를 레벨·골드 조건 없이 무료로 장착할 수 있습니다. 원하는 곡괭이의 ‘장착하기’를 누른 뒤 자동채굴을 시작하면 해당 모션과 효과를 확인할 수 있습니다.

관리자 여부는 서버 로그인 권한으로 판정합니다. 일반 회원의 구매·보유 조건은 유지되며, 관리자 테스트 장비를 영구 구매 내역으로 추가하지 않습니다. 골드와 성장 레벨도 그대로 유지됩니다.

요청에 따라 문법 검사와 변경 파일 공백 검사만 수행했습니다. 화면·플레이 검수는 사용자 진행입니다.
