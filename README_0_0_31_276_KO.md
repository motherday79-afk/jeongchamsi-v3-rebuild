# 정참시 276 — 접속 중 자동채굴

광산에서 **자동채굴하기**를 누르면 선택한 캐릭터가 1.5초마다 계속 타격합니다. **자동채굴 멈추기**로 중지합니다. 시작 전과 중지 중에도 접속 중인 인부는 쉽니다.

다른 탭으로 이동하거나 게임 화면을 닫으면 인부 채굴로 전환됩니다. 돌아오면 버튼을 눌러 플레이어 채굴을 다시 시작합니다. 저장고가 가득 차면 채굴이 멈추며 기존 방식으로 회수합니다.

타격 결과는 서버에서 계산하고 약 4초마다 모아서 반영합니다. 화면의 1.5초 타격마다 서버 요청을 보내지 않습니다. 인부와 플레이어 채굴은 중복 적립되지 않습니다. 갑작스러운 종료로 닫기 알림을 전송하지 못하면 마지막 접속 확인으로부터 최대 12초 뒤 인부 방식으로 전환됩니다.

기존 골드·강화·캐릭터 선택을 유지합니다. 이 패치에 공용 잭팟 지급 기능은 포함되지 않습니다.

확인: 채굴·회수·권한 및 접속 모드 관련 자동 테스트 21개 통과. 실제 운영 플레이 확인은 사용자에게 맡깁니다.

275 사용자는 PATCH ZIP을 기존 소스에 덮어씁니다. FULL ZIP은 전체 소스입니다.
