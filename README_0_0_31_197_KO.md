# JCS 0.0.31.197 — AI 응답이유 카테고리 정렬

기준: 0.0.31.196 위에 덮어쓰기

## 변경사항

- 여론조사 상세 > 응답 이유를 응답형태별 카테고리로 그룹화
  - 매우 잘하고 있다
  - 잘하는 편이다
  - 잘못하는 편이다
  - 매우 잘못하고 있다
  - 판단 유보 / 모르겠다
- 상단에 응답 카테고리별 인원/비율 요약 표시
- 각 카테고리를 펼치면 주요 이유 TOP 3 표시
- 실제 JCS AI ID 목록을 20개씩 노출
- `더보기 +20`으로 순차 확장
- 각 AI ID를 펼치면 해당 ID의 확장 프로필 + 응답 이유 + INTELLIGENCE 설명 + 주요 요소 표시
- `AI 패널 프로필 전체보기` 링크 제공
- 기존 HUMAN/AI 계산, 게시, 관리자 저장 구조는 변경하지 않음

## 적용

ZIP 내부 파일을 기존 프로젝트의 동일 경로에 덮어쓰기합니다.
배포 완료 후 Ctrl+F5 또는 Ctrl+Shift+R로 강력 새로고침합니다.
