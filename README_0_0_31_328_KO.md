# 328 · 오만의 탑 진행 및 일일퀘스트
- 관리자 본인의 탑 진행을 1층으로 초기화. 진행 중 도전 무효화, 골드/장비/오늘 완료한 퀘스트 유지.
- 매 층 목표 금 증가: max(층+9, ceil(10 × 1.015^(층-1))). 초기 10, 11, 12G 순서.
- 오늘 한 층 클리어 퀘스트 추가, 총 7개. 한국 시간 자정 초기화.
- 깨어있는 눈, 노래하는 숲, 오만의 탑의 두루마리용 장식 이름 이미지 통일. 기존 작은 크기 유지.
- 사용자 시각/플레이 검수. 코드 테스트로 층 증가, 초기화 권한, 이전 도전 무효화, 완료 및 일자 변경 검증.
