# 316 · 계곡 길·간판·수레 손상 연출

- 단색 도로와 직선 가장자리 제거, 흙길/자갈/바퀴 자국/가장자리 돌과 풀 추가.
- 이동에 따라 나무다리 구간 통과: 나무판 결/틈/못, 나무 기둥과 처진 밧줄, 다리 아래 그림자.
- 망자의 계곡 전용 일러스트 간판을 월드맵과 시작 화면에 적용.
- 금화 수레 4단계 이미지: 가득 참, 중간, 적게 남음, 빈 파손 수레.
- 충돌 시 휘청임과 금화 낙하, 내구도별 이미지 전환. 마지막 충돌 후 1.5초 연출 뒤 실패 결과 저장.
- 보유 골드 및 보상은 변경하지 않음. 기존 판정·일일퀘스트 검사 3개 통과, 구문 및 diff 검사 완료.
- 시각/플레이 검수는 사용자 진행.
