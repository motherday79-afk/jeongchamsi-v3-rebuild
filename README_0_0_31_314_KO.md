# 314 · 곡괭이별 음향과 약탈 결과 음악

- 곡괭이 10종마다 고유한 휘두르기/타격 파일, 총 20개 추가.
- 장착한 곡괭이의 시각 등급에 따라 음향 선택. 체험/기존 유료 장비는 금 등급과 연결.
- 기존 모션의 휘두르기 및 충돌 이벤트에 연결하여 다중 타격에도 각각 재생.
- 성공/실패 5초 결과 음악 재제작: 리듬과 화성 진행, 2.45초 결과 공개에 맞춘 악센트.
- 결과 재생 중 배경 음악을 내려 중첩 방지, 종료 후 복귀.
- 자체 합성 음원 사용. 영상 원본 및 출처는 기존 유지. 새 영상 파일에도 같은 음악 삽입.
- 음향 상태/장비 매핑 검사 5개 통과, 구문 및 diff 검사 통과. 청취 검수는 사용자 진행.
