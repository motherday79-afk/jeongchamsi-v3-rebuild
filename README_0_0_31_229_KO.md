# JCS 0.0.31.229 · 폴리마블 남2 캐릭터 클릭 반응 수정

## 수정 내용
- 31.228에서 캐릭터 클릭 이벤트 바인딩이 앱 최초 부팅 시 한 번만 실행되어, `/polimable` 화면이 나중에 렌더링될 경우 이벤트가 연결되지 않던 문제 수정.
- `/polimable` 렌더링 직후 실행되는 `hydratePoliMarble()` 안에서 `bindPoliMarbleInteractions()`를 호출하도록 변경.
- 남2 게임말 클릭 시 `이동 → 승리 → 실패/당황 → 감정컷` 순환 표시.
- 보드/배경/프로필/게임말 위치 및 게임룰은 변경하지 않음.
