# JCS 0.0.31.293 — 곡괭이 고유 기운

- 신비한 이상 6종에서 공통 흰색 다이아 반짝임과 공통 충돌 링을 제거했습니다.
- 신비: 보라 마력과 회전하는 결정 / 차원: 오팔색 균열 / 어둠: 검은 연무와 붉은 맥동 균열.
- 천상: 금빛 후광과 떠오르는 깃털 / 번개: 무기를 따라 불규칙하게 움직이는 전격 / 바람: 청록 기류와 회전하는 곡괭이 분신.
- 대기 중에도 무기를 중심으로 지속하며 들어 올릴 때와 충돌 때 기존 효과와 연결됩니다.
- 타격 파편도 장비별 결정·연무·깃털·전격·분신으로 구분했습니다.
- 쓸만한은 은빛, 숙련자는 금빛 반짝임을 유지합니다.
- 292 연속 타격, 코스튬 및 계정·경제 데이터는 유지합니다.

문법 검사만 수행했습니다. 실제 화면과 플레이 검수는 사용자 진행입니다.
