# 정참시 263 — 중앙 광장과 거점 거래 안내

중앙의 건물·돔·분수·발광을 낮은 잔디·석재 광장으로 교체했습니다. 중앙에 낮은 로고를 두고 주사위·카드·선택창이 나타나면 흐리게 표시합니다. 바깥 칸·눌림·저장 배치·확대 화면은 유지합니다.

구매·강화·인수창은 현재 보유 민심, 기본 비용, 적용된 할인, 최종 지불 금액, 지불 후 잔액, 상대 방문 수입, 소유/강화/영구 소유 상태를 표시합니다. 부족하면 부족액을 표시하고 거래 실행을 비활성화합니다. 할인 금액과 강화 지출 계산을 같은 함수로 연결했습니다. 인수창 잔액은 방문 비용 정산 이후 금액입니다. 그룹 독점·현재 수입 2배 카드를 반영하며 방어권 면제를 안내합니다. 강화 제한과 매각 규칙은 유지합니다.

검증: 거래 계산·문자 이스케이프·기존 게임 흐름·화면 비율 검사 총 7개 통과. JS 구문 검사 통과. 사용자의 요청으로 반복적인 브라우저 플레이·시각 검증은 생략했습니다.
사용: 운영 폴리마블을 새로고침하세요. 262 FULL에 263 PATCH를 적용하거나 263 FULL 전체 소스를 사용합니다.

이미지 제작: 내장 image_gen 편집 도구 사용. 원본 assets/polimable/editor/tile-clean-255.png에서 중앙만 편집했으며, 적용 파일은 assets/polimable/editor/central-plaza-263.png입니다. 코드에서 중앙 다이아몬드 내부만 잘라 표시합니다.
이미지 프롬프트: 원본의 화면 크기·시점·32칸·바깥 도시·UI를 유지하고 중앙 내부의 건물, 돔, 분수, 구체, 깃발, 높은 가로등, 강한 마법 빛을 제거한다. 낮은 세이지 녹색 잔디와 따뜻한 밝은 석재 원형 광장, 은은한 퍼플·골드 동심원 무늬로 교체한다. 중앙은 주사위·카드 공간으로 비우고 꽃과 낮은 관목은 가장자리에만 둔다. 중앙 텍스트는 코드로 별도 추가하므로 이미지에는 넣지 않는다.
