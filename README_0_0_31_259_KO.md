# 정참시 0.0.31.259 — 착지 윤곽 잔상 수정
258에서 별도 테두리는 제거했지만, 움직이는 칸 표면 아래 짙은 바탕이 드러나 윤곽처럼 보이는 문제가 남았습니다.
짙은 바탕을 제거하고 원래 칸을 고정한 채 안쪽 표면만 부드럽게 겹쳐 눌리도록 수정했습니다. 칸 끝에서 움직이는 층은 완전히 투명해져 경계가 벌어지지 않습니다.
주사위·캐릭터·깃발·건물·배치 설정과 게임 규칙은 유지합니다.

확인: 관련 자동 검사 16개 통과. 로컬 검사 화면에서 최대 7px 눌린 순간을 정지해 경계를 확인했습니다. 3+3→6칸 이동→구매 안내까지 진행되고, 눌림 층이 다시 숨겨지는 것을 확인했습니다. 브라우저 오류 없음.
PATCH는 258에 적용합니다. FULL은 전체 소스입니다. 운영 배포 기록은 별도 파일로 제공합니다.
