# JCS 0.0.31.164 — 비교하기 복귀 오류·애니메이션·풋터 수정

## 이번 패치

- 왼쪽 최상단 로고를 제거했습니다. 보라색→골드 그라데이션의 ‘정치에 참여할 시간’ 문구를 왼쪽에 배치하며, 문구 클릭 시 홈으로 이동하는 기능과 클릭 높이를 유지합니다. 검색창·풋터·로딩 화면의 로고는 유지합니다.
- 오른쪽 사이드바 ‘실시간 급상승 정치인’의 점과 외곽 링에 반복 펄스를 연결했습니다.
- 로딩 화면의 기존 금색 로고에 회전·호흡 애니메이션을 연결했습니다. 새 이미지를 생성하거나 로고 원본을 변형하지 않았습니다. 운영체제의 동작 줄이기 설정은 존중합니다.
- 풋터 로고·정참시 이름·설명의 세로 정렬을 맞췄습니다. 참여 인원 안내 앞의 중복 여백과 구분선을 제거하고 행 간격을 줄였습니다. 풋터의 ‘정참시’ 이름에도 보라색→골드 그라데이션을 적용했습니다.
- 비교하기의 메뉴 이동·복귀 처리와 홈 부분 갱신을 수정했습니다.

## 비교하기 오류 원인과 수정

새 메뉴의 로딩이 끝나기 전에 다시 이동하면 이전 화면이 새 주소의 복원 화면으로 저장될 수 있었습니다. 해당 주소의 렌더링이 완료된 화면만 저장하도록 변경했습니다.

홈에서 다른 메뉴로 이동할 때 비교 애니메이션 컨트롤러가 종료되지만, 홈 복귀 때 기존 연결 표시만 확인하고 재연결하지 않는 문제가 있었습니다. 돌아온 화면의 선택 상태를 복원하고 컨트롤러를 다시 연결합니다. HTML로 복원된 화면의 중복 장식도 정리합니다.

홈 일부를 새로 붙일 때 비교하기·자동완성을 연결하지 않던 경로에도 초기화를 추가했습니다. 검색은 기존 정치인 자동완성 서비스를 계속 사용합니다.

## 적용 방법

현재 163이면 `JCS_0_0_31_164_PATCH.zip`을 풀어 같은 경로에 덮어쓴 뒤 재배포합니다. 전체 교체 또는 더 오래된 버전에서는 `JCS_0_0_31_164.zip`만 사용합니다.

데이터 초기화·재수집·배너 재등록·환경변수 변경은 필요하지 않습니다. 기존 이미지·배지·캠페인 및 데이터, 162의 서버 배포 수정과 163의 검색 카드 축소를 유지합니다.

## 검증

메뉴 로딩 중 재이동, 홈 복귀 후 비교 컨트롤러 재연결, 저장된 비교 대상 복원에 관한 검사 3개는 수정 전 실패하고 수정 후 통과했습니다. 전체 기능 검사 243개를 통과했습니다. 서버 배포 묶음 시작 검사도 포함됩니다.

5개 화면 폭과 동작 줄이기 ON/OFF 조건에서 스타일 선언·우선순위 160개를 확인했습니다. 최상단 로고 제거, 문구의 홈 경로, 검색·풋터·로딩 로고 유지도 확인했습니다.

현재 연결 제한으로 실제 브라우저 화면·애니메이션 프레임 확인과 운영 배포는 수행하지 못했습니다. 기능 검사는 실행 코드와 메모리 내 DOM·애니메이션 경계에서, 스타일 검사는 CSS 선언 기준으로 수행했습니다.
