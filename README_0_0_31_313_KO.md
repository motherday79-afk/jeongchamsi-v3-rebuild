# 313 · 광산 음량 보정

- 원인: BGM 0.24 × 전체 0.65 이중 감쇠, 원본 BGM 약 -20 LUFS.
- BGM 파일을 -16 LUFS 부근으로 보정, 전체 게인 1.0 / BGM 0.85로 변경.
- 영상 사운드와 효과음도 각각 음량·최대 피크를 측정하여 보정. 초단기 효과음은 피크 기준.
- 영상 재생 중 BGM 감쇠 유지(0.12), 음향 겹침을 완화하는 출력 컴프레서 추가.
- 새 파일/캐시 버전 사용. 모바일 기기 볼륨과 음소거 설정은 유지.
- 기본 구문·음향 상태 검사. 최종 기기별 청취 검수는 사용자 진행.

- 일일퀘스트: 기존 약탈 1회 + 자동채굴 시작 1회 + 광물 회수 5회, 총 3개.
- 서버의 정상 처리 시에만 기록하고 한국 시간 자정 초기화. 요청 재전송 중복 집계 방지.
- 관련 자동 검사 9개 통과. 플레이 검수는 사용자 진행.
