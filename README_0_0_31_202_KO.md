# JCS 0.0.31.202 · 폴리마블 비주얼 업그레이드 패치

## 적용 기준
- **31.201 위에 그대로 덮어쓰기**
- 목적: 사용자가 요청한 두 가지 반영
  1. **캐릭터가 결과 칸으로 텔레포트하지 않고 한 칸씩 총총총 이동**
  2. **폴리마블 페이지를 첨부한 참고 이미지 톤에 더 가깝게 리디자인**

## 이번 패치 핵심
### 1) 순차 이동 애니메이션
- 주사위 결과를 받은 뒤 캐릭터가 **한 칸씩 순서대로 이동**
- 이동 중 상태 문구: `총총총 n/N칸 이동 중...`
- 마지막 칸 도착 후에 최종 이벤트/점수/선택지가 반영됨
- 기존 서버 엔진은 유지하고, **클라이언트 렌더링 단계에서 보드게임 손맛**을 살림

### 2) 비주얼 리스킨
- 보드/하늘/간판/중앙 광장/우측 패널을 전면 재정돈
- 참고 이미지처럼 **아기자기하고 귀여운 보드게임 화면**에 가깝게 개선
- 구조는 유지:
  - 보드 칸 구조 유지
  - 주사위 / 민심 SCORE / 전략카드 / 랭킹 구조 유지
  - 기존 게임 로직 유지
- 디자인만 업그레이드:
  - 큰 JCS 폴리마블 로고
  - 말풍선형 상단 안내
  - 퍼플 게임 패널 강화
  - 간판/배경/광장 요소 보강
  - 타일 색감/입체감/둥근 모서리 강화

## 체크 포인트
1. 홈 오른쪽 사이드바에서 **JCS 폴리마블 카드**가 정상 노출되는지
2. `/polimable` 진입 후 화면이 참고 시안처럼 더 귀엽게 보이는지
3. 주사위를 굴렸을 때 캐릭터가 **한 칸씩 이동**하는지
4. 이동 끝난 뒤 점수/선택/전략카드/랭킹이 정상 반영되는지
5. 모바일에서도 보드가 깨지지 않는지

## 참고
- 서버 API/엔진 로직은 건드리지 않아 기존 저장 방식과 호환됨
- 이번 패치는 **비주얼 + 인터랙션 업그레이드** 중심
- 필요하면 다음 단계에서 31.203으로
  - 이동 효과음 토글
  - 칸 도착 시 `+120 / -180` 팝업
  - 더 정교한 말 애니메이션
  - 칸별 일러스트 보강
  를 추가 확장 가능
