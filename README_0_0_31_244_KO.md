# JCS 0.0.31.244 · POLIMARBLE OWNERSHIP + AI HOTFIX

## 목적
31.243에서 거점 구매 후 소유 마커가 표시되지 않고, 이후 AI 턴까지 멈추는 회귀 버그를 긴급 수정합니다.

## 수정 내용
- `POLIMARBLE_OWNER_BADGE_POINTS`를 `OWNER_BADGES`로 실제 게임 인터랙션에 연결
- 구매 / 강화 / 인수 / 매각 결과가 소유 마커 레이어에 정상 반영되도록 복구
- 소유 마커 렌더링 오류가 발생하더라도 턴 엔진과 AI 예약 실행이 중단되지 않도록 HUD 렌더를 블록별로 격리
- 1P 턴 종료 후 AI 2P 자동 턴이 정상적으로 이어지도록 기존 턴 스케줄 흐름 유지

## 변경하지 않은 항목
- 게임 경제 규칙
- 주사위 확률 및 애니메이션
- 캐릭터 이동 좌표
- 1P / 2P 정보 좌표
- TODAY RANKING 좌표
- 전략카드 4슬롯 좌표 및 카드 확인 UX
- 백그라운드 이미지

## 확인 포인트
1. 1P가 빈 거점을 구매하면 해당 타일 내부에 `1P · L1` 소유 마커가 즉시 표시되는지
2. AI가 구매하면 `AI · L1` 마커가 표시되는지
3. 강화 시 L2/L3/L4가 같은 위치에서 갱신되는지
4. 인수 시 소유 색과 소유자가 즉시 교체되는지
5. 매각 시 마커가 제거되는지
6. 1P 턴 종료 후 AI가 자동으로 주사위를 굴리고 이동하는지
7. AI 턴 종료 후 다시 1P 턴으로 복귀하는지
