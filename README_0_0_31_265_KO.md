# JCS 0.0.31.265 — 감정표현 복원 및 소유자별 건물

- 두 캐릭터의 기쁨·승리·놀람·분노·슬픔을 독립 투명 PNG로 교체합니다.
- 건물 1~3단계에 1P 블루 / 2P 핑크를 적용합니다. 인수 후에는 새 소유자의 색상으로 표시됩니다.
- 저장된 위치·크기, 깃발, 이동용 캐릭터, 주사위, 게임 규칙은 유지합니다.
- 배치 편집 미리보기의 기본 건물도 정리된 블루 객체로 교체합니다.

## 적용
264 사용자는 PATCH ZIP을 같은 경로에 덮어씁니다. FULL ZIP은 전체 소스입니다.
브라우저에서 Ctrl+F5로 새 파일을 불러옵니다. 실제 플레이 화면은 사용자가 확인합니다.

## 이미지 작업
내장 image_gen 도구 사용. 기존 각 PNG를 편집 대상으로 제공해 동일 캐릭터/건물 복원 및 투명 배경 분리를 요청했습니다.
프롬프트와 생성 원본 경로는 docs/assets/polimable-265-generation.json에 기록합니다.
배포용 파일: assets/polimable/characters/player{1,2}/*-265.png 및 assets/polimable/objects/building-*-p*-265.png.
