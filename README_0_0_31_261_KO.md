# 정참시 0.0.31.261 — 타일 경계 및 착지 효과 보완

- 정지 상태는 글자를 지운 원본 보드를 그대로 사용해 덧댄 옆면과 이중 경계를 제거합니다.
- 32개 칸의 비대칭 모양과 둥근 모서리를 개별 지정했습니다. 밟은 칸만 원본 윗면을 내리고 원본 옆면을 압축합니다.
- 착지 빛의 범위·별 입자를 확대하고 광선을 추가했습니다. 마지막 착지는 0.9초 동안 표시합니다.
- 저장된 지명·색상·각도·깃발/건물/캐릭터 배치값과 게임 규칙은 유지합니다.

사용: 운영 폴리마블을 새로고침하고 주사위를 굴려 확인하세요. 배치 재저장은 필요하지 않습니다.
PATCH는 260에 적용하는 변경분이며 FULL은 261 전체 소스입니다.

검증 범위: 원본 옆면 하단 고정 및 상단 변위의 수학적 검사, 로컬 녹색 줄 1·3·6칸 실제 이동 순간의 화면 확인을 수행했습니다. 사용자의 즉시 적용 요청에 따라 추가 반복 플레이는 중단했습니다. 모든 칸·기종의 시각 완성을 검증했다는 의미는 아닙니다.
