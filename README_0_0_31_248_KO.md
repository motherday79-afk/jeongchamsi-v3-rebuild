# JCS 0.0.31.248 · POLIMARBLE MOBILE FULLSCREEN CENTER PATCH

## 목적
모바일에서 폴리마블을 가로모드로 전환했을 때 게임판이 일반 문서 흐름 아래쪽에 남아 전체 화면을 보려면 스크롤해야 하던 문제를 해결합니다.

## 적용 내용
- 모바일 폴리마블 화면을 `visualViewport` 기준의 고정 전체화면 레이어로 전환
- 가로모드에서 `1672×941` 게임 캔버스 전체를 화면 정중앙에 배치
- 내부 HUD/타일/캐릭터/소유마커 좌표는 변경하지 않고 캔버스 전체만 동일 비율로 확대·축소
- `html/body` 스크롤 잠금으로 검정 여백에서 별도의 페이지 스크롤이 필요하지 않게 처리
- iPhone safe-area / Dynamic Island / Android cutout 영역을 기존 safe-area 계산에 유지
- Safari 주소창 변화 등 `visualViewport resize/scroll` 발생 시 즉시 중앙 정렬 재계산
- 세로→가로 회전 직후 viewport 값이 늦게 갱신되는 기기를 위해 80ms / 240ms 재동기화 추가
- 가로모드 진입 시 문서 스크롤 위치를 0으로 정리
- 세로모드는 기존 가로모드 안내 유지
