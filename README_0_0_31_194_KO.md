# JCS 0.0.31.194 — 여론조사 운영 확장 패치

기준: 0.0.31.193 위에 덮어쓰기

## 1. 과거 조사 기록 삭제
- 관리자 > AI 여론조사 > 지난 조사 보기에서 각 RUN에 `기록 삭제` 버튼 추가
- 과거 조사 상세보기에도 `이 과거조사 기록 삭제` 영역 추가
- 삭제 시 RUN 본문, RUN 목록, 게시 마커/게시 목록을 함께 삭제
- 삭제한 RUN이 해당 주차의 최신 RUN이면 남아 있는 이전 RUN으로 최신 포인터를 되돌림
- 삭제는 복구 불가이며 관리자만 가능

## 2. JCS 여론조사 아이콘 / 네비게이션
- `JCS 여론조사` 서비스 항목 추가
- 메인 서비스 런처에 `여론` 아이콘 추가
- 전체 서비스/드로어 네비게이션에도 동일 서비스 항목 노출
- 메인 여론조사 모듈과 상세보기 헤더에 동일한 여론조사 아이콘 사용
- 경로: `/ai-panel`

## 3. HUMAN 최신 조사 자동수집 강화
`최신 조사 가져오기` 1회로 기관별 최신 1건씩만 운영화면에 표시합니다.

### 한국갤럽
- 한국갤럽 데일리 오피니언 공식 공개자료

### 리얼미터
자동수집 우선순위:
1. 에너지경제신문의 리얼미터 정기 여론조사 시리즈(의뢰처 공개 원문)
2. 리얼미터 공식 RSS
3. 리얼미터 공식 홈페이지

리얼미터 기사 안의 전주 대비 증감(%P)과 현재 지지율(%)을 구분하여 현재값을 읽도록 파서를 보강했습니다.

### NBS
자동수집 우선순위:
1. NBS 공식 홈페이지
2. 연합뉴스 NBS 검색 결과 및 기사
3. 뉴시스 정치/청와대 최신 목록에서 NBS 기사 자동 탐색

NBS 기사에 모름/무응답이 명시되지 않은 경우에는 100-긍정-부정으로 임의 계산하지 않고 미제공(null)로 유지합니다.

## 4. 자동수집 실패 시 반자동 붙여넣기
관리자 `최신 조사 가져오기` 아래의
`자동수집이 안 되는 기관만 결과 붙여넣기`를 펼치면 ChatGPT에서 정리한 HUMAN 조사 데이터를 그대로 붙여넣을 수 있습니다.

예시:

기관: 리얼미터
발표일: 2026-09-14
조사기간: 2026-09-07 ~ 2026-09-11
표본수: 2515
긍정: 33.8
부정: 63.3
유보: 2.9
조사방법: 무선(100%) 자동응답 방식
응답률: 4.5
표본오차: 2.0
원문: https://m.ekn.kr/view.php?key=20260913025043915
질문: 대통령 국정수행 평가

NBS처럼 유보값이 원문에 명시되지 않은 경우 `유보:` 줄은 생략하면 됩니다.

## 적용 방법
1. 현재 31.193 파일은 삭제하지 않습니다.
2. 이 패치 ZIP을 풉니다.
3. ZIP 안 파일을 GitHub의 동일 경로에 덮어씁니다.
4. Vercel 배포 완료 후 Ctrl+Shift+R 또는 Ctrl+F5로 강력 새로고침합니다.
