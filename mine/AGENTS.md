# 광산 미니게임 제작 기준

- 모든 신규 미니게임과 전체 화면 퀘스트의 왼쪽 상단 제목은 디자인 간판 이미지로 표시한다.
- `game-header.js`의 `GAME_TITLES`에 화면 키와 이미지 경로를 등록하고 `setGameHeader` / `game-header.css`를 공통 사용한다. 제목을 개별 폰트나 별도 CSS로 다시 만들지 않는다.
- 제목의 실제 텍스트는 접근성을 위해 유지한다. PC/모바일 및 낮은 화면에서 공통 크기 규칙을 따른다.
- 주요 조작 버튼은 기존 광산·약탈·계곡과 어울리는 게임 디자인을 사용한다. hover/focus/눌림 상태를 제공한다.
- 사용자가 화면·플레이 검수를 담당한다. 필요한 코드 검사를 수행하되 반복적인 브라우저 검수나 추가 승인으로 배포를 지연하지 않는다.
