# JCS 0.0.31.227 · 폴리마블 객체 베이스 3단계

## 이번 패치의 범위
이번 패치는 게임 기능 구현 패치가 아닙니다.
사용자가 승인한 최신 보드/UI 이미지를 정참시 `/polimable`의 **유일한 시각 베이스 이미지**로 교체하고, 향후 데이터를 넣을 영역만 독립 객체로 매핑합니다.

### 적용 내용
- 신규 베이스: `assets/polimable/polimable-board-base-31-227.png`
- 32개 보드 칸 = 각각 독립 투명 DOM 객체
- 1P 패널 = 독립 투명 객체
- 2P 패널 = 독립 투명 객체
- 전략카드 보유판 = 독립 투명 객체
- TODAY RANKING = 독립 투명 객체
- 주사위 굴리기 박스 = 독립 투명 객체
- 게임룰 / 주사위 동작 / 캐릭터 / 랭킹 데이터 / 민심 데이터 = 아직 적용하지 않음

## 가장 중요한 적용 규칙
**이전 보드/백그라운드 위에 신규 이미지를 덮는 방식이 아닙니다.**
기존 보드/백그라운드 이미지를 삭제하고 `polimable-board-base-31-227.png` 하나만 사용합니다.

GitHub 반영 전에 `DELETE_BEFORE_COMMIT_31_227.txt`에 적힌 이전 보드 이미지들을 반드시 삭제하세요.

## 왜 객체가 투명한가
최신 승인 이미지 자체에 타일 라벨/아이콘과 빈 HUD 디자인이 이미 완성돼 있습니다.
따라서 같은 그래픽을 다시 올리면 중복됩니다.
31.227에서는 각 영역의 좌표 컨테이너만 독립 객체로 만들고, 다음 단계에서 캐릭터/실데이터/주사위/카드 등을 해당 객체 내부에만 넣습니다.

## 로컬 검수
개발자 도구에서 `.pm-board-stage`에 `pm-object-debug` 클래스를 임시 추가하면:
- 빨간선 = 32칸 객체
- 파란선 = 5개 HUD 객체
를 확인할 수 있습니다.
