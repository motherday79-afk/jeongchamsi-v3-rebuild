# JCS 0.0.31.232 · 폴리마블 신규 백그라운드 교체 + 주사위→캐릭터 이동 테스트

## 이번 단계의 목적
승인된 `배경확정.png`를 정참시 폴리마블의 **유일한 보드/백그라운드 이미지**로 교체하고, 주사위를 굴린 합계만큼 남2 캐릭터가 32칸을 한 칸씩 이동하는지 확인합니다.

## 절대 규칙
- 기존 폴리마블 보드/백그라운드 PNG를 화면 위/아래에 겹쳐 사용하지 않습니다.
- 신규 `assets/polimable/polimable-board-base-31-232.png` 한 장만 사용합니다.
- 32칸 + 1P/2P + 전략카드 + TODAY RANKING + 주사위 HUD 좌표 객체는 독립 DOM 객체로 유지합니다.
- 신규 배경에 이미 고정 디자인된 `주사위 굴리기` 버튼 위에는 **투명 클릭영역만** 둡니다. 별도의 버튼 이미지를 덮지 않습니다.

## 동작 범위
- 주사위 2개 굴림
- 최종 눈배치 및 합계/DOUBLE 표시
- 합계만큼 남2 캐릭터 이동
- START(0) → 하단 왼쪽 → 좌측 위 → 상단 오른쪽 → 우측 아래 → START 순서
- 한 칸씩 약 0.23초 간격 이동
- 이동 중 남2 `move` 이미지 사용, 이동 완료 후 `token` 이미지 복귀
