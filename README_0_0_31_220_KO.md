# JCS 0.0.31.220 · 폴리마블 사이드카드 오버레이 패치

적용 대상: `0.0.31.219`

## 목적
- 메인 오른쪽 사이드바의 폴리마블 카드에서
  `TODAY KING / 나의 오늘 기록 / GAME START`를
  **이미지 아래 나열 방식이 아니라 이미지 내부 오버레이 방식**으로 배치
- 모바일에서도 동일한 이미지 내부 카드 구조 유지
- 기존 모바일 위치(오늘의 운세 아래)는 그대로 유지

## 포함 파일
- `css/polimable-201.css`
- `src/views/polimable-page.js`
- `src/layout/home-layout.js`
- `src/app.js`
- `index.html`

## 반영 내용
1. 폴리마블 사이드 카드를 하나의 완성형 이미지 카드 구조로 변경
2. 카드 내부에 `TODAY KING`, `나의 오늘 기록`, `GAME START`를 오버레이 배치
3. 기존 이미지 아래에 표시되던 요약 블록은 제거
4. 모바일에서도 운세 아래 위치는 유지하고, 카드 내부 오버레이만 보이도록 정리
