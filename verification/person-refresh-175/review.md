# 175 검토 기록

범위: 지정 검색어·개별 게시·회원 포인트 갱신.

별도 백엔드 검토 및 화면 검토에서 확인한 문제를 수정했습니다. 기사 0건 정상 처리, 미확인 수치 보존과 확인 합계 표시, 개별 게시와 전체 게시 경합, 공개 응답의 순위·자료 세대 일치, 회원 수집본의 관리 작업 경합, 통신 오류 상태 복구, 검색어 저장 중 편집 충돌을 포함합니다.

완료된 전체 게시 재요청은 재반영하지 않으며, 더 최근 개별 갱신본은 이후 전체 게시에서도 유지합니다. 기존 전체 수집 실패 목록에 있었던 인물도 보존합니다. 개인 갱신 성공·포인트 차감은 같은 CAS 트랜잭션으로 처리합니다.

392개 자동 검사를 통과했습니다. 실제 운영 API 수집·배포·포인트 차감은 실행하지 않았습니다.
