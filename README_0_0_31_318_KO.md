# 318 · 계곡 배경 이동·걷기·조작 디자인

- 별도 도로 렌더러 사용 제거. 계곡 원화의 중앙 어두운 길 위에서 진행.
- 플레이 시간에 따라 배경을 소실점 중심으로 확대해 전진감 제공. 일시정지 시 멈춤.
- 화면 내 중복 글자 제목 제거, 상단 제목은 기존 간판 이미지로 통일.
- 운송 시작/좌/우 버튼을 목재·금속 장식의 전용 이미지로 교체. 접근성 이름 및 포커스 유지.
- 화물 4단계 × 양발 걷기 2자세 = 8프레임 적용. 좌우 이동 시 방향 전환 및 기울기 연출.
- 내구도, 금화 수집, 60초 판정과 보상 미지급 정책 유지.
- 구문/diff 및 기존 판정 검사 완료. 화면/플레이 검수는 사용자 진행.
