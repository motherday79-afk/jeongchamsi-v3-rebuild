# JCS 0.0.31.158 — 홈 화면 보완 · CAMPAIGN 분야 확장

## 적용 방법

현재 157 버전이면 `JCS_0_0_31_158_PATCH.zip`을 풀어 프로젝트의 같은 경로에 합친 뒤 배포하세요. 이전 버전에서 적용하거나 전체 소스가 필요하면 `JCS_0_0_31_158.zip`을 사용하세요. 두 ZIP을 중복 적용할 필요는 없습니다.

기존 의존성·Redis·사진 업로드 환경 설정을 유지합니다. 데이터 초기화나 운영 데이터 마이그레이션은 필요하지 않습니다. 배포 후 탭을 다시 열면 변경된 코드가 적용됩니다. `/api/v3/health`의 버전은 `JCS_0_0_31_158`입니다. 이번 전달물은 적용용 소스이며 운영 사이트에 배포하지 않았습니다.

## 홈 화면

- 케이지: 관리자로 케이지 본문에 들어가 **메인 케이지 설정**에서 노출할 케이지, 제목 줄바꿈 위치, 첫째 줄/둘째 줄/동일 크기 강조를 선택하고 실제 배너 미리보기를 확인한 뒤 저장합니다. 원문 제목을 새로 작성하지 않고 기존 제목의 표시 위치만 지정합니다.
- 직접 지정한 줄바꿈은 화면 크기가 바뀌어도 유지됩니다. 크게 표시하기 어려울 만큼 긴 행은 저장 전에 안내합니다. 제목 원문이 바뀌면 이전 제목용 설정이 새 제목에 잘못 적용되지 않습니다. 직접 지정을 해제하면 기본 표시로 돌아갑니다.
- 응원·후원: 80px 높이와 좌우 50:50 클릭 영역을 유지하며 화이트 배경에 퍼플·골드 아이콘과 정돈된 화살표를 적용했습니다. 왼쪽은 정참시 응원하기, 오른쪽은 후원하기입니다.
- 비교분석: 각 정치인의 사진, 바닥 갈라짐 효과, 정치인 선택 버튼의 가로 중심을 맞춥니다. 정치인을 바꾸거나 화면 크기가 달라져도 현재 사진을 기준으로 위치를 갱신합니다.

## CAMPAIGN 분야와 예시 5명

더보기 → **캠페인** 또는 `/campaigns`에서 **전체 / 정치 / 문화·예술 / 기업·창업**을 선택할 수 있습니다. 기존 CAMPAIGN 전체보기와 상세페이지의 퍼플·골드·네이비 디자인을 이어갑니다.

첫 화면에는 대표 예시 1개와 일반 카드 4개를 제공합니다. 이름·지역·단체·활동은 모두 가상으로 구성했으며, 기존 정치인 명단에는 등록하지 않습니다. 사진은 앞서 승인한 시안의 원본을 재사용합니다.

| 예시 | 분야 | 이름 | 주제 |
| --- | --- | --- | --- |
| 001 | 문화·예술 | 윤서진 | 빈 공간을 활용한 지역 문화 |
| 002 | 정치 | 한도윤 | 심야 교통 |
| 003 | 문화·예술 | 임하린 | 돌봄과 공연예술 |
| 004 | 정치 | 박은채 | 전통시장 |
| 005 | 기업·창업 | 최미라 | 지역 일자리 |

각 예시에는 소개, 선정 이유, 이야기, 필요한 지원, 세 가지 제안이 들어 있습니다. 실제 후원계좌·후원 QR·영상은 넣지 않습니다. EXAMPLE 표시와 예시 기간을 사용하며 공식 캠페인 번호를 소비하지 않습니다.

관리자는 목록 상단 **캠페인 관리**에서 예시를 열어 수정·임시저장·게시·비공개·종료할 수 있습니다. 예시는 기본 제공 자료이며 저장한 수정본이 우선합니다. 비공개로 전환한 예시는 다시 자동 생성되지 않습니다. 예시의 EXAMPLE 표시는 수정해도 유지됩니다. 실제 캠페인을 올릴 때는 **캠페인 등록**에서 새 글을 만드세요.

정치 분야는 기존 정치인 자동완성 검색을 사용합니다. 문화·예술과 기업·창업은 이름·역할·조직/팀을 직접 입력합니다. 기존 분야 정보가 없는 캠페인은 정치 분야로 취급합니다. 분야별 상세페이지에는 정책, 작품·활동, 사업·제품에 맞는 제목과 안내문을 표시합니다.

## 운영과 보존

- 예시는 관리자가 종료하거나 비공개로 바꿀 때까지 공개됩니다. 실제 캠페인은 기존 시작일·종료일 규칙을 사용합니다.
- 실제 캠페인은 한국 시간 기준 종료일이 지나면 ARCHIVE에 표시됩니다. 임시저장은 공개본을 바꾸지 않으며 게시해야 수정본이 공개됩니다.
- 이미 게시한 캠페인의 내용과 게시 이력을 보존합니다. 영구 삭제는 게시 전 초안에만 허용됩니다.
- 기존 배지 이미지, 배지 데이터, 정치인 원본 정보는 변경하지 않습니다.
- 메인 오른쪽 광고배너에 CAMPAIGN 이미지나 연결을 추가하지 않습니다. 결제·수수료·정참시의 후원금 수취 기능도 이번 변경에 포함하지 않습니다.
