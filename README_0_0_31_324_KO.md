# 324 — 깨어있는 눈 / 퀘스트 이름 크기
- 월드맵과 두루마리에 깨어있는 눈 추가. 20장 중 보물 2개, 매 시도 2장 선택, 최대 3회 누적 성공.
- 3초 위치 공개 후 두 쌍씩 7번 700ms 교환. PC 5×4 / 모바일 4×5.
- 서버에서 카드 배치·선택·누적 발견 검증. 성공만 퀘스트 기록. 골드 보상·차감 없음.
- 재도전 가능, 기존 뒤로가기/음향 설정 사용. 배경·제목·카드·이름은 built-in imagegen 생성.
- 퀘스트 고유 이름만 절반 폭으로 축소. 바로가기 버튼 유지.
- 화면 및 플레이 검수는 사용자 담당.
