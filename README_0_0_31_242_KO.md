# JCS 0.0.31.242 · POLIMARBLE STRATEGY 4-SLOT PATCH

## 목적
31.241까지 고정된 1P / 2P / TODAY RANKING 좌표를 유지하면서, 좌하단 전략카드 보유판의 4개 슬롯을 실제 배경 이미지의 빈 카드칸에 정확하게 대응시킵니다.

## 이번 패치 범위
- 전략카드 슬롯 4개를 `1672×941` 논리 캔버스 안으로 이동
- 각 슬롯을 CSS grid가 아니라 독립 픽셀 좌표로 지정
- 카드 크기를 각 배경 슬롯보다 작게 고정하여 중앙 정렬
- 카드판에서는 `아이콘 + 카드명`만 표시
- 상세 설명은 기존 title/선택 로직을 유지하고 카드판에서는 숨김
- 빈 슬롯은 배경의 빈 카드칸만 보이도록 실제 DOM 카드를 투명 처리
