# 308 — 월드맵 간판 · 약탈 전체 화면 디자인 · 관리자 테스트 초기화

- 나의 광산: 목재·금광석 장식 이미지 간판.
- 후회없는 약탈: 검붉은 철제 요새 이미지 간판.
- 오늘의 퀘스트: 나침반이 있는 두루마리 이미지 판.
- 약탈은 입장부터 카드 선택·결과까지 PC와 모바일 화면 전체를 사용합니다.
- 전용 요새 내부 배경과 문양이 새겨진 카드 뒷면을 추가했습니다.
- 문구·횟수·완료 상태는 이미지에 고정하지 않고 실시간 표시합니다.
- 뒤로가기와 상단 월드맵 버튼은 기존 이동 기록에 따라 돌아갑니다.

## 관리자 반복 테스트
후회없는 약탈 화면 아래의 **내 약탈 횟수 초기화**를 누르세요.
오늘의 약탈 횟수 0/3, 일일퀘스트 미완료로 돌아갑니다.
이미 얻거나 잃은 골드와 나머지 광산 데이터는 유지됩니다.
관리자 본인만 대상이며 일반 회원 요청은 서버에서 차단합니다.
초기화 전의 요청을 재전송해도 새 도전으로 정산하지 않습니다.

검사: 약탈 정산·중복 방지·관리자 초기화 관련 6개 테스트와 수정 JavaScript 문법 검사.
화면 및 플레이 검수는 사용자 진행.
