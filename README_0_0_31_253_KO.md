# JCS 0.0.31.253 · 폴리마블 배치 편집 버튼 노출 HOTFIX

## 수정 범위
- 31.252의 `배치 편집` 버튼이 게임판과 무관한 위치에 생성되던 문제 수정
- 관리자 화면에서는 배치 API 응답 전에도 `배치 편집 확인 중…` 버튼을 먼저 노출
- 게임판 우측 상단을 기준으로 버튼 위치를 계산하고, 스크롤/회전/화면 크기 변경 시 다시 맞춤
- PC와 모바일 가로화면 모두 viewport 고정 버튼으로 표시
- 배치 API 실패 시 버튼을 숨기지 않고 `배치 편집 재시도`로 표시
- 서버 권한 응답이 관리자 화면과 불일치하면 `편집 권한 다시 확인`으로 표시

## 변경하지 않은 것
- 폴리마블 배경
- 게임룰 / AI / 주사위 / 캐릭터 이동
- 프로필 배치 편집 기능 자체
- 서버 저장 권한 검증

## 확인 방법
1. 관리자 로그인
2. `/polimable` 진입
3. 게임판 우측 상단에 `배치 편집` 버튼 확인
4. 버튼 클릭 후 1P/2P 프로필 및 텍스트 편집 화면 진입 확인
