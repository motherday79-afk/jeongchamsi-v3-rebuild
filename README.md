# JCS_0_0_2

기준: **기존 정참시 레이아웃 유지 + 안정 기능/운영 데이터 이식 단계**

## 이번 버전 범위
- 기존 회원 ID/권한/프로필/비밀번호 해시 이식 구조
- 기존 회원 활동 데이터 이식
- 정뮤니티
- IT'S ME
- COLUMN
- Citizen Choice
- 세대의 선택·대통령
- 전국평가제
- 아카데미
- 댓글 / 좋아요 / 참여기록
- 관리자 로그인 후 회원/콘텐츠 안정 영역 요약

## 복사하지 않는 영역
- NOW RANK
- 정치인 DB 및 정치인 분석
- 비교 인텔리전스
- AGE / GENDER / AGE×GENDER
- Refresh 엔진
- HISTORY
- 정치 인텔리전스 엔진
- 실시간 키워드 / 급상승 데이터

## 저장소 원칙
기존 운영 키를 새 런타임이 직접 사용하지 않습니다.

- 기존 회원: `jcv3:users:v2`
- 기존 활동: `jcv3:useractivity:v1:*`
- 기존 콘텐츠: `jcv3:content:v4:<domain>`

위 값은 **1회 이식 입력**으로만 읽습니다.
새 프로젝트는 모두 `jcsr2:*` 네임스페이스에 저장합니다.

## 비밀번호
기존 정참시의 `scrypt$salt$hash` 형식을 그대로 검증하므로 이식 후 비밀번호 변경 없이 로그인 가능합니다.

## 실제 운영 데이터
회원 DB는 개인정보이므로 ZIP 안에 평문/덤프 형태로 포함하지 않습니다.
배포 후 `MIGRATION_SETUP.md` 절차로 기존 저장소 → 새 저장소 1회 복사를 실행합니다.
