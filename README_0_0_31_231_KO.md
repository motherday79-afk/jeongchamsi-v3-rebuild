# JCS 0.0.31.231 · 폴리마블 주사위 비주얼 개선 패치

## 이번 패치 범위
기존 31.230 보드/캐릭터/배경은 그대로 유지하고 **주사위 UI만 수정**합니다.

- 새 배경 이미지 생성/교체 없음
- 기존 `polimable-board-base-31-227.png` 그대로 유지
- 주사위 2개를 입체감 있는 스타일로 개선
- 1~6 결과는 숫자 텍스트가 아니라 정석 pip(눈) 배치
- `주사위 굴리기` 버튼 재디자인 및 완전 중앙 정렬
- 결과 영역은 `합계 N`과 `DOUBLE · a + b`를 분리 표시
- 더블 판정 로직 유지
- 캐릭터 이동 및 실제 게임 룰은 아직 연결하지 않음

## 적용
31.230 위에 이 패치를 덮어씁니다. 삭제해야 할 신규 배경 파일은 없습니다.
