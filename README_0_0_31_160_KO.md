# JCS 0.0.31.160 — 통합검색 둘러보기 · 로고 확대 · 케이지 제목

## 적용 방법

159 버전에는 `JCS_0_0_31_160_PATCH.zip`을 풀어 기존 프로젝트의 같은 경로에 합친 뒤 배포합니다. 전체 교체가 필요하면 `JCS_0_0_31_160.zip`을 사용합니다. 두 파일을 중복 적용할 필요는 없습니다. 데이터 초기화·재수집·새 환경변수는 필요하지 않습니다. `/api/v3/health`에서 `JCS_0_0_31_160`을 확인할 수 있습니다.

## 통합검색 하단

기존 정치인·언론 보도분석 영역을 끝까지 유지하고 그 뒤에 다음 내용을 표시합니다.

1. **지금 이어지는 캠페인** — 현재 공개된 캠페인 중 대표 캠페인을 먼저 보여주고 중복 없이 최대 3개를 표시합니다. 기존 캠페인 카드의 사진·잘라보기·제목·분류·모금 표시·두 줄 이동 문구를 공유합니다. 카드 전체를 누르면 캠페인 상세로, 전체보기는 `/campaigns`로 연결합니다.
2. **작고 귀여운 별빛 친구들** — ‘정참시 쇼핑몰에 새로운 아이템이 추가되었습니다’ 안내와 기존 키즈 블루 윙·코랄 크라운·블루 오비트·코랄 크리스털 4종을 표시합니다. PC에서는 한 줄, 모바일에서는 2×2입니다. 상품을 누르면 기존 상세페이지로 연결하고 디자인 시안·출시 준비 중 표기를 유지합니다.

캠페인은 기존 공개 API에서 가져옵니다. 관리자가 숨긴 캠페인을 예시 데이터로 다시 덮어쓰지 않습니다. 캠페인 응답을 기다리느라 검색 결과가 늦어지지 않으며, 조회에 실패하거나 공개된 캠페인이 없으면 해당 캠페인 영역을 표시하지 않습니다. 빠르게 재검색하거나 이전 화면으로 돌아갔을 때 오래된 응답이 최신 내용을 덮어쓰지 않도록 처리합니다.

검색 결과와 무관하게 둘러볼 수 있는 정참시 콘텐츠 안내입니다. 검색한 정치인을 캠페인 대상으로 자동 선정하는 기능은 추가하지 않았습니다.

## 로고 크기

- 푸터: 24×24 → **48×48**, 표시 영역을 가로·세로 각각 2배로 확대했습니다.
- 왼쪽 상단: 30×30 → **48×48**.
- 검색창 안: 30×30 → **44×44**. 로고 자리와 검색창 높이도 함께 조정했습니다.

첨부한 골드 PNG 원본은 그대로입니다. 색상·모양·비율·투명도를 바꾸거나 다시 생성하지 않았으며, 원본에 포함된 투명 여백을 포함해 비율을 유지합니다.

## 케이지 제목

입력 문구를 실제 텍스트로 표시하는 공통 렌더러에 굵고 각진 붓획의 서체를 적용했습니다. 관리자 미리보기와 메인 배너가 같은 글씨 배치 계산을 사용합니다. 기울기·획 질감·크림/골드 색상과 줄별 폭을 함께 조정하며, 실제 폰트의 글자 폭과 획 범위에 맞춰 제목판 안에 배치합니다.

관리자에서 직접 줄바꿈 위치를 고르고 첫째 줄·둘째 줄·동일 강조를 설정하는 기존 기능은 유지합니다. 제목을 바꿨을 때 이전 문구의 줄바꿈 설정을 잘못 적용하지 않도록 기존 원문 검증도 유지합니다. 이미 저장한 긴 제목은 기존 버전의 허용 기준을 함께 확인해 지정한 줄 수를 보존하고, 새 서체의 크기를 줄여 제목판 안에 맞춥니다. 케이지 배경·참전 버튼·득표율 영역과 원본 참고 이미지는 그대로 보존했습니다.

**표현상의 한계:** 참고 이미지에 직접 그린 긴 붓끝과 불규칙한 획까지 같은 모양으로 재현한 것은 아닙니다. 이번 변경은 문구를 자유롭게 바꿀 수 있는 붓글씨 표현을 보강한 구현입니다. 원문·변경 문구·정책 문구의 벡터 배치 비교 자료를 검증 폴더에 포함했으며, 이 자료는 브라우저 화면 캡처가 아닙니다.

폰트 원본과 이용 조건을 함께 포함했습니다. 원본 파일은 변환·분할하지 않아 약 3.3MB가 추가됩니다. 로딩 중에는 기존 붓글씨 폰트가 대체 표시될 수 있습니다. 두 폰트가 지원하지 않는 이모지·특수 문자는 기기의 대체 폰트에 따라 달라질 수 있습니다.

## 기존 작업 보존

기존 배지·정치인 데이터·캠페인 예시와 사진·쇼핑몰 상품 디자인·골드 로고 원본은 유지합니다. 메인 오른쪽 광고배너에 CAMPAIGN 이미지를 넣는 작업은 포함하지 않습니다. 결제·후원금 수취·수수료 기능도 추가하지 않습니다.
