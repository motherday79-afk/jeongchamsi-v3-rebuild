# 정참시 275 — 나의 광산 첫 플레이 버전

## 접속
- 메인 화면의 ‘나의 광산 → 광산 입장하기’ 배너를 누릅니다.
- 직접 주소: https://jeongchamsi-v3-rebuild.vercel.app/mine
- 정참시 계정 로그인 후 광부를 선택합니다. 왼쪽 위 ‘정참시’로 메인에 돌아갑니다.
- PC/모바일 모두 사용 가능한 화면 전체를 광산으로 사용합니다. 모바일은 세로 배치에 최적화했습니다.

## 플레이
1. 자동채굴 인부는 기본 3초마다 타격합니다. 접속하지 않아도 저장고가 찰 때까지 경과 시간으로 계산됩니다.
2. ‘직접 내려치기’는 1.5초마다 사용할 수 있습니다. 수동 타격 시 자동 타격 기준 시간이 다시 시작됩니다.
3. 기본 곡괭이 성공률은 타격당 3%, 성공 시 금 1개입니다. 성공이 보장되는 횟수는 없습니다.
4. 저장고 기본 용량은 10금입니다. 가득 찬 경우에만 회수 버튼이 활성화됩니다. 회수하면 골드로 적립하고 채굴이 재개되며 광고주 페이지로 이동합니다.
5. 뒤로가기를 누르면 광산으로 돌아옵니다. 새로고침/중복 클릭으로 같은 회수가 다시 지급되지 않습니다.
6. 곡괭이 강화는 성공률 +2%p, 인부 강화는 자동 간격 -0.1초입니다. 곡괭이·인부 최고 Lv.20, 저장고 최고 Lv.5입니다. 저장고 확장은 곡괭이 또는 인부 Lv.5/10/15/20 조건을 사용합니다.
7. 광산 골드는 기존 정참시 포인트와 분리됩니다. 환전/캠페인 사용처는 이 버전에 없습니다.

## 체험 장비와 캐릭터
- 곡괭이 메뉴에서 황금 곡괭이를 무료 체험할 수 있습니다. 성공률 +12%p, 추가 타격 25%. 추가 타격도 독립적으로 성공 여부를 계산합니다. 결제 기능은 연결하지 않았습니다.
- 건장한 광부/하이힐 광부/미니미 엘프를 선택할 수 있습니다. 캐릭터 선택 자체는 성능 차이가 없습니다.
- 승인 시안을 기준으로 생성한 투명 4프레임 타격 이미지입니다. 배경과 인부·광맥은 분리했습니다. 매 프레임 곡괭이와 팔을 따로 조립하는 3D 리깅 모델은 아닙니다. 장비 체험은 금빛 효과로 구분하며 장비별 개별 곡괭이 외형은 추가 제작 대상입니다.

## 관리자
- 게임 화면의 ‘관리’ 버튼에서 광고주 이름, 간판 문구, https:// URL, 실제 광고 연결 여부를 설정합니다.
- 기본값은 실제 광고 미연결입니다. 회수 시 내부 광고 이동 체험 페이지가 열립니다.
- ‘테스트 저장고 채우기’로 기다리지 않고 회수·복귀·강화를 확인할 수 있습니다. 관리자 테스트 회수는 실제 광고 통계에서 제외합니다.
- 최근 30일 날짜별 이동 수/중복 제외 회원 수를 표시합니다. URL 리다이렉트 발행 기준이며 외부 페이지 로딩 완료를 보장하는 지표가 아닙니다. 여러 광고 설정의 합계이고 광고주별 분리는 이 버전에 없습니다.
- 일별 광고 통계는 90일 후 만료됩니다. 회원 상태는 작은 독립 Redis 키에 저장하고 회수/요청 기록은 각각 최근 8/16개만 유지합니다.

## 확인 범위
- 채굴 시각·확률 경계, 가득 찬 저장고, 강화 조건, 중복/동시 회수, 인증·관리자 권한, 광고 URL, 광고 집계 등 19개 대상 테스트 통과(폴리마블 제거 회귀검사 포함).
- 로컬 브라우저에서 캐릭터 선택, 관리자 테스트 채우기, 회수 후 광고 안내 이동, 뒤로가기 후 10 G/빈 저장고 확인.
- 반복 플레이·전체 모바일 기기 시각 검증은 사용자 확인 단계입니다. 모든 기존 테스트를 실행했다고 의미하지 않습니다.

## 패치 적용
- 274 전체 소스 위에 PATCH ZIP 내용을 같은 상대 경로로 덮어씁니다.
- FULL ZIP은 275 전체 소스입니다. 비밀 환경변수·로그인 토큰·node_modules는 포함하지 않습니다.
- 기존 회원/포인트 데이터는 변경하지 않습니다. 폴리마블 제거 상태는 유지합니다.
